    Static gauge

    The static gauge locks worldsheet time to the lab clock, X^0 = c\tau , so each line of constant \tau is a snapshot of the whole string at one instant of lab time.

    A global shutter

    Filming a moving string, you could sync a global shutter to the wall clock: every frame captures the entire string at a single lab instant. The static gauge is that choice of shutter. It draws the worldsheet's constant-τ\tauτ grid lines to coincide with "the string, right now" as seen in one fixed Lorentz frame. Advance τ\tauτ by dτd\taudτ and the lab clock advances by the same dτd\taudτ — the two clocks are welded together.

    We are free to do this because the Nambu–Goto action depends only on the shape of the worldsheet in spacetime, never on how we ruled it with coordinates (τ,σ)(\tau,\sigma)(τ,σ): any smooth invertible relabeling (τ,σ)→(τ~,σ~)(\tau,\sigma)\to(\tilde\tau,\tilde\sigma)(τ,σ)→(τ~,σ~) leaves it unchanged. This reparameterization invariance is the string analogue of gauge freedom in electromagnetism — many potentials AμA_\muAμ​ describe the same E⃗,B⃗\vec E,\vec BE,B, and a shrewd gauge choice exposes the physics without changing any of it. The static gauge spends the string's gauge freedom on the single most convenient rule: let worldsheet time be lab time.

    The choice, stated

    Pick a Lorentz frame. The hyperplane t=t0t=t_0t=t0​ cuts the worldsheet along a curve — that curve is the string at time t0t_0t0​ in this frame. We declare it to be the line τ=t0\tau = t_0τ=t0​. Doing this at every instant defines τ\tauτ on the whole worldsheet:

    τ(Q)=t(Q)for every worldsheet point Q.\tau(Q) = t(Q) \quad\text{for every worldsheet point } Q.τ(Q)=t(Q)for every worldsheet point Q.

    In terms of the embedding coordinate X0=ctX^0 = ctX0=ct this reads

     X0(τ,σ)=c t(τ,σ)=c τ \boxed{\,X^0(\tau,\sigma) = c\,t(\tau,\sigma) = c\,\tau\,}X0(τ,σ)=ct(τ,σ)=cτ​

    That is the entire content of the static gauge. We have spent our τ\tauτ-freedom and nothing else: σ\sigmaσ is still an arbitrary label running along the string. A relabeling σ↦σ~(τ,σ)\sigma\mapsto\tilde\sigma(\tau,\sigma)σ↦σ~(τ,σ) slides labels along the same physical curve without moving the string, so any physically meaningful "string velocity" must ignore motion parallel to the string — the loose end that makes velocity subtle in Endpoint velocity and endpoint force.

    One choice does remain: the σ\sigmaσ-interval. For an open string, let the two boundary curves be σ=0\sigma=0σ=0 and σ=σ1\sigma=\sigma_1σ=σ1​, so σ∈[0,σ1]\sigma\in[0,\sigma_1]σ∈[0,σ1​]. For a closed string the σ\sigmaσ-line must close into a circle, (τ,σ)∼(τ,σ+σc)(\tau,\sigma)\sim(\tau,\sigma+\sigma_c)(τ,σ)∼(τ,σ+σc​) with σc\sigma_cσc​ the circumference, because the closed worldsheet is topologically a cylinder.

    What the gauge buys: clean tangent vectors

    Split the embedding into time and space, Xμ=(c t, X⃗(t,σ))X^\mu = (c\,t,\ \vec X(t,\sigma))Xμ=(ct, X(t,σ)), where X⃗\vec XX holds the ddd spatial coordinates. Because X0=cτX^0=c\tauX0=cτ is now trivial, the two worldsheet tangent vectors separate cleanly:

    \frac{\partial X^\mu}{\partial\sigma} = \Big(0,\ \frac{\partial\vec X}{\partial\sigma}\Big), \qquad \frac{\partial X^\mu}{\partial\tau} = \Big(c,\ \frac{\partial\vec X}{\partial t}\Big). \tag{1}

    The σ\sigmaσ-tangent has no time component — walking along the string at fixed τ=t\tau=tτ=t does not change ttt — so it is pure spatial stretch ∂X⃗/∂σ\partial\vec X/\partial\sigma∂X/∂σ. The τ\tauτ-tangent always carries the universal ccc in its time slot, with spatial part the motion ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t. This clean split is what later turns the Nambu–Goto area into an ordinary time integral ∫dt (⋯ )\int dt\,(\cdots)∫dt(⋯).

    A ten-second sign check

    The gauge also lets us confirm the sign under the Nambu–Goto square root. Take a piece of string momentarily at rest, ∂X⃗/∂t=0\partial\vec X/\partial t = 0∂X/∂t=0. From (1), with mostly-plus signature,

    X˙⋅X˙=−c2,X′⋅X′=(∂X⃗∂σ)2,X˙⋅X′=0,\dot X\cdot\dot X = -c^2, \qquad X'\cdot X' = \Big(\frac{\partial\vec X}{\partial\sigma}\Big)^2, \qquad \dot X\cdot X' = 0,X˙⋅X˙=−c2,X′⋅X′=(∂σ∂X​)2,X˙⋅X′=0,

    so the square root (X˙⋅X′)2−(X˙⋅X˙)(X′⋅X′)\sqrt{(\dot X\cdot X')^2 - (\dot X\cdot\dot X)(X'\cdot X')}(X˙⋅X′)2−(X˙⋅X˙)(X′⋅X′)​ becomes

    \sqrt{\,0 - (-c^2)\Big(\frac{\partial\vec X}{\partial\sigma}\Big)^2\,} = c\,\Big|\frac{\partial\vec X}{\partial\sigma}\Big|, \tag{2}

    real and positive — ccc times the local stretch, exactly what a proper-area density should be. The minus sign under the radical (together with the minus in front of the action) is the one that makes a static string carry positive energy, as String tension and the energy of a stretched string computes. Forget the sign someday, and this is the fastest way to recover it.

    Signature used throughout this module: mostly-plus, ημν=diag(−,+,…,+)\eta_{\mu\nu}=\mathrm{diag}(-,+,\dots,+)ημν​=diag(−,+,…,+), so for a moving piece X˙⋅X˙=−c2+(∂X⃗/∂t)2\dot X\cdot\dot X = -c^2 + (\partial\vec X/\partial t)^2X˙⋅X˙=−c2+(∂X/∂t)2. This single sign is the most common place to go wrong; the check (2) is the antidote.

    Why this matters

    The static gauge is the hinge of the whole module. It converts the abstract worldsheet area into a plain mechanics problem with an ordinary time integral, which is what lets us read off a potential energy in String tension and the energy of a stretched string and a Lagrangian in Endpoint velocity and endpoint force. Every concrete number in Module 10 rides on this one gauge choice: we glued the string's clock to ours, so "the string at time ttt" is now literally a grid line, and Nambu–Goto becomes ordinary dynamics in ordinary time.

    Open questions

    • Static gauge fixes only τ\tauτ; it leaves residual smooth relabelings σ↦σ~(τ,σ)\sigma\mapsto\tilde\sigma(\tau,\sigma)σ↦σ~(τ,σ) that preserve the two endpoint curves. Module 11 spends this leftover freedom by parameterizing σ\sigmaσ with the string's energy.
    • The gauge needs lab time to be a good worldsheet coordinate: every constant-ttt hyperplane must cut the worldsheet transversally, in an ordinary string snapshot. An everywhere-timelike worldsheet — physical string motion — guarantees this locally; the gauge breaks down only where the worldsheet turns spacelike, i.e. for unphysical superluminal motion.

    Exercise

    A student proposes the "co-moving gauge" X0=cτ+λ X1(τ,σ)X^0 = c\tau + \lambda\, X^1(\tau,\sigma)X0=cτ+λX1(τ,σ) for some constant λ≠0\lambda\neq 0λ=0, hoping to simplify a string drifting along x1x^1x1. Show that this destroys the defining property of the static gauge: compute the time component of the τ\tauτ-tangent, ∂X0/∂τ\partial X^0/\partial\tau∂X0/∂τ, and of the σ\sigmaσ-tangent, ∂X0/∂σ\partial X^0/\partial\sigma∂X0/∂σ, and explain why the clean split (1) is lost. Then state the one property of X0=cτX^0=c\tauX0=cτ that makes the split work.

    Solution

    Differentiate the proposed relation. The τ\tauτ-tangent's time slot is ∂X0∂τ=c+λ ∂X1∂τ,\frac{\partial X^0}{\partial\tau} = c + \lambda\,\frac{\partial X^1}{\partial\tau},∂τ∂X0​=c+λ∂τ∂X1​, no longer the universal constant ccc — it drifts with the string's own motion ∂X1/∂τ\partial X^1/\partial\tau∂X1/∂τ. Worse, the σ\sigmaσ-tangent's time slot is ∂X0∂σ=λ ∂X1∂σ,\frac{\partial X^0}{\partial\sigma} = \lambda\,\frac{\partial X^1}{\partial\sigma},∂σ∂X0​=λ∂σ∂X1​, nonzero wherever the string has any extent along x1x^1x1: walking along the string at fixed τ\tauτ now changes the lab time, so constant-τ\tauτ lines are not snapshots at a single instant. Both halves of the clean split (1) fail — the σ\sigmaσ-tangent picks up a time component and the τ\tauτ-tangent loses its fixed ccc.

    The property that makes X0=cτX^0=c\tauX0=cτ work is that X0X^0X0 depends on τ\tauτ alone, linearly, with no σ\sigmaσ-dependence: then ∂X0/∂σ=0\partial X^0/\partial\sigma=0∂X0/∂σ=0 (constant-τ\tauτ curves are true equal-time snapshots) and ∂X0/∂τ=c\partial X^0/\partial\tau=c∂X0/∂τ=c (a universal clock rate). Any admixture of the spatial coordinates spoils exactly these two facts.

    The student's proposal is not inconsistent — for λ=−1\lambda=-1λ=−1 it sets X0+X1∝τX^0+X^1\propto\tauX0+X1∝τ, which is essentially the Light-cone gauge adopted from Module 12 on. It is a perfectly good gauge that trades away the snapshot property; it just is not a static-type gauge.
