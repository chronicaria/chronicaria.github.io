6:T2860d,<h2 id="one-rule-the-action-is-the-size-of-the-swept-shape">One rule: the action is the size of the swept shape</h2>
<p>A point particle is a dot; a string is a tiny loop or segment. Pushed through time, each sweeps out a shape: the dot a <em>curve</em> (its worldline), the string a <em>surface</em> (its worldsheet). A single rule then fixes the entire theory of each object — <strong>the action is the geometric size of the swept shape</strong>: proper length for the curve, proper area for the surface.</p>

<p>The reason the free particle extremizes proper length is, word for word, the reason the free string extremizes proper area — the same sentence with "length" swapped for "area." This note works out that one swap, and it is why the course spends a module on a particle: the string action is too unfamiliar to guess cold, yet it is a near-mechanical lift of the particle action once the dimensional pattern is visible. The recipe is identical both times — take the reparameterization-invariant geometric measure of the swept object and multiply by the constant with the right units. See <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/09-nambu-goto-worldsheet-geometry/worldsheet-and-induced-metric/" class="wiki-link">Worldsheet and induced metric</a> for the surface and its geometry.</p>
