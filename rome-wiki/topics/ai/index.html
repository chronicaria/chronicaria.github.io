    1. Agent memory architecturesAgent memory is a versioned control system for deciding what an agent writes, retrieves, consolidates, and invalidates; its value is the improvement in future action after every extra token, call, and error opportunity is charged.
    2. AI agents (MOC)This MOC collects notes on LLM agents as teams, swarms, simulators, and collective reasoning systems.
    3. AI evaluation as measurement scienceAI evaluation becomes measurement science when a score is treated as evidence for a defined inference and decision—not as a property that a benchmark simply reveals.
    4. AI R&D automation evidenceEvidence for AI R&D automation must show reliable scientific progress across ambiguous, long-feedback-loop work—not merely fast execution on a scored engineering task.
    5. AI safety evaluationAI safety evaluation is the evidence-producing process that tests whether an AI system can cause a specified harm, whether safeguards reduce that risk in realistic conditions, and whether the remaining uncertainty permits a particular development or deployment decision.
    6. Benchmark contamination and saturationBenchmark scores become misleading for several different reasons—training-data contamination, memorization, benchmark leakage, saturation, and post-hoc tuning—and each failure requires a different diagnosis and remedy.
    7. Computer-use evaluationComputer-use evaluation should measure a fully specified agent–scaffold–interface system in a controlled, stateful environment, not treat one benchmark success rate as a context-free property of a model.
    8. Cost-adjusted frontier model performanceCost-adjusted model evaluation should publish a task-specific quality–resource frontier, not divide one benchmark score by one price and call the resulting ratio a universal ranking.
    9. Designed information asymmetry for LLM forecastsDesigned information asymmetry deliberately gives forecasting agents different evidence so deliberation can transmit private signals instead of amplifying shared mistakes.
    10. From agent task horizons to deployment decisionsA task-horizon result is an external capability signal, not a permission slip: deploy only after translating its full success curve into use-case-specific evidence about failure cost, detectability, safeguards, and local performance.
    11. From forecasts to positions in agentic portfoliosAn agentic portfolio should separate forecast formation from position sizing, because being right directionally is not the same as knowing how much to bet.
    12. Frontier AI release evidence ladderA frontier-AI “release” is not one event but a sequence of claims about identity, documentation, access, measured performance, independent evaluation, and sustained deployment; each claim should inherit only the strongest evidence actually available for it.
    13. GPT-Live full-duplex voice architectureGPT-Live-1 and GPT-Live-1 mini are full-duplex voice models that can listen and speak continuously, while delegating harder search and reasoning tasks to a separate frontier model.
    14. Inference-time scalingInference-time scaling improves a fixed model system by spending and allocating more computation after a prompt arrives, but its gains depend on search diversity, reliable verification, adaptive stopping, and honest accounting of tokens, latency, and cost.
    15. Infrastructure noise in agentic coding evaluationsInfrastructure is part of an agentic coding experiment: memory ceilings, CPU allocation, sandbox enforcement, concurrency, caching, and service latency can change both whether a run finishes and which problem-solving strategies succeed.
    16. Interpretability evidence standardsAn interpretability claim should be graded by what it demonstrates—prediction, causal control, or a faithful mechanism—rather than by how intuitive its visualization looks.
    17. Large-scale LLM agent systemsLarge-scale LLM agent systems currently appear in three public forms: task teams, forecasting/debate ensembles, and simulated societies where many agents interact over time.
    18. LLM agent ensembles for forecastingA many-agent LLM forecasting system should behave less like a shouting debate club and more like an evidence-diverse, calibrated forecasting ensemble.
    19. LLM agent societiesLLM agent societies simulate populations of language-model agents interacting in a world, which can produce roles, cliques, polarization, norms, and other emergent social patterns.
    20. Long-horizon task reliabilityLong-horizon agent reliability is the probability that an entire extended task ends correctly under a stated model, scaffold, budget, and environment—not the model's ability to produce one impressive long trajectory.
    21. Model versus scaffold in agent evaluationsAn agent benchmark measures a configured system—not a model in isolation—so credible comparisons must separately report the model, scaffold, tools, operator, and resource budget.
    22. Multi-agent forecasting frameworksMulti-agent forecasting frameworks work best when they treat agents as decorrelated evidence processors, not as many copies of the same opinion engine.
    23. Neural scaling inference-time compute and algorithmic progressTraining scale builds a model's reusable competence, inference-time compute spends resources to elicit and select better answers from that competence, and algorithmic progress changes the return on both; none is a general substitute for the other two.
    24. Open-weight frontier modelsAn open-weight model exposes parameters that others can run, inspect, or adapt, but the practical frontier depends separately on license rights, reproducibility, measured capability, serving cost, and whether an organization can deploy the whole system reliably.
    25. Orca inter-agent orchestrationOrca agents can collaborate through persistent terminal-to-terminal messages, tracked task dispatches, blocking questions, completion messages, and coordinator loops.
    26. Orca workflow patternsOrca is most powerful when agents are given distinct branches, roles, evidence, or review duties, then merged through human diff review.
    27. Reasoning budget and fair model comparisonA reasoning score describes a model-system-budget combination, not a model in isolation; fair comparison therefore reports both matched-resource results and each system's accuracy–cost frontier.
    28. Scientific discovery agentsScientific discovery agents are best understood as evidence-producing systems on a ladder from bounded assistance to independently replicated discovery—not as “AI scientists” merely because they can write a paper or operate a laboratory tool.
    29. Single-agent versus multi-agent inferenceA multi-agent system earns its extra complexity only when independent search, information diversity, specialization, or verification improves the accuracy–cost frontier against a compute-matched single-agent baseline.
    30. Time horizon of AI agentsAn AI agent's task-completion time horizon is the human-expert duration of tasks at which a fitted evaluation curve predicts a chosen probability of success; it is a difficulty-calibrated benchmark statistic, not the time the agent runs unattended.
    31. Tool-use reliabilityTool-use reliability is the measured ability of a particular model-and-scaffold system to reach a verified terminal state under imperfect observations and tool failures, without exceeding its authority or hiding the cost of recovery.
    32. Verification loops for coding agentsA coding agent becomes dependable not by testing more indiscriminately, but by separating feedback used to improve a patch from independent evidence used to decide whether the patch should be trusted.
    33. What makes an AI model frontierAn AI model is frontier only relative to a specified capability, resource, or risk boundary at a specified time; no single benchmark rank, parameter count, or lab label establishes the category.
