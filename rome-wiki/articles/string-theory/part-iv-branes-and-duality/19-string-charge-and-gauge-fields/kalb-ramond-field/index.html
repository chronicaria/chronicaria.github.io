    Kalb-Ramond field

    The Kalb–Ramond field B_{\mu\nu} is an antisymmetric two-index gauge field, and a string couples to it the way a point particle couples to the photon A_\mu — one extra index on the field for one extra dimension on the object.

    What the extra index is for

    A photon AμA_\muAμ​ carries one index because it feeds on a tangent vector dXμdX^\mudXμ: a point particle drags a single direction as it moves. A string does not move along a line; it sweeps a surface, and a surface has an oriented area element, an antisymmetric bivector dXμ∧dXνdX^\mu\wedge dX^\nudXμ∧dXν. Feeding on area takes a field with two antisymmetric indices, and that field is BμνB_{\mu\nu}Bμν​. Everything in this note is that one idea and the gauge redundancy it carries.

    The pattern generalizes: a ppp-dimensional object couples to a gauge field with (p+1)(p{+}1)(p+1) antisymmetric indices (a point is p=0p=0p=0, a string is p=1p=1p=1).

    object worldvolume dim what it drags gauge field
    point particle 111 (a line) tangent vector dXμdX^\mudXμ AμA_\muAμ​ (1 index)
    string 222 (a sheet) oriented area dXμ∧dXνdX^\mu\wedge dX^\nudXμ∧dXν BμνB_{\mu\nu}Bμν​ (2 indices)
    Dppp-brane p+1p{+}1p+1 oriented (p+1)(p{+}1)(p+1)-volume Aμ0⋯μpA_{\mu_0\cdots\mu_p}Aμ0​⋯μp​​ (p+1p{+}1p+1 indices)

    The string sits one rung up the ladder from the particle. The field is not an add-on: quantizing the closed string produces a massless antisymmetric state Bμν=−BνμB_{\mu\nu}=-B_{\nu\mu}Bμν​=−Bνμ​ alongside the graviton and dilaton (see Fundamental string charge), so BBB is already present in the closed-string spectrum.

    The field strength and its gauge symmetry

    Write Bμν=−BνμB_{\mu\nu}=-B_{\nu\mu}Bμν​=−Bνμ​. Its gauge-invariant field strength is the antisymmetrized derivative (in form language, H=dBH=dBH=dB):

    Hμνρ=∂μBνρ+∂νBρμ+∂ρBμν.(1)H_{\mu\nu\rho} = \partial_\mu B_{\nu\rho} + \partial_\nu B_{\rho\mu} + \partial_\rho B_{\mu\nu}. \tag{1}Hμνρ​=∂μ​Bνρ​+∂ν​Bρμ​+∂ρ​Bμν​.(1)

    This is the two-form analogue of Fμν=∂μAν−∂νAμF_{\mu\nu}=\partial_\mu A_\nu-\partial_\nu A_\muFμν​=∂μ​Aν​−∂ν​Aμ​: the physical, gauge-invariant object built from derivatives of the potential.

    The gauge transformation shifts BBB by an "exterior derivative" of a vector parameter Λμ\Lambda_\muΛμ​:

    Bμν⟼Bμν+∂μΛν−∂νΛμ.(2)B_{\mu\nu}\longmapsto B_{\mu\nu} + \partial_\mu\Lambda_\nu-\partial_\nu\Lambda_\mu. \tag{2}Bμν​⟼Bμν​+∂μ​Λν​−∂ν​Λμ​.(2)

    The parameter carries one index — Maxwell's λ\lambdaλ is a scalar, BBB's Λμ\Lambda_\muΛμ​ is a vector. Plug (2) into (1): every added piece is a second antisymmetrized derivative like ∂[μ∂νΛρ]\partial_{[\mu}\partial_\nu\Lambda_{\rho]}∂[μ​∂ν​Λρ]​, which vanishes because partials commute while the indices are antisymmetrized. So HHH is unchanged — in form language, H↦d(B+dΛ)=dB+d2Λ=dBH\mapsto d(B+d\Lambda)=dB+d^2\Lambda=dBH↦d(B+dΛ)=dB+d2Λ=dB since d2=0d^2=0d2=0. This is the same reason FFF survives Aμ↦Aμ+∂μλA_\mu\mapsto A_\mu+\partial_\mu\lambdaAμ​↦Aμ​+∂μ​λ: the field strength keeps only the curl-like part, and the shift is purely gradient-like.

    Why a string, not a particle, couples to BBB

    A point particle of charge qqq couples through a one-form integrated along its worldline:

    SA=q∫Aμ(X) dXμ.(3)S_A = q\int A_\mu(X)\,dX^\mu. \tag{3}SA​=q∫Aμ​(X)dXμ.(3)

    One integral, one tangent vector, because a worldline has one direction. A string's worldsheet has two directions (τ,σ)(\tau,\sigma)(τ,σ), so it can integrate a two-form. With the sign convention shared with Fundamental string charge,

    SB=−12∫dτ dσ  ϵαβ ∂αXμ ∂βXν Bμν(X),(4)S_B = -\frac{1}{2}\int d\tau\,d\sigma\; \epsilon^{\alpha\beta}\,\partial_\alpha X^\mu\,\partial_\beta X^\nu\, B_{\mu\nu}(X), \tag{4}SB​=−21​∫dτdσϵαβ∂α​Xμ∂β​XνBμν​(X),(4)

    where α,β∈{0,1}\alpha,\beta\in\{0,1\}α,β∈{0,1} are worldsheet indices (∂0=∂τ, ∂1=∂σ\partial_0=\partial_\tau,\ \partial_1=\partial_\sigma∂0​=∂τ​, ∂1​=∂σ​) and ϵ01=1\epsilon^{01}=1ϵ01=1. The block ϵαβ∂αXμ∂βXν=∂τXμ∂σXν−∂σXμ∂τXν\epsilon^{\alpha\beta}\partial_\alpha X^\mu\partial_\beta X^\nu = \partial_\tau X^\mu\partial_\sigma X^\nu-\partial_\sigma X^\mu\partial_\tau X^\nuϵαβ∂α​Xμ∂β​Xν=∂τ​Xμ∂σ​Xν−∂σ​Xμ∂τ​Xν is the antisymmetric tangent bivector — the oriented area element the sheet sweeps in spacetime. BBB assigns a coupling to that oriented area, so orientation is physical: reverse σ→π−σ\sigma\to\pi-\sigmaσ→π−σ and the area element flips sign, flipping the sign of SBS_BSB​. Unoriented string theories therefore have no BBB in their spectrum. (The full consequence — that string charge is a vector along the string — is worked out in Fundamental string charge.)

    Closed strings vs. open strings: watch the boundary

    The gauge redundancy (2) has teeth, and the difference between closed and open strings is entirely a boundary-term story — the theme running through this module.

    Vary SBS_BSB​ under (2). The two terms of δBμν\delta B_{\mu\nu}δBμν​ are antisymmetric and contract with the antisymmetric area element, so they double up, and the result collapses to two total worldsheet derivatives:

    δΛSB=−∫dτ dσ (∂τ(Λν ∂σXν)−∂σ(Λν ∂τXν)).(5)\delta_\Lambda S_B = -\int d\tau\,d\sigma\,\Big(\partial_\tau(\Lambda_\nu\,\partial_\sigma X^\nu) - \partial_\sigma(\Lambda_\nu\,\partial_\tau X^\nu)\Big). \tag{5}δΛ​SB​=−∫dτdσ(∂τ​(Λν​∂σ​Xν)−∂σ​(Λν​∂τ​Xν)).(5)

    This is a curl in the (τ,σ)(\tau,\sigma)(τ,σ) plane, so by Green's/Stokes' theorem it equals a line integral around the worldsheet boundary ∂Σ\partial\Sigma∂Σ. Orient the plane the standard way, σ\sigmaσ horizontal and τ\tauτ vertical, and traverse ∂Σ\partial\Sigma∂Σ counterclockwise:

    δΛSB=∮∂ΣΛμ dXμ.(6)\delta_\Lambda S_B = \oint_{\partial\Sigma}\Lambda_\mu\,dX^\mu. \tag{6}δΛ​SB​=∮∂Σ​Λμ​dXμ.(6)
    • Closed string. The worldsheet is a tube, infinite in time and periodic in σ\sigmaσ, so there is no σ\sigmaσ-edge. The ∂τ\partial_\tau∂τ​ piece dies because Λ→0\Lambda\to0Λ→0 at the ends of time. So ∂Σ=∅\partial\Sigma=\varnothing∂Σ=∅ and δΛSB=0\delta_\Lambda S_B=0δΛ​SB​=0: the coupling is gauge invariant, and a closed string carries conserved Kalb–Ramond charge with no endpoint data needed.
    • Open string. The worldsheet is a strip with two edges, the endpoint worldlines at σ=0\sigma=0σ=0 and σ=π\sigma=\piσ=π. Now ∂Σ≠∅\partial\Sigma\neq\varnothing∂Σ=∅. The ∂τ\partial_\tau∂τ​ piece still vanishes at temporal infinity, leaving the σ\sigmaσ-boundary term
    δΛSB=∫dτ Λμ ∂τXμ∣σ=π−∫dτ Λμ ∂τXμ∣σ=0.(7)\delta_\Lambda S_B = \int d\tau\,\Lambda_\mu\,\partial_\tau X^\mu\Big|_{\sigma=\pi} - \int d\tau\,\Lambda_\mu\,\partial_\tau X^\mu\Big|_{\sigma=0}. \tag{7}δΛ​SB​=∫dτΛμ​∂τ​Xμ​σ=π​−∫dτΛμ​∂τ​Xμ​σ=0​.(7)

    Equation (7) is the engine of the rest of the module. A nonzero gauge variation means the standalone string current is not conserved at the endpoints — the charge flowing down the string reaches the end and has nowhere to go. When the endpoints sit on a D-brane, only the directions along the brane survive: the Dirichlet condition ∂τXa=0\partial_\tau X^a=0∂τ​Xa=0 kills the normal components, so the surviving variation involves the brane indices, Λm ∂τXm\Lambda_m\,\partial_\tau X^mΛm​∂τ​Xm. Endpoint charge cures the leftover by making each endpoint a charged particle under a Maxwell field AmA_mAm​ on the brane, with the joint rule

    Am⟼Am−Λm,(8)A_m\longmapsto A_m-\Lambda_m, \tag{8}Am​⟼Am​−Λm​,(8)

    tuned so its variation cancels (7) term by term. The consequence, developed in Maxwell fields on branes, is that FFF alone is no longer gauge invariant on the brane; only the combination

    Fmn=Fmn+Bmn(9)\mathcal F_{mn}=F_{mn}+B_{mn} \tag{9}Fmn​=Fmn​+Bmn​(9)

    is, and the string charge that would have "stopped" at the endpoint continues as electric flux on the brane worldvolume.

    Open questions

    • The absolute normalization of the BBB coupling and of the endpoint charge is fixed only by matching to the full string normalization (string coupling gsg_sgs​, α′\alpha'α′) and the brane effective action — deferred to Born-Infeld action and later material.
    • The Ramond–Ramond analogue, which gives stable charged D-branes in superstring theory, is a separate story; this note covers only the NS–NS two-form BμνB_{\mu\nu}Bμν​ that the fundamental string couples to. See D-brane charge as a preview.

    Exercise

    Show that SBS_BSB​ in (4) is unchanged if you replace BμνB_{\mu\nu}Bμν​ by its symmetric part's counterpart — i.e. prove directly that only the antisymmetric part of any two-index field couples. Concretely: let Tμν=Sμν+BμνT_{\mu\nu}=S_{\mu\nu}+B_{\mu\nu}Tμν​=Sμν​+Bμν​ with Sμν=SνμS_{\mu\nu}=S_{\nu\mu}Sμν​=Sνμ​ symmetric and Bμν=−BνμB_{\mu\nu}=-B_{\nu\mu}Bμν​=−Bνμ​ antisymmetric, and show the symmetric part SμνS_{\mu\nu}Sμν​ drops out of the worldsheet coupling. Then use the same mechanism to argue in one line why the gauge shift ∂μΛν−∂νΛμ\partial_\mu\Lambda_\nu-\partial_\nu\Lambda_\mu∂μ​Λν​−∂ν​Λμ​ is the most general one that leaves HHH invariant while being built from a vector parameter.

    Solution

    The coupling contracts BμνB_{\mu\nu}Bμν​ with the area element Aμν≡ϵαβ∂αXμ∂βXνA^{\mu\nu}\equiv\epsilon^{\alpha\beta}\partial_\alpha X^\mu\partial_\beta X^\nuAμν≡ϵαβ∂α​Xμ∂β​Xν. Swapping the dummy names μ↔ν\mu\leftrightarrow\nuμ↔ν and using ϵαβ=−ϵβα\epsilon^{\alpha\beta}=-\epsilon^{\beta\alpha}ϵαβ=−ϵβα, Aνμ=ϵαβ∂αXν∂βXμ=ϵβα∂βXν∂αXμ=−ϵαβ∂αXμ∂βXν=−Aμν,A^{\nu\mu}=\epsilon^{\alpha\beta}\partial_\alpha X^\nu\partial_\beta X^\mu=\epsilon^{\beta\alpha}\partial_\beta X^\nu\partial_\alpha X^\mu=-\epsilon^{\alpha\beta}\partial_\alpha X^\mu\partial_\beta X^\nu=-A^{\mu\nu},Aνμ=ϵαβ∂α​Xν∂β​Xμ=ϵβα∂β​Xν∂α​Xμ=−ϵαβ∂α​Xμ∂β​Xν=−Aμν, so AμνA^{\mu\nu}Aμν is antisymmetric. Now for the symmetric part, SμνAμν=SνμAμνS_{\mu\nu}A^{\mu\nu}=S_{\nu\mu}A^{\mu\nu}Sμν​Aμν=Sνμ​Aμν (symmetry of SSS) =SμνAνμ=S_{\mu\nu}A^{\nu\mu}=Sμν​Aνμ (relabel) =−SμνAμν=-S_{\mu\nu}A^{\mu\nu}=−Sμν​Aμν (antisymmetry of AAA). A quantity equal to its own negative is zero, so SμνAμν=0S_{\mu\nu}A^{\mu\nu}=0Sμν​Aμν=0: the symmetric part contributes nothing, and TμνAμν=BμνAμνT_{\mu\nu}A^{\mu\nu}=B_{\mu\nu}A^{\mu\nu}Tμν​Aμν=Bμν​Aμν. Only the antisymmetric part couples.

    The same antisymmetry pins down the gauge symmetry. A shift of BBB built from first derivatives of a vector Λμ\Lambda_\muΛμ​ is a linear combination of ∂μΛν\partial_\mu\Lambda_\nu∂μ​Λν​ and ∂νΛμ\partial_\nu\Lambda_\mu∂ν​Λμ​; keeping BBB antisymmetric forces the antisymmetric combination ∂μΛν−∂νΛμ=(dΛ)μν\partial_\mu\Lambda_\nu-\partial_\nu\Lambda_\mu=(d\Lambda)_{\mu\nu}∂μ​Λν​−∂ν​Λμ​=(dΛ)μν​, up to an overall scale absorbed into Λ\LambdaΛ. It leaves H=dBH=dBH=dB invariant because H↦d(B+dΛ)=dB+d2Λ=dBH\mapsto d(B+d\Lambda)=dB+d^2\Lambda=dBH↦d(B+dΛ)=dB+d2Λ=dB (d2=0d^2=0d2=0). This is the most general first-derivative shift of a vector parameter consistent with the antisymmetry of BBB.
