    A string can only move sideways

    A classical string is a wiggling line in DDD-dimensional spacetime, described by DDD embedding functions Xμ(τ,σ)X^\mu(\tau,\sigma)Xμ(τ,σ). Not all DDD are physical: the description is redundant in two ways, and both redundancies must be removed before "how much is the string actually doing?" has an honest answer.

    A point sliding along the string toward its neighbor changes neither the string's shape nor where it sits in space — it only relabels which value of σ\sigmaσ marks that spacetime point. Sliding is reparameterization bookkeeping, not motion; the string's genuine motion is sideways. Light-cone gauge is the coordinate choice that turns this fact into a clean equation: after gauge-fixing, the physical fields are the transverse coordinates XIX^IXI.

    The mechanism has three moves:

    1. Pick a clock. Instead of ordinary time X0X^0X0, use the light-ray combination X+=(X0+X1)/2X^+ = (X^0+X^1)/\sqrt2X+=(X0+X1)/2​. Spend the gauge freedom to force X+=2α′p+τX^+ = 2\alpha' p^+\tauX+=2α′p+τ (natural units ℏ=c=1\hbar=c=1ℏ=c=1 throughout). Now X+X^+X+ is not a field to solve for; it is the worldsheet time τ\tauτ in disguise.
    2. Solve, don't just impose. In light-cone coordinates the two constraints (X˙±X′)2=0(\dot X\pm X')^2=0(X˙±X′)2=0 that tangled everything in earlier gauges become linear equations for the derivatives of the other light-ray coordinate X−X^-X−. You reconstruct X−X^-X− from the transverse data — no square root, no tangle.
    3. What's left is physical. X+X^+X+ is the clock, X−X^-X− is reconstructed, so the genuine motion lives entirely in the D−2D-2D−2 transverse coordinates XIX^IXI.

    Of the DDD coordinates, then: one becomes the clock, one is dictated by the constraints, and the remaining D−2D-2D−2 are the string's actual degrees of freedom. That count is the module's headline.

    Why one algebraic fact makes it all work

    Everything hinges on the shape of the metric in light-cone coordinates. With mostly-plus signature η=diag(−,+,+,… )\eta = \mathrm{diag}(-,+,+,\dots)η=diag(−,+,+,…) and X±=(X0±X1)/2X^\pm = (X^0\pm X^1)/\sqrt2X±=(X0±X1)/2​,

    a⋅b=−a+b−−a−b++aIbI,a\cdot b = -a^+b^- - a^-b^+ + a^Ib^I,a⋅b=−a+b−−a−b++aIbI,

    which has no (a−)2(a^-)^2(a−)2 term — the (+,−)(+,-)(+,−) block is off-diagonal. So a constraint like (X˙±X′)2=0(\dot X\pm X')^2 = 0(X˙±X′)2=0, quadratic in general, is only linear in the unknown X˙−±X−′\dot X^-\pm X^{-\prime}X˙−±X−′. In static gauge (freeze X0X^0X0) the leftover constraints stay quadratic and couple all D−1D-1D−1 spatial fields; you can impose them but never invert them. Light-cone gauge trades a familiar time coordinate for a metric that lets you divide instead of extracting a root, and the price is that Lorentz symmetry is no longer manifest.

    The module in one recipe

    For the open string, read light-cone gauge as an input-output machine:

    { x0I, pI, αnI, p+, x0− }⟹XI(τ,σ), X+(τ,σ), X−(τ,σ).\{\,x_0^I,\ p^I,\ \alpha_n^I,\ p^+,\ x_0^-\,\} \quad\Longrightarrow\quad X^I(\tau,\sigma),\ X^+(\tau,\sigma),\ X^-(\tau,\sigma).{x0I​, pI, αnI​, p+, x0−​}⟹XI(τ,σ), X+(τ,σ), X−(τ,σ).

The gauge gives X+=2α′p+τX^+ = 2\alpha' p^+\tauX+=2α′p+τ immediately; the constraints give X−X^-X− by integration. No longitudinal oscillator αn−\alpha_n^-αn−​ is ever chosen independently — each is fixed to a quadratic in the transverse modes.

    Why this module matters

    Module 11 solved the string equations of motion only partially: the constraints X˙⋅X′=0\dot X\cdot X' = 0X˙⋅X′=0 and X˙2+X′2=0\dot X^2 + X'^2 = 0X˙2+X′2=0 were still sitting there, entangling the components of XμX^\muXμ, and we never got a clean degree-of-freedom count. This module finishes the job by exhibiting the D−2D-2D−2 physical transverse fields explicitly.

    It is also the hinge into Part III. When we quantize, the transverse oscillators αnI\alpha_n^IαnI​ become the creation/annihilation operators that build the entire string spectrum, and the reconstruction αn−∼Ln⊥\alpha_n^-\sim L_n^\perpαn−​∼Ln⊥​ becomes the source of the critical dimension: demanding that the hidden Lorentz generators still close into the correct algebra forces D=26D=26D=26. That anomaly, and the normal-ordering shift a=−1a=-1a=−1 that turns the classical M2≥0M^2\geq0M2≥0 formula into a spectrum with a tachyon, are flagged below and derived in Part III.

    Static gauge versus light-cone gauge

    Static gauge Light-cone gauge
    Clock X0=τX^0 = \tauX0=τ (nnn timelike) X+=2α′p+τX^+ = 2\alpha' p^+\tauX+=2α′p+τ (nnn null)
    Constraints can only be imposed can be solved for X˙−±X−′\dot X^-\pm X^{-\prime}X˙−±X−′
    Physical fields D−1D-1D−1 spatial XiX^iXi, still tangled D−2D-2D−2 transverse XIX^IXI, free
    Manifest symmetry spatial rotations; boosts need compensating reparameterizations transverse rotations; boosts mixing +,−,I+,-,I+,−,I are hidden
    Best for visualizing string shapes counting dof, solving completely, quantizing

    Both freeze one coordinate. The difference is the leftover constraint: static gauge leaves a nonlinear relation among all D−1D-1D−1 spatial fields (nothing isolates); light-cone gauge leaves a term −2X˙+X˙−=−2(2α′p+)X˙−-2\dot X^+\dot X^- = -2(2\alpha' p^+)\dot X^-−2X˙+X˙−=−2(2α′p+)X˙− that is linear in X˙−\dot X^-X˙−, so you divide it out. The null direction is exactly what converts a quadratic-looking constraint into a linear reconstruction.

    Open questions

    • Light-cone gauge breaks manifest Lorentz invariance (it singles out the x1x^1x1 direction). Classically harmless, but this is where quantization bites: requiring the broken Lorentz generators to close forces D=26D=26D=26. Deferred to Part III.
    • The classical mass formula M2=1α′∑n≥1n anI∗anI≥0M^2 = \frac1{\alpha'}\sum_{n\geq1} n\,a_n^{I*}a_n^I \geq 0M2=α′1​∑n≥1​nanI∗​anI​≥0 says the classical string is never a tachyon. Quantization adds a normal-ordering constant a=−1a=-1a=−1 (from a regularized ∑n≥1n=ζ(−1)=−112\sum_{n\geq1} n = \zeta(-1) = -\tfrac1{12}∑n≥1​n=ζ(−1)=−121​ via a cutoff — never the naive divergent sum), producing a tachyon at D=26D=26D=26 and discretizing the spectrum. Deferred to Part III.
    • This module treats the open string. The closed string uses β=1\beta=1β=1, σ∈[0,2π]\sigma\in[0,2\pi]σ∈[0,2π], independent left/right movers, and a global level-matching condition; deferred to the closed-string modules.

    Solution

    (a) X+X^+X+ is frozen by the gauge — the reparameterization freedom is spent to set X+=2α′p+τX^+ = 2\alpha' p^+\tauX+=2α′p+τ, so X+X^+X+ carries no dynamical data beyond the single number p+p^+p+ (its zero-mode position and all oscillators are zero). X−X^-X− is solved by the constraints — the two constraints determine both X˙−\dot X^-X˙− and X−′X^{-\prime}X−′ from the transverse fields, so X−X^-X− is fixed up to one integration constant x0−x_0^-x0−​. The free data is exactly { XI(τ,σ), p+, x0− },\{\,X^I(\tau,\sigma),\ p^+,\ x_0^-\,\},{XI(τ,σ), p+, x0−​}, i.e. the D−2D-2D−2 transverse fields plus two longitudinal constants.

    (b) With I=2,…,D−1I = 2,\dots,D-1I=2,…,D−1 (that is D−2D-2D−2 values) and Neumann endpoints, XI(τ,σ)=x0I+2α′ α0I τ+i2α′∑n≠01n αnI e−inτcos⁡nσ,α0I=2α′ pI,X^I(\tau,\sigma) = x_0^I + \sqrt{2\alpha'}\,\alpha_0^I\,\tau + i\sqrt{2\alpha'}\sum_{n\neq0}\frac{1}{n}\,\alpha_n^I\,e^{-in\tau}\cos n\sigma, \qquad \alpha_0^I = \sqrt{2\alpha'}\,p^I,XI(τ,σ)=x0I​+2α′​α0I​τ+i2α′​∑n=0​n1​αnI​e−inτcosnσ,α0I​=2α′​pI, so the drift term is 2α′ α0Iτ=2α′pIτ\sqrt{2\alpha'}\,\alpha_0^I\tau = 2\alpha' p^I\tau2α′​α0I​τ=2α′pIτ.
