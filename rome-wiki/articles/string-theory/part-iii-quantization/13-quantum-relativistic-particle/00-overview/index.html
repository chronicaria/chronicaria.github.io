    The big picture

    Quantizing the string is a hard jump, but almost all of its machinery already shows up for a single relativistic particle: pick independent variables, postulate their commutators, write a Hamiltonian that reproduces the classical motion, and find the Hilbert space. So we do the particle first. The string then reuses every step, with one addition — an oscillator index nnn and a sum over modes.

    A relativistic particle is a string with no vibrations — a point carried through spacetime. Quantizing it teaches the bookkeeping (light-cone gauge, canonical commutators, the Hamiltonian) in a setting where the "mass" is a fixed number mmm. For the string, that number becomes an operator built from vibration modes, and the rest of Part III is what that operator does to the spectrum.

    The three moves

    The whole module is one classical-to-quantum bridge, crossed in three moves:

    1. Reduce the phase space. Light-cone gauge solves the mass-shell constraint instead of dragging it along, leaving only the independent data (xI,x0−,pI,p+)(x^I, x_0^-, p^I, p^+)(xI,x0−​,pI,p+).
    2. Quantize what's left. Promote those to operators; turn Poisson brackets into commutators via [A,B]=i{A,B}[A,B]=i\{A,B\}[A,B]=i{A,B} (natural units, ℏ=c=1\hbar=c=1ℏ=c=1).
    3. Reuse the reduced Hamiltonian as an operator. Because it is built from commuting momenta, there is no ordering ambiguity — for the particle. (That is exactly where the string will get interesting.)

    The payoff

    The single result to remember is the light-cone Hamiltonian

    \boxed{\;H = \frac{1}{2m^2}\big(p^I p^I + m^2\big)\;} \tag{1}

    Everything in the module compresses into this line. In light-cone components p2=−2p+p−+pIpIp^2 = -2p^+p^- + p^Ip^Ip2=−2p+p−+pIpI (mostly-plus signature), so the mass shell p2+m2=0p^2+m^2=0p2+m2=0 solves for the light-cone energy, p−=12p+(pIpI+m2)p^- = \tfrac{1}{2p^+}(p^Ip^I + m^2)p−=2p+1​(pIpI+m2). Multiply by the gauge factor p+/m2p^+/m^2p+/m2 — which converts a generator of x+x^+x+-translations into a generator of τ\tauτ-translations — and the p+p^+p+ cancels, leaving (1)(1)(1). The Hamiltonian does not impose the mass shell as a side constraint; it is the mass shell, already solved.

    That template is the reason to bother: for the string, replace the fixed rest mass mmm by a mass operator built from oscillators, then demand that the Lorentz generators still close. That single demand forces D=26D=26D=26 and the normal-ordering constant a=−1a=-1a=−1. The particle version has no such obstruction — its m2m^2m2 is just a number — which is precisely why it is the clean rehearsal.

    Sublessons

    Read in this order; the first three build the bridge, the last checks that quantization did not break Lorentz symmetry.

    • 13.1 Schrodinger and Heisenberg pictures — two bookkeepings of time. We quantize in the Heisenberg picture because there the operators obey the classical equations of motion, which is exactly the leverage we use to pin down the theory.
    • 13.2 Canonical commutators — which variables survive the constraint, and the postulated [xI,pJ]=iηIJ[x^I,p^J]=i\eta^{IJ}[xI,pJ]=iηIJ, [x0−,p+]=−i[x_0^-,p^+]=-i[x0−​,p+]=−i. The minus sign in the longitudinal pair is forced by the light-cone metric, not chosen.
    • 13.3 Light-cone Hamiltonian — the centerpiece. Derives (1)(1)(1) from gauge condition + mass shell, and checks it generates the right τ\tauτ-evolution.
    • 13.4 Momentum and Lorentz generators — conserved charges become operators that generate their symmetry by commutation, and close into the Lorentz algebra [Mμν,Mρσ]=…[M^{\mu\nu},M^{\rho\sigma}]=\dots[Mμν,Mρσ]=…. The closure test [M−I,M−J]=0[M^{-I},M^{-J}]=0[M−I,M−J]=0 is the toy version of the calculation that later fixes D=26D=26D=26.

    Open questions

    • No mathematical step in this module is deferred — the four sublessons stand alone. The one genuine forward reference is conceptual: the string version of the Lorentz-closure test, [M−I,M−J]=0[M^{-I},M^{-J}]=0[M−I,M−J]=0, becomes anomalous unless the open-string spectrum carries the right normal-ordering constant and dimension. That anomaly is where this module's template pays off; it is settled in Modules 14 and 16.

    Exercise

    Do this cold, with no notes — it is the exit test for the entire module.

    Starting from the relativistic particle action S=−m∫dτ−x˙2S=-m\int d\tau\sqrt{-\dot x^2}S=−m∫dτ−x˙2​, impose the light-cone gauge x+=p+m2τx^+ = \frac{p^+}{m^2}\taux+=m2p+​τ and derive the light-cone Hamiltonian (1)(1)(1). Then, in one or two sentences, explain why this HHH is the mass-shell relation p2+m2=0p^2+m^2=0p2+m2=0 — i.e. why HHH is that constraint solved for p−p^-p− and dressed with the gauge factor p+/m2p^+/m^2p+/m2. Finally, write down the canonical commutators from memory.

    Solution

    Setup and mass shell. From L=−m−x˙2L=-m\sqrt{-\dot x^2}L=−m−x˙2​ the momentum is pμ=∂L/∂x˙μ=mx˙μ/−x˙2p_\mu = \partial L/\partial\dot x^\mu = m\dot x_\mu/\sqrt{-\dot x^2}pμ​=∂L/∂x˙μ=mx˙μ​/−x˙2​. Squaring and contracting kills the parameterization: p2=m2x˙2/(−x˙2)=−m2p^2 = m^2\dot x^2/(-\dot x^2) = -m^2p2=m2x˙2/(−x˙2)=−m2, i.e. p2+m2=0,p^2 + m^2 = 0,p2+m2=0, the mass shell, true in any parameterization.

    Gauge fixes the dynamics. The gauge x+=p+τ/m2x^+ = p^+\tau/m^2x+=p+τ/m2 means x˙+=p+/m2\dot x^+ = p^+/m^2x˙+=p+/m2 (p+p^+p+ is conserved). Feed this into the +++ component of the momentum, with the index raised: p+=m x˙+−x˙2=1−x˙2p+m.p^+ = \frac{m\,\dot x^+}{\sqrt{-\dot x^2}} = \frac{1}{\sqrt{-\dot x^2}}\frac{p^+}{m}.p+=−x˙2​mx˙+​=−x˙2​1​mp+​. Cancel p+p^+p+: −x˙2=1/m\sqrt{-\dot x^2}=1/m−x˙2​=1/m, i.e. x˙2=−1/m2\dot x^2 = -1/m^2x˙2=−1/m2, and pμ=m2x˙μp_\mu = m^2\dot x_\mupμ​=m2x˙μ​ — the square-root nonlinearity is gone.

    Solve the mass shell for p−p^-p−. In light-cone components (with η+−=−1\eta^{+-}=-1η+−=−1, transverse part Euclidean) p2=−2p+p−+pIpIp^2 = -2p^+p^- + p^Ip^Ip2=−2p+p−+pIpI, so p2+m2=0p^2+m^2=0p2+m2=0 becomes −2p+p−+pIpI+m2=0⟹p−=12p+(pIpI+m2).-2p^+p^- + p^Ip^I + m^2 = 0 \quad\Longrightarrow\quad p^- = \frac{1}{2p^+}\big(p^Ip^I + m^2\big).−2p+p−+pIpI+m2=0⟹p−=2p+1​(pIpI+m2). p−p^-p− is now a derived quantity — no independent longitudinal energy survives.

    From p−p^-p− to HHH. Light-cone energy p−p^-p− generates x+x^+x+-translations, but we evolve in τ\tauτ, and the gauge ties them by ∂τ=(p+/m2) ∂x+\partial_\tau = (p^+/m^2)\,\partial_{x^+}∂τ​=(p+/m2)∂x+​. Hence H=p+m2 p−=12m2(pIpI+m2),H = \frac{p^+}{m^2}\,p^- = \frac{1}{2m^2}\big(p^Ip^I + m^2\big),H=m2p+​p−=2m21​(pIpI+m2), the two factors of p+p^+p+ canceling. This is result (1)(1)(1).

    Why HHH is the mass shell. HHH was built by solving p2+m2=0p^2+m^2=0p2+m2=0 for p−p^-p− and multiplying by the gauge factor p+/m2p^+/m^2p+/m2; nothing else went in. So 2m2H−pIpI=m22m^2 H - p^Ip^I = m^22m2H−pIpI=m2 is just the on-shell statement that the invariant mass is mmm. The Hamiltonian never imposes the constraint separately — it is the constraint, already solved.
