    Painting a "which brane?" label on each open-string endpoint turns the single photon on one brane into a whole matrix of gauge fields on a stack — and that matrix is exactly a U(N) gauge field.

    Endpoints as nodes and edges

    An open string on a stack of NNN branes is a directed arrow between two nodes. Its tail (the σ=0\sigma=0σ=0 end) sits on some brane iii; its head (the σ=π\sigma=\piσ=π end) sits on some brane jjj. The pair (i,j)(i,j)(i,j) — which brane at each end — is the only new information a stack adds, on top of the oscillators the string already carried on a single brane.

    Two consequences follow at once. Give the tail a row index and the head a column index: a string becomes a matrix entry, and a general state is an N×NN\times NN×N matrix of amplitudes, so the one photon of a single brane becomes N2N^2N2 of them. And two open strings fuse only by gluing the head of one to the tail of the other, which is allowed just when the two touching ends sit on the same brane — the exact rule that makes matrices multiply. The endpoint bookkeeping is matrix algebra.

    So the gauge group is the geometry of the stack. NNN separated branes see U(1)NU(1)^NU(1)N; slide them onto each other and the off-diagonal arrows go massless, fusing the NNN photons into one U(N)U(N)U(N) gauge field. Gauge symmetry enhancement is just branes touching.

    These labels are the Chan–Paton factors, introduced in the 1960s as a formal trick to get gauge symmetry out of open strings, long before anyone knew they meant "which brane."

    Endpoint labels as matrix indices

    On a single D-brane an oriented open string carries nothing beyond its oscillator state. On NNN coincident branes each of the two endpoints can land on any brane, so the ground state gains a discrete label:

    ∣ oscillators;i,j ⟩,i,j=1,…,N,|\,\text{oscillators}; i,j\,\rangle,\qquad i,j=1,\dots,N,∣oscillators;i,j⟩,i,j=1,…,N,

    with iii the brane at σ=0\sigma=0σ=0 and jjj the brane at σ=π\sigma=\piσ=π. There are N2N^2N2 such sectors — N2N^2N2 copies of the entire single-brane spectrum.

    With two labels, each running 1,…,N1,\dots,N1,…,N, the natural object is an N×NN\times NN×N matrix. Model the state (i,j)(i,j)(i,j) by the matrix unit EijE_{ij}Eij​: a 111 in row iii, column jjj, zeros elsewhere. A general open-string state is then a superposition

    ∑i,j=1Nλij ∣ oscillators;i,j ⟩,\sum_{i,j=1}^N \lambda^i{}_j\,|\,\text{oscillators}; i,j\,\rangle,i,j=1∑N​λij​∣oscillators;i,j⟩,

    whose coefficients λij\lambda^i{}_jλij​ form an N×NN\times NN×N matrix — the Chan–Paton matrix of the state. The row index comes from the tail, the column index from the head.

    Why joining strings is matrix multiplication

    Two open strings interact by gluing an endpoint of one to an endpoint of the other. Concretely, the head (σ=π\sigma=\piσ=π) of the first joins the tail (σ=0\sigma=0σ=0) of the second; the join point stops being an endpoint, leaving a single longer string. This is only geometrically possible if the two touching ends lie on the same brane. Writing the sector-joining rule for strings [ij][ij][ij] (from brane iii to jjj) and [jk][jk][jk]:

    [ij]∗[jk]=[ik](j not summed).(1)[ij]\ast[jk]=[ik]\qquad(j\ \text{not summed}). \tag{1}[ij]∗[jk]=[ik](j not summed).(1)

    The head-brane of the first must equal the tail-brane of the second, and the survivor runs from iii to kkk. In matrix-unit form this is exactly

    EijEkl=δjk Eil.(2)E_{ij}E_{kl}=\delta_{jk}\,E_{il}. \tag{2}Eij​Ekl​=δjk​Eil​.(2)

    The Kronecker δjk\delta_{jk}δjk​ enforces "the end of the first must match the start of the second" — no shared brane, no fusion. That delta is the whole reason endpoint labels obey matrix algebra, and it is not an analogy: the string interaction literally multiplies Chan–Paton matrices.

    From N2N^2N2 photons to a U(N)U(N)U(N) gauge field

    On a single brane the massless level-1 vector is one photon AmA_mAm​, an abelian U(1)U(1)U(1) field on the (p+1)(p+1)(p+1)-dimensional world-volume (m=0,…,pm=0,\dots,pm=0,…,p). On the stack that state acquires the endpoint labels, giving N2N^2N2 massless vectors

    Amij,m=0,…,p,i,j=1,…,N.A_m{}^i{}_j,\qquad m=0,\dots,p,\quad i,j=1,\dots,N.Am​ij​,m=0,…,p,i,j=1,…,N.

    Here mmm is a genuine world-volume Lorentz index; the pair (i,j)(i,j)(i,j) is an internal matrix index. So AmA_mAm​ is now a matrix-valued gauge field: one matrix per world-volume direction.

    One constraint fixes which matrices appear. Reversing a string's orientation swaps its two ends, sending the sector [ij]→[ji][ij]\to[ji][ij]→[ji]; demanding a unitary — hence physically sensible — theory ties the [ij][ij][ij] and [ji][ji][ji] amplitudes together as λ†=λ\lambda^\dagger=\lambdaλ†=λ. The Chan–Paton matrices are therefore Hermitian, which is precisely the Lie algebra u(N)\mathfrak u(N)u(N). The gauge group is U(N)U(N)U(N), the N×NN\times NN×N unitary matrices, whose group multiplication is matrix multiplication — the same operation as the joining rule (1). The massless vectors assemble into a non-abelian U(N)U(N)U(N) gauge field on the common world-volume; building the field strength from it is the job of Yang-Mills from D-branes.

    Separated branes: U(N)→U(1)NU(N)\to U(1)^NU(N)→U(1)N

    Slide the branes apart. A string from brane iii to brane jjj is now classically stretched over the gap Δxij=xˉj−xˉi\Delta x_{ij}=\bar x_j-\bar x_iΔxij​=xˉj​−xˉi​, and tension ×\times× length costs energy that shows up as mass:

    M2  ⊃  (∣Δxij∣2πα′)2.(3)M^2 \;\supset\; \left(\frac{|\Delta x_{ij}|}{2\pi\alpha'}\right)^2 . \tag{3}M2⊃(2πα′∣Δxij​∣​)2.(3)

    (Here 2πα′=1/T02\pi\alpha'=1/T_02πα′=1/T0​, so the term is (tension×length)2(\text{tension}\times\text{length})^2(tension×length)2, derived in Strings between parallel branes.) The off-diagonal vectors i≠ji\neq ji=j acquire this mass and drop out of the low-energy theory; only the diagonal strings i=ji=ji=j, with Δxii=0\Delta x_{ii}=0Δxii​=0, stay massless. Those NNN diagonal entries are NNN independent U(1)U(1)U(1) gauge fields:

    U(N) ⟶ U(1)N(branes separated).U(N)\ \longrightarrow\ U(1)^N \qquad(\text{branes separated}).U(N) ⟶ U(1)N(branes separated).

    Bring the branes back together and the stretched-length penalty vanishes: the off-diagonal vectors become massless again and the full U(N)U(N)U(N) is restored. This is a stringy Higgs mechanism — brane separation is the Higgs vev, and the stretched strings are the massive WWW-bosons it produces.

    The geometry–gauge dictionary in one table:

    brane configuration light endpoint labels gauge symmetry at low energy
    one brane one label [11][11][11] U(1)U(1)U(1)
    NNN separated branes only diagonal [ii][ii][ii] light U(1)NU(1)^NU(1)N
    NNN coincident branes all [ij][ij][ij] light U(N)U(N)U(N)

    Open questions

    • This is the spectrum-level origin of the labels. The full non-abelian interactions — vertex operators, amplitudes, the trace over Chan–Paton indices that makes amplitudes gauge-invariant — belong to a later open-string-interactions treatment.
    • Unoriented strings and orientifold projections reduce U(N)U(N)U(N) to SO(N)SO(N)SO(N) or Sp(N)Sp(N)Sp(N); that requires an orientation-reversal identification beyond this oriented bosonic pass.

    Exercise

    A stack of NNN coincident D-branes gives U(N)U(N)U(N), whose Lie algebra u(N)\mathfrak u(N)u(N) has N2N^2N2 generators — matching the N2N^2N2 endpoint sectors, one massless vector each. Now separate the NNN branes to NNN generic (all-distinct) positions. Using only the mass rule (3), count how many vectors stay massless, and identify the unbroken gauge group and the number of massive vectors. Confirm the massless count equals the number of U(1)U(1)U(1) factors, and check the arithmetic against dim⁡U(N)=N2\dim U(N)=N^2dimU(N)=N2.

    Solution

    A vector in sector [ij][ij][ij] is massless iff its stretched length vanishes, i.e. Δxij=xˉj−xˉi=0\Delta x_{ij}=\bar x_j-\bar x_i=0Δxij​=xˉj​−xˉi​=0. With all NNN positions distinct, this holds only for i=ji=ji=j: the NNN diagonal sectors [ii][ii][ii] stay massless, and all N2−N=N(N−1)N^2-N=N(N-1)N2−N=N(N−1) off-diagonal sectors become massive.

    The NNN surviving diagonal vectors are NNN mutually commuting U(1)U(1)U(1) gauge fields (each is a single brane's own photon), so the unbroken group is U(1)N,dim⁡=N.U(1)^N,\qquad \dim = N.U(1)N,dim=N. The massless count NNN equals the number of U(1)U(1)U(1) factors ✓\checkmark✓.

    Arithmetic check: the N2N^2N2 generators of U(N)U(N)U(N) split as N⏟Cartan / diagonal, unbroken  +  N(N−1)⏟off-diagonal, now massive  =  N2.\underbrace{N}_{\text{Cartan / diagonal, unbroken}}\;+\;\underbrace{N(N-1)}_{\text{off-diagonal, now massive}}\;=\;N^2.Cartan / diagonal, unbrokenN​​+off-diagonal, now massiveN(N−1)​​=N2. The off-diagonal generators are the root directions of U(N)U(N)U(N), and breaking down to the diagonal torus U(1)NU(1)^NU(1)N is exactly what makes them massive — the stringy Higgs mechanism, with the N(N−1)N(N-1)N(N−1) stretched strings as its massive WWW-bosons. For N=2N=2N=2: 4=2+24=2+24=2+2, so U(2)U(2)U(2) breaks to U(1)2U(1)^2U(1)2 with 222 massive off-diagonal vectors.
