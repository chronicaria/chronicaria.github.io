<h2 id="length-belongs-to-the-road-not-the-milestones">Length belongs to the road, not the milestones</h2>
<p>Think of a road on a map. Its length is a property of the <em>road</em>. You can plant milestone markers along it however you like — every meter, every mile, bunched up here, spread out there — and when you add up the distances between markers you always get the same total. Where you paint the markers is bookkeeping; the road doesn't care.</p>
<p>A <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/proper-time-action/" class="wiki-link">worldline</a> is that road, drawn in spacetime, and its "length" is <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/proper-length-and-proper-time/" class="wiki-link">proper time</a>. The parameter <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>τ</mi></mrow><annotation encoding="application/x-tex">\tau</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.4306em;"></span><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span></span></span></span> is where you paint the markers. So the action <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>S</mi><mo>=</mo><mo>−</mo><mi>m</mi><mi>c</mi><mo>∫</mo><mi>d</mi><mi>s</mi></mrow><annotation encoding="application/x-tex">S=-mc\int ds</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord mathnormal" style="margin-right:0.0576em;">S</span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">=</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:1.1111em;vertical-align:-0.3061em;"></span><span class="mord">−</span><span class="mord mathnormal">m</span><span class="mord mathnormal">c</span><span class="mspace" style="margin-right:0.1667em;"></span><span class="mop op-symbol small-op" style="margin-right:0.1945em;position:relative;top:-0.0006em;">∫</span><span class="mspace" style="margin-right:0.1667em;"></span><span class="mord mathnormal">d</span><span class="mord mathnormal">s</span></span></span></span> — which is <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mo>−</mo><mi>m</mi><mi>c</mi></mrow><annotation encoding="application/x-tex">-mc</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6667em;vertical-align:-0.0833em;"></span><span class="mord">−</span><span class="mord mathnormal">m</span><span class="mord mathnormal">c</span></span></span></span> times that length — must come out the same no matter which parameter you use. That is <em>reparameterization invariance</em>, and it holds for one reason: the integrand is <strong>homogeneous of degree one</strong> in the velocities.</p>
<p>The parameter was never physical, so it cannot change the physics. That single sentence is why the next note can <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/gauge-choices-for-the-worldline-parameter/" class="wiki-link">choose a convenient parameter</a> and lose nothing.</p>

<h2 id="why-this-matters">Why this matters</h2>
<ol>
<li>
<p><strong>It is a redundancy, not a symmetry.</strong> A Lorentz boost relates the descriptions of two <em>different</em> observers, both physical. A reparameterization relates one geometric curve to <em>itself</em>, written with a different label — an equivalence between descriptions, carrying no new physical motion. This is the freedom we spend next by making a <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/gauge-choices-for-the-worldline-parameter/" class="wiki-link">gauge choice</a>.</p>
</li>
<li>
<p><strong>The equation of motion must be parameter-blind.</strong> Varying the action gives <span class="katex"><span class="katex-mathml"><math <h2 id="open-questions">Open questions</h2>
<ul>
<li>Reparameterization invariance is the origin of a <em>constraint</em> in the Hamiltonian formulation: the Hamiltonian of a purely geometric action vanishes identically. Not developed here; flagged for the string constraints later.</li>
<li>The two-parameter worldsheet version replaces the one-variable Jacobian with a Jacobian <em>determinant</em>; Module 09 (<a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/09-nambu-goto-worldsheet-geometry/nambu-goto-action/" class="wiki-link">Nambu–Goto action</a>) supplies the details.</li>
</ul>
