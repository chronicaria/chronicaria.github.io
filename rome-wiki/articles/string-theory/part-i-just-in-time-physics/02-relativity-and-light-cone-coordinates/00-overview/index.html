    02 — Relativity and Light-Cone Coordinates (Overview)

    Aligning coordinates with light rays turns the mass shell — the one equation every relativistic object must obey — from a square root into a division. Compactifying one spatial direction then makes momentum discrete.

    Trading the square root for a division

    Every relativistic particle carries a four-momentum pμ=(E/c,p⃗)p^\mu = (E/c, \vec p)pμ=(E/c,p​), and its squared Minkowski length is pinned by the rest mass (mostly-plus signature):

    p⋅p=−m2c2.p\cdot p = -m^2c^2.p⋅p=−m2c2.

    This is a constraint, not a force law — it does not say how ppp evolves, only which momenta are allowed. Solved for the energy in ordinary coordinates it gives E=cp⃗ 2+m2c2E = c\sqrt{\vec p^{\,2} + m^2c^2}E=cp​2+m2c2​, a square root; after quantization that square root becomes an awkward operator, and string theory dodges it with a coordinate trick.

    The trick: instead of measuring time along the vertical axis, measure it along a light ray. Define x±=(x0±x1)/2x^\pm = (x^0 \pm x^1)/\sqrt2x±=(x0±x1)/2​ — the two 45∘45^\circ45∘ null directions in the time/x1x^1x1 plane. In this skewed frame the time–space block of the Minkowski quadratic form has no diagonal (x+)2(x^+)^2(x+)2 or (x−)2(x^-)^2(x−)2 term at all: it is the pure cross-term −2 x+x−-2\,x^+x^-−2x+x−, and the transverse directions ride along unchanged. The mass shell becomes

    −2 p+p−+pT2=−m2c2,-2\,p^+p^- + p_T^2 = -m^2c^2,−2p+p−+pT2​=−m2c2,

    with pT2=∑I(pI)2p_T^2 = \sum_I (p^I)^2pT2​=∑I​(pI)2 the squared momentum in the transverse directions I=2,…,D−1I = 2,\dots,D-1I=2,…,D−1 of DDD-dimensional spacetime (here D=4D=4D=4, so I=2,3I = 2,3I=2,3). The light-cone energy p−p^-p− appears only to the first power, so no square root — divide:

     p−=pT2+m2c22p+ .\boxed{\,p^- = \frac{p_T^2 + m^2c^2}{2p^+}\,}.p−=2p+pT2​+m2c2​​.

    That single algebraic fact is the reason light-cone coordinates exist. Light-cone string quantization is tractable because it repeats this finite-dimensional move across infinitely many oscillator modes at once: the string's energy becomes an oscillator expression divided by 2p+2p^+2p+, and only the transverse directions stay dynamical.

    The same thing happens for a plain hyperbola. Solving y2−x2=ky^2 - x^2 = ky2−x2=k for yyy needs a square root; in the null variables u=(y+x)/2u = (y+x)/\sqrt2u=(y+x)/2​, v=(y−x)/2v = (y-x)/\sqrt2v=(y−x)/2​ the curve reads 2uv=k2uv = k2uv=k, solved by one division, v=k/(2u)v = k/(2u)v=k/(2u). Same curve, better axes — and the mass shell is exactly this hyperbola, one dimension up.

    The four moving parts

    Each becomes its own note; here is why each exists and how it feeds the next.

    1. 2.1 Minkowski metric and the mass shell — the indefinite geometry itself. Time and space enter the interval with opposite signs, −ds2=−(dx0)2+(dxi)2-ds^2 = -(dx^0)^2 + (dx^i)^2−ds2=−(dx0)2+(dxi)2, and feeding the four-momentum into that form yields p⋅p=−m2c2p\cdot p = -m^2c^2p⋅p=−m2c2. The mass shell is a Lorentz-invariant level set: all observers agree on mmm.
    2. 2.2 Light-cone coordinates — the skew change of basis x±=(x0±x1)/2x^\pm = (x^0\pm x^1)/\sqrt2x±=(x0±x1)/2​. The metric goes off-diagonal, η+−=η−+=−1\eta_{+-} = \eta_{-+} = -1η+−​=η−+​=−1, and index-lowering swaps the labels: a+=−a−a_+ = -a^-a+​=−a−. The quadratic form becomes bilinear in +++ and −-− instead of quadratic in either — the payoff set up here and cashed in next.
    3. 2.3 Solving the mass shell in light-cone coordinates — the payoff itself. Because η−−=0\eta_{--} = 0η−−​=0, the mass shell is linear in p−p^-p−, and p−=(pT2+m2c2)/(2p+)p^- = (p_T^2 + m^2c^2)/(2p^+)p−=(pT2​+m2c2)/(2p+) follows by pure algebra. One subtlety earns its own discussion there: the light-cone energy is p−p^-p−, not p+p^+p+, because x+x^+x+ is the light-cone time and its conjugate covariant component is p+=−p−p_+ = -p^-p+​=−p−.
    4. 2.4 Momentum quantization on a circle — an independent, quantum-mechanical thread. Curl one spatial direction into a circle S1=R/(2πR Z)S^1 = \mathbb{R}/(2\pi R\,\mathbb{Z})S1=R/(2πRZ); single-valuedness of the wavefunction then forces p=ℏn/Rp = \hbar n/Rp=ℏn/R, n∈Zn\in\mathbb{Z}n∈Z. Continuous translation symmetry survives, but the global condition "go once around = identity" allows only integer modes — the seed of Kaluza–Klein towers and, later, string winding.

    The spine connecting them: notes 1–3 are one idea in two coordinate systems — the mass shell, first as invariant geometry, then re-expressed so it is trivially solvable. Note 4 stands apart as the mechanism by which compactness discretizes momentum, included because the same relativistic four-momentum reappears there as a mass tower mn2=M2+ℏ2n2/(c2R2)m_n^2 = M^2 + \hbar^2 n^2/(c^2R^2)mn2​=M2+ℏ2n2/(c2R2).

    Two conventions to lock in now, because everything downstream leans on them:

    • Mostly-plus signature (−,+,+,+)(-,+,+,+)(−,+,+,+) throughout, so p2=−m2c2p^2 = -m^2c^2p2=−m2c2. Many particle-physics texts use mostly-minus, which flips the sign; always check before importing a formula.
    • Never lower ±\pm± indices without writing the sign swap explicitly. Keep them up; the energy is always p−p^-p−.

    Nothing here needs physics beyond special relativity's energy-momentum relation and a plane wave eipx/ℏe^{ipx/\hbar}eipx/ℏ. Everything else is derived in place.

    Open questions

    • Later chapters set c=1c=1c=1 and often ℏ=1\hbar=1ℏ=1; track which constants have been suppressed so nonrelativistic comparisons still make sense.
    • Light-cone gauge will assume p+≠0p^+\neq 0p+=0. The excluded case is a massless particle moving exactly along the −x1-x^1−x1 null ray, where p+=0p^+ = 0p+=0 and the division above breaks — revisit why that sector is safely dropped.
    • For strings, winding modes add energy ∝R\propto R∝R, competing with the momentum tower's ∝1/R\propto 1/R∝1/R. That tension is T-duality, deferred until the string spectrum exists.

    Exercise

    Close every note and work on a blank page; the two parts are the module's two core results — the square-root-free energy and the discreteness mechanism.

    1. Starting from p⋅p=−m2c2p\cdot p = -m^2c^2p⋅p=−m2c2, use the light-cone scalar product to solve for p−p^-p− in terms of p+p^+p+, the transverse momenta pIp^IpI (I=2,…,D−1I = 2,\dots,D-1I=2,…,D−1), and m2m^2m2. Identify exactly where the factor of 222 enters and explain, in one sentence, why no square root appears.
    2. Starting from the identification x∼x+2πRx \sim x + 2\pi Rx∼x+2πR, impose single-valuedness on a plane wave eipx/ℏe^{ipx/\hbar}eipx/ℏ and derive p=ℏn/Rp = \hbar n/Rp=ℏn/R, n∈Zn\in\mathbb{Z}n∈Z. Name the exact global condition that forces discreteness.
    Solution

    Part 1. The light-cone self-product of the momentum is p⋅p=−2 p+p−+pT2,pT2≡∑I=2D−1(pI)2.p\cdot p = -2\,p^+p^- + p_T^2, \qquad p_T^2 \equiv \sum_{I=2}^{D-1}(p^I)^2.p⋅p=−2p+p−+pT2​,pT2​≡∑I=2D−1​(pI)2. The factor of 222 comes from the two off-diagonal metric entries η+−=η−+=−1\eta_{+-} = \eta_{-+} = -1η+−​=η−+​=−1, which both multiply p+p−p^+p^-p+p− and add. Setting this equal to −m2c2-m^2c^2−m2c2: −2 p+p−+pT2=−m2c2  ⟹  2 p+p−=pT2+m2c2  ⟹   p−=pT2+m2c22p+ .-2\,p^+p^- + p_T^2 = -m^2c^2 \;\Longrightarrow\; 2\,p^+p^- = p_T^2 + m^2c^2 \;\Longrightarrow\; \boxed{\,p^- = \frac{p_T^2 + m^2c^2}{2p^+}\,}.−2p+p−+pT2​=−m2c2⟹2p+p−=pT2​+m2c2⟹p−=2p+pT2​+m2c2​​. No square root appears because η−−=0\eta_{--} = 0η−−​=0: the mass shell has no (p−)2(p^-)^2(p−)2 term, so it is linear in p−p^-p−, and a linear equation is solved by one division (valid whenever p+≠0p^+\neq 0p+=0). Sanity check: a particle boosted hard along +x1+x^1+x1 with pT=0p_T = 0pT​=0 has p0=(p1)2+m2c2≃p1+m2c22p1p^0 = \sqrt{(p^1)^2 + m^2c^2} \simeq p^1 + \frac{m^2c^2}{2p^1}p0=(p1)2+m2c2​≃p1+2p1m2c2​, so p+=p0+p12≃2 p1p^+ = \frac{p^0+p^1}{\sqrt2} \simeq \sqrt2\,p^1p+=2​p0+p1​≃2​p1 and p−=p0−p12≃m2c222 p1p^- = \frac{p^0-p^1}{\sqrt2} \simeq \frac{m^2c^2}{2\sqrt2\,p^1}p−=2​p0−p1​≃22​p1m2c2​ — exactly the boxed formula's m2c2/(2p+)m^2c^2/(2p^+)m2c2/(2p+) at p+=2 p1p^+ = \sqrt2\,p^1p+=2​p1. ✓\checkmark✓

    Part 2. A momentum eigenstate along the compact direction is ψ(x)=eipx/ℏ\psi(x) = e^{ipx/\hbar}ψ(x)=eipx/ℏ. Because xxx and x+2πRx + 2\pi Rx+2πR name the same point on the circle, ψ\psiψ must return to itself after one loop: ψ(x+2πR)=ψ(x)  ⟹  eip(2πR)/ℏ=1.\psi(x + 2\pi R) = \psi(x) \;\Longrightarrow\; e^{ip(2\pi R)/\hbar} = 1.ψ(x+2πR)=ψ(x)⟹eip(2πR)/ℏ=1. A complex exponential equals 111 iff its phase is an integer multiple of 2π2\pi2π: p (2πR)ℏ=2πn,  n∈Z  ⟹   p=ℏnR .\frac{p\,(2\pi R)}{\hbar} = 2\pi n, \; n\in\mathbb{Z} \;\Longrightarrow\; \boxed{\,p = \frac{\hbar n}{R}\,}.ℏp(2πR)​=2πn,n∈Z⟹p=Rℏn​​. The exact global condition is single-valuedness of the wavefunction under the identification x∼x+2πRx\sim x+2\pi Rx∼x+2πR — the 2π2\pi2π's cancel, so the answer is ℏn/R\hbar n/Rℏn/R (radius RRR), not 2πℏn/R2\pi\hbar n/R2πℏn/R. The integer nnn counts phase windings per trip around the circle.
