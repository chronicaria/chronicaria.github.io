3:T283fa,<p>You count a point charge by <em>enclosing</em> it in a sphere and measuring the flux out; you count a string by <em>linking</em> it with a loop and measuring the circulation around. <p>So the string is a wire carrying current down its length, not a smear of static charge sitting on it. A divergenceless current has nowhere to dump itself; like an incompressible flow, its lines cannot terminate. A real current-carrying wire either closes into a loop or runs off to infinity, and the string inherits the same constraint, before D-branes enter:</p>
<blockquote>
<p>String-charge conservation forces every string to be a closed loop or infinitely long.</p>
</blockquote>
<p>A string that simply <em>ended</em> in empty space would be a current that stops: the flow lines would have a source or sink at the endpoint, violating (1). A string <em>can</em> end on a D-brane, but only because electric flux on the brane picks up the current where the string drops it, the resolution in <a href="/rome-wiki/articles/string-theory/part-iv-branes-and-duality/19-string-charge-and-gauge-fields/endpoint-charge/" class="wiki-link">Endpoint charge</a>.</p>

<p>The last two rows carry the whole content: <strong>enclosing a point and linking a line are the same topological statement, shifted up one dimension in the charged object.</strong> A point charge is trapped inside a codimension-one sphere; a string is trapped inside a loop threaded around it. This is why the string is the honest one-dimensional generalization of a charged particle, and why its natural gauge field carries one extra index. Measure a particle by the flux it pushes <em>out</em>; measure a string by the field that swirls <em>around</em>.</p>
