6:T259c7,<h2 id="a-blank-ruler-along-the-worldline">A blank ruler along the worldline</h2>
<p>The worldline is a curve in spacetime — a set of points, a bare wire. To describe it we lay a ruler alongside it and read off <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><msup><mi>x</mi><mi>μ</mi></msup><mo stretchy="false">(</mo><mi>τ</mi><mo stretchy="false">)</mo></mrow><annotation encoding="application/x-tex">x^\mu(\tau)</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:1em;vertical-align:-0.25em;"></span><span class="mord"><span class="mord mathnormal">x</span><span class="msupsub"><span class="vlist-t"><span class="vlist-r"><span class="vlist" style="height:0.6644em;"><span style="top:-3.063em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mathnormal mtight">μ</span></span></span></span></span></span></span></span><span class="mopen">(</span><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="mclose">)</span></span></span></span>. But the ruler starts <em>blank</em>: <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/reparameterization-invariance/" class="wiki-link">reparameterization invariance</a> says any smooth monotone relabeling <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>τ</mi><mo>→</mo><mi>f</mi><mo stretchy="false">(</mo><mi>τ</mi><mo stretchy="false">)</mo></mrow><annotation encoding="application/x-tex">\tau\to f(\tau)</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.4306em;"></span><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">→</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:1em;vertical-align:-0.25em;"></span><span class="mord mathnormal" style="margin-right:0.1076em;">f</span><span class="mopen">(</span><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="mclose">)</span></span></span></span> gives the same curve, the same action, the same physics. We get to paint the tick marks wherever we like. That freedom is a <em>gauge redundancy</em>, not a symmetry: a symmetry relates different physical situations (a boost relates two observers), a redundancy relates two <em>descriptions of the same situation</em>. Fixing a gauge just picks one representative from the equivalence class of relabelings — it deletes bookkeeping, never physics.</p>
<p>In applied-math terms: the physical object is the equivalence class of parameterized curves under precomposition with a monotone bijection, and a gauge condition is a rule that selects one representative, at least locally.</p>
<p>For a point particle this is a luxury — the <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/free-particle-equation-of-motion/" class="wiki-link">Free particle equation of motion</a> is already trivial. For the <em>string</em> it is survival: the <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/09-nambu-goto-worldsheet-geometry/nambu-goto-action/" class="wiki-link">Nambu-Goto action</a> is intractable until we spend the reparameterization freedom, all the way to the <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/12-classical-light-cone-gauge/light-cone-gauge/" class="wiki-link">Light-cone gauge</a> on which quantization is built. The point particle is the rehearsal, where each move is visible with one dimension instead of two.</p>
<p><strong>Legal ruler.</strong> A relabeling must stay one-to-one along the curve, so <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>d</mi><msup><mi>τ</mi><mo mathvariant="normal" lspace="0em" rspace="0em">′</mo></msup><mi mathvariant="normal">/</mi><mi>d</mi><mi>τ</mi><mo mathvariant="normal">≠</mo><mn>0</mn></mrow><annotation encoding="application/x-tex">d\tau'/d\tau\neq 0</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:1.0019em;vertical-align:-0.25em;"></span><span class="mord mathnormal">d</span><span class="mord"><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="msupsub"><span class="vlist-t"><span class="vlist-r"><span class="vlist" style="height:0.7519em;"><span style="top:-3.063em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mtight"><span class="mord mtight">′</span></span></span></span></span></span></span></span></span><span class="mord">/</span><span class="mord mathnormal">d</span><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel"><span class="mrel"><span class="mord vbox"><span class="thinbox"><span class="rlap"><span class="strut" style="height:0.8889em;vertical-align:-0.1944em;"></span><span class="inner"><span class="mord"><span class="mrel"></span></span></span><span class="fix"></span></span></span></span></span><span class="mspace nobreak"></span><span class="mrel">=</span></span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.6444em;"></span><span class="mord">0</span></span></span></span>; we take it strictly increasing, <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>d</mi><msup><mi>τ</mi><mo mathvariant="normal" lspace="0em" rspace="0em">′</mo></msup><mi mathvariant="normal">/</mi><mi>d</mi><mi>τ</mi><mo>></mo><mn>0</mn></mrow><annotation encoding="application/x-tex">d\tau'/d\tau>0</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:1.0019em;vertical-align:-0.25em;"></span><span class="mord mathnormal">d</span><span class="mord"><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="msupsub"><span class="vlist-t"><span class="vlist-r"><span class="vlist" style="height:0.7519em;"><span style="top:-3.063em;margin-right:0.05em;"><span class="pstrut" style="height:2.7em;"></span><span class="sizing reset-size6 size3 mtight"><span class="mord mtight"><span class="mord mtight">′</span></span></span></span></span></span></span></span></span><span class="mord">/</span><span class="mord mathnormal">d</span><span class="mord mathnormal" style="margin-right:0.1132em;">τ</span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">></span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.6444em;"></span><span class="mord">0</span></span></span></span>, so the parameter still runs from the initial endpoint to the final one.</p>
<p>Below, the same freedom is spent three ways. Read each as: <em>what did we set the ruler to, and what did that buy us?</em></p>

<p>Every row spends the <em>same</em> freedom — the reparameterization redundancy — and buys a different simplification. No row changes the physics; that is guaranteed by <a href="/rome-wiki/articles/string-theory/part-ii-classical-strings/08-relativistic-point-particle/reparameterization-invariance/" class="wiki-link">Reparameterization invariance</a>. The parameter is a blank ruler, and a gauge choice is a decision about where to paint the marks so the equation you care about looks simplest.</p>
