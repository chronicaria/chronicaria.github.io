18:T148e4,<h2 id="no-interaction-point">No interaction point</h2>
<p>A point particle traces a <strong>worldline</strong>; when two of them meet, you get a new local object — a <strong>vertex</strong>, a kink where lines cross. That kink is where you write the coupling constant.</p>
<p>A string traces a <strong>worldsheet</strong> — the history is already two-dimensional. So when strings join or split, nothing new is glued on. You just <em>bend the same surface</em>: a tube smoothly branches into two tubes, like a pair of trousers. Zoom in anywhere on that surface — even right at the crotch — and it looks exactly like a free string propagating. <strong>There is no interaction point.</strong> The interaction is a global fact about the surface's shape, not a local event you can put your finger on.</p>
<p>That single observation drives the whole module. If there is no vertex, there is no place to attach a coupling and no point to sum over. What replaces "sum over vertices"? <strong>Integrate over the shapes of the surface.</strong> The four moves below are just this idea made precise.</p>
<h2 id="the-four-moves-of-this-module">The four moves of this module</h2>
<ol>
<li>
<p><strong>One surface, not a graph.</strong> A join/split is a single smooth worldsheet. Locally free everywhere; the interaction lives only in the global topology and shape. → 24.1 <a href="/rome-wiki/articles/string-theory/part-v-graduate-bridge/24-interactions-and-riemann-surfaces/splitting-and-joining-worldsheets/" class="wiki-link">Splitting and joining worldsheets</a></p>
</li>
<li>
<p><strong>Shape, not size.</strong> The string action is invariant under Weyl rescaling, so lengths on the worldsheet are unphysical — only the <em>conformal</em> (angle-preserving, complex-analytic) structure matters. The worldsheet is therefore a <strong>Riemann surface</strong>. Under a conformal map to a bounded region, each semi-infinite external string shrinks to a single boundary point that is never actually reached — a <strong>puncture</strong>. External strings are punctures, not legs. → 24.2 <a href="/rome-wiki/articles/string-theory/part-v-graduate-bridge/24-interactions-and-riemann-surfaces/riemann-surfaces-replace-feynman-graphs/" class="wiki-link">Riemann surfaces replace Feynman graphs</a></p>
</li>
<li>
<p><strong>Fix what you can for free; integrate the rest.</strong> At fixed topology, two punctured surfaces are "the same" if a conformal automorphism maps one to the other. That automorphism group — the <strong>conformal Killing group</strong> (<span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>P</mi><mi>S</mi><mi>L</mi><mo stretchy="false">(</mo><mn>2</mn><mo separator="true">,</mo><mi mathvariant="double-struck">C</mi><mo stretchy="false">)</mo></mrow><annotation encoding="application/x-tex">PSL(2,\mathbb{C})</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:1em;vertical-align:-0.25em;"></span><span class="mord mathnormal" style="margin-right:0.1389em;">P</span><span class="mord mathnormal" style="margin-right:0.0576em;">S</span><span class="mord mathnormal">L</span><span class="mopen">(</span><span class="mord">2</span><span class="mpunct">,</span><span class="mspace" style="margin-right:0.1667em;"></span><span class="mord mathbb">C</span><span class="mclose">)</span></span></span></span> for the sphere, <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>P</mi><mi>S</mi><mi>L</mi><mo stretchy="false">(</mo><mn>2</mn><mo separator="true">,</mo><mi mathvariant="double-struck">R</mi><mo stretchy="false">)</mo></mrow><annotation encoding="application/x-tex">PSL(2,\mathbb{R})</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:1em;vertical-align:-0.25em;"></span><span class="mord mathnormal" style="margin-right:0.1389em;">P</span><span class="mord mathnormal" style="margin-right:0.0576em;">S</span><span class="mord mathnormal">L</span><span class="mopen">(</span><span class="mord">2</span><span class="mpunct">,</span><span class="mspace" style="margin-right:0.1667em;"></span><span class="mord mathbb">R</span><span class="mclose">)</span></span></span></span> for the disk) — lets you pin a few punctures to standard positions for free. Whatever coordinates survive are <strong>moduli</strong>, and they parametrize the <strong>moduli space</strong> of genuinely inequivalent shapes. → 24.3 <a href="/rome-wiki/articles/string-theory/part-v-graduate-bridge/24-interactions-and-riemann-surfaces/moduli-spaces/" class="wiki-link">Moduli spaces</a></p>
</li>
<li>
<p><strong>The amplitude is the moduli integral.</strong> Each inequivalent shape is one "path" from initial to final states, so summing paths = integrating over the moduli space. For four open strings the moduli space is one real interval, so the amplitude is a single integral</p>
</li>
</ol>
<p><span class="katex-error" title="ParseError: KaTeX parse error: \tag works only in display equations" style="color:#cc0000">A = g_o^2\int_0^1 d\lambda\ \lambda^{2\alpha' p_1\cdot p_2}\,(1-\lambda)^{2\alpha' p_2\cdot p_3}. \tag{1}</span></p>

<h2 id="why-this-is-the-bridge">Why this is the bridge</h2>
<p>This module is the step from <em>spectrum</em> (the free string's states) to <em>scattering</em> (how they collide). It is also where string theory's <strong>UV softness</strong> first peeks out: a region that looks like dangerous short-distance physics in one conformal frame can be re-drawn, by a conformal map, as harmless long-distance propagation in another. Doing amplitudes over moduli space, rather than over point vertices, is exactly what removes the point-particle UV blow-up. Loops just add handles to the surface; the same "integrate over shapes" logic carries over. → 24.6 <a href="/rome-wiki/articles/string-theory/part-v-graduate-bridge/24-interactions-and-riemann-surfaces/perturbative-string-expansion-by-topology/" class="wiki-link">Perturbative string expansion by topology</a></p>
