    Reparameterization invariance

    Relabeling the points of a worldline by any new increasing parameter leaves the action unchanged, because the action measures the curve's proper length (proper time), not the ruler we lay along it. The parameter is a redundancy of the description, not physics.

    Length belongs to the road, not the milestones

    Think of a road on a map. Its length is a property of the road. You can plant milestone markers along it however you like — every meter, every mile, bunched up here, spread out there — and when you add up the distances between markers you always get the same total. Where you paint the markers is bookkeeping; the road doesn't care.

    A worldline is that road, drawn in spacetime, and its "length" is proper time. The parameter τ\tauτ is where you paint the markers. So the action S=−mc∫dsS=-mc\int dsS=−mc∫ds — which is −mc-mc−mc times that length — must come out the same no matter which parameter you use. That is reparameterization invariance, and it holds for one reason: the integrand is homogeneous of degree one in the velocities.

    The parameter was never physical, so it cannot change the physics. That single sentence is why the next note can choose a convenient parameter and lose nothing.

    Setup: a parameterized worldline

    A worldline P\mathcal{P}P is a set of points — a curve in spacetime. Proper length ∫Pds\int_\mathcal{P} ds∫P​ds is intrinsic to that curve: chop P\mathcal{P}P into little pieces, add up dsdsds for each, and you never had to name a parameter at all.

    To actually compute, we describe the curve with a parameter τ\tauτ, strictly increasing from the initial point to the final point but otherwise arbitrary:

    xμ=xμ(τ),xiμ=xμ(τi),xfμ=xμ(τf).x^\mu = x^\mu(\tau), \qquad x_i^\mu = x^\mu(\tau_i),\quad x_f^\mu = x^\mu(\tau_f).xμ=xμ(τ),xiμ​=xμ(τi​),xfμ​=xμ(τf​).

    This is a map from an interval [τi,τf][\tau_i,\tau_f][τi​,τf​] into spacetime. Time itself, x0x^0x0, is now a function of τ\tauτ: we gave up the everyday habit of using time as the parameter precisely so that space and time enter on the same footing, which keeps the treatment manifestly Lorentz-covariant.

    Rewrite dsdsds using the parameter. With the mostly-plus metric η=diag(−,+,+,+)\eta=\mathrm{diag}(-,+,+,+)η=diag(−,+,+,+), a timelike displacement has ds2=−ημν dxμdxν>0ds^2 = -\eta_{\mu\nu}\,dx^\mu dx^\nu > 0ds2=−ημν​dxμdxν>0, so

    ds2=−ημνdxμdτdxνdτ (dτ)2,ds=−ημνdxμdτdxνdτ  dτ.ds^2 = -\eta_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau}\,(d\tau)^2, \qquad ds = \sqrt{-\eta_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau}}\;d\tau.ds2=−ημν​dτdxμ​dτdxν​(dτ)2,ds=−ημν​dτdxμ​dτdxν​​dτ.

    The action in explicit, parameter-dependent form:

    S = -mc\int_{\tau_i}^{\tau_f}\sqrt{-\eta_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau}}\;d\tau. \tag{1}

    Every symbol under the integral now refers to τ\tauτ; the claim is that the value of the integral does not.

    The derivation: invariance under τ→τ′\tau \to \tau'τ→τ′

    Switch to a new parameter τ′(τ)\tau'(\tau)τ′(τ) that is strictly increasing, so dτ′/dτ>0d\tau'/d\tau > 0dτ′/dτ>0. By the chain rule,

    dxμdτ=dxμdτ′dτ′dτ.\frac{dx^\mu}{d\tau} = \frac{dx^\mu}{d\tau'}\frac{d\tau'}{d\tau}.dτdxμ​=dτ′dxμ​dτdτ′​.

    The factor dτ′/dτd\tau'/d\taudτ′/dτ multiplies both velocities inside the square root, so it appears squared under the root and comes out as one power — positive, so no absolute value is needed:

    −ημνdxμdτdxνdτ=dτ′dτ−ημνdxμdτ′dxνdτ′.\sqrt{-\eta_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau}} = \frac{d\tau'}{d\tau}\sqrt{-\eta_{\mu\nu}\frac{dx^\mu}{d\tau'}\frac{dx^\nu}{d\tau'}}.−ημν​dτdxμ​dτdxν​​=dτdτ′​−ημν​dτ′dxμ​dτ′dxν​​.

    Put this back into (1). The leftover Jacobian recombines with the measure — dτ′dτ dτ=dτ′\dfrac{d\tau'}{d\tau}\,d\tau = d\tau'dτdτ′​dτ=dτ′ — and the same change of variables carries the limits τi,f→τi,f′\tau_{i,f}\to\tau'_{i,f}τi,f​→τi,f′​:

    S = -mc\int_{\tau_i}^{\tau_f}\sqrt{-\eta_{\mu\nu}\frac{dx^\mu}{d\tau'}\frac{dx^\nu}{d\tau'}}\;\underbrace{\frac{d\tau'}{d\tau}\,d\tau}_{=\,d\tau'} = -mc\int_{\tau'_i}^{\tau'_f}\sqrt{-\eta_{\mu\nu}\frac{dx^\mu}{d\tau'}\frac{dx^\nu}{d\tau'}}\;d\tau'. \tag{2}

    Equation (2) has exactly the same form as (1), only with every τ\tauτ replaced by τ′\tau'τ′, so SSS is unchanged. The check took two lines and used no equations of motion — the action is manifestly reparameterization invariant.

    The one fact that made it work. The integrand is a square root, hence homogeneous of degree one in the velocities x˙μ≡dxμ/dτ\dot x^\mu \equiv dx^\mu/d\taux˙μ≡dxμ/dτ: rescale all velocities by a common positive factor λ\lambdaλ and the integrand scales by exactly λ1\lambda^1λ1. Under τ→τ′\tau\to\tau'τ→τ′ the velocities pick up the common factor λ=dτ′/dτ\lambda = d\tau'/d\tauλ=dτ′/dτ, so:

    • degree-one homogeneity pulls one power of the Jacobian out of the root;
    • converting dτ→dτ′d\tau\to d\tau'dτ→dτ′ absorbs one power into the measure.

    They cancel exactly; any other degree fails (see the Exercise). The string will lean on the same cancellation: reparameterizing the two worldsheet coordinates pulls exactly one Jacobian determinant out of the Nambu–Goto action integrand, and the two-dimensional measure absorbs it.

    Why this matters

    1. It is a redundancy, not a symmetry. A Lorentz boost relates the descriptions of two different observers, both physical. A reparameterization relates one geometric curve to itself, written with a different label — an equivalence between descriptions, carrying no new physical motion. This is the freedom we spend next by making a gauge choice.

    2. The equation of motion must be parameter-blind. Varying the action gives dpμ/dτ=0dp_\mu/d\tau = 0dpμ​/dτ=0 for arbitrary τ\tauτ — see Free particle equation of motion. "The four-momentum is constant along the curve" cannot depend on which ruler we chose, and indeed it doesn't.

    One subtlety on orientation. If τ′(τ)\tau'(\tau)τ′(τ) decreases (dτ′/dτ<0d\tau'/d\tau<0dτ′/dτ<0), the factor leaving the root is ∣dτ′/dτ∣|d\tau'/d\tau|∣dτ′/dτ∣, and the new parameter would run from the final endpoint back to the initial one. The geometric length is still the same, but for a variational problem with a fixed initial-to-final orientation it is cleanest to restrict to strictly increasing reparameterizations, which is what we did above.

    Open questions

    • Reparameterization invariance is the origin of a constraint in the Hamiltonian formulation: the Hamiltonian of a purely geometric action vanishes identically. Not developed here; flagged for the string constraints later.
    • The two-parameter worldsheet version replaces the one-variable Jacobian with a Jacobian determinant; Module 09 (Nambu–Goto action) supplies the details.

    Exercise

    The proof above hinged on the integrand being homogeneous of degree one. Test that this is really the load-bearing property by trying the "wrong" power. Consider the alternative action

    S~=∫τiτf(−ημνdxμdτdxνdτ) dτ,\tilde S = \int_{\tau_i}^{\tau_f}\Big(-\eta_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau}\Big)\,d\tau,S~=∫τi​τf​​(−ημν​dτdxμ​dτdxν​)dτ,

    whose integrand (no square root) is homogeneous of degree two in the velocities. Reparameterize τ→τ′\tau\to\tau'τ→τ′ with τ′\tau'τ′ strictly increasing and show that S~\tilde SS~ is not reparameterization invariant. What is the extra factor that fails to cancel, and what does it mean physically that S~\tilde SS~ "knows" about the parameter?

    Solution

    Under the chain rule each velocity picks up dτ′/dτd\tau'/d\taudτ′/dτ, and because the integrand is degree two it scales by (dτ′/dτ)2(d\tau'/d\tau)^2(dτ′/dτ)2: −ημνdxμdτdxνdτ=(dτ′dτ)2(−ημνdxμdτ′dxνdτ′).-\eta_{\mu\nu}\frac{dx^\mu}{d\tau}\frac{dx^\nu}{d\tau} = \Big(\frac{d\tau'}{d\tau}\Big)^2\Big(-\eta_{\mu\nu}\frac{dx^\mu}{d\tau'}\frac{dx^\nu}{d\tau'}\Big).−ημν​dτdxμ​dτdxν​=(dτdτ′​)2(−ημν​dτ′dxμ​dτ′dxν​). Converting the measure eats only one power: dτ′dτ dτ=dτ′\frac{d\tau'}{d\tau}\,d\tau = d\tau'dτdτ′​dτ=dτ′. So S~=∫τi′τf′(−ημνdxμdτ′dxνdτ′) dτ′dτ  dτ′.\tilde S = \int_{\tau'_i}^{\tau'_f}\Big(-\eta_{\mu\nu}\frac{dx^\mu}{d\tau'}\frac{dx^\nu}{d\tau'}\Big)\,\frac{d\tau'}{d\tau}\;d\tau'.S~=∫τi′​τf′​​(−ημν​dτ′dxμ​dτ′dxν​)dτdτ′​dτ′. One factor of dτ′/dτd\tau'/d\taudτ′/dτ is left over inside the integral. Unless dτ′/dτ≡1d\tau'/d\tau \equiv 1dτ′/dτ≡1 — a trivial shift of origin, τ′=τ+const\tau'=\tau+\text{const}τ′=τ+const — this factor rescales the integrand and S~\tilde SS~ genuinely changes value: an affine relabeling τ′=aτ\tau'=a\tauτ′=aτ multiplies S~\tilde SS~ by 1/a1/a1/a, and a non-affine one distorts it point by point. Physically, S~\tilde SS~ measures the "energy" of the parameterization, not the intrinsic length. On a timelike curve the integrand is (ds/dτ)2(ds/d\tau)^2(ds/dτ)2, so over a fixed interval Cauchy–Schwarz gives S~≥(∫ds)2/(τf−τi)\tilde S \ge \big(\int ds\big)^2/(\tau_f-\tau_i)S~≥(∫ds)2/(τf​−τi​), with equality exactly when the marks are spaced evenly: S~\tilde SS~ is smallest for a constant-speed labeling and larger for any uneven one. It secretly encodes a choice of clock — exactly the information a geometric action must not contain. (The degree-two form is still useful: promote the leftover Jacobian into a dynamical variable — an auxiliary einbein field on the worldline — and the resulting action is reparameterization invariant again and, unlike −mc∫ds-mc\int ds−mc∫ds, survives the massless limit. That einbein formulation is the point-particle prototype of the string's Polyakov action.)
