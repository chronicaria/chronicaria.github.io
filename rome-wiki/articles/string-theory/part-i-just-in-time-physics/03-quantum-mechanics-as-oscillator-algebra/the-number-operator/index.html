    The number operator

    The number operator N=a^\dagger a has eigenvalues exactly 0,1,2,\dots : it counts how many quanta of energy \hbar\omega a state holds. Two facts do all the work — N is non-negative because it is a squared length, and a steps it down one unit at a time — and a quantity that is non-negative and drops in whole steps can only be a non-negative integer.

    Think of a stack of identical coins. a†a^\daggera† drops one coin on top, aaa removes the top coin, and NNN reports how many coins are in the stack. You cannot have −1-1−1 coins (that's positivity), and you can only add or remove whole coins (that's the ladder), so the stack height is 0,1,2,…0,1,2,\dots0,1,2,… — nothing in between. The oscillator's energy levels are exactly this coin stack, each coin worth ℏω\hbar\omegaℏω, resting on a fixed 12ℏω\tfrac12\hbar\omega21​ℏω "table." This note is the module's exit check, worked end to end.

    Everything below is pure algebra from the two outputs of Ladder operators: [a,a†]=1[a,a^\dagger]=1[a,a†]=1 and H=ℏω(a†a+12)H=\hbar\omega(a^\dagger a+\tfrac12)H=ℏω(a†a+21​). Only the very last step (completeness) invokes the wavefunction.

    Setup: the spectrum of HHH is the spectrum of NNN

    N≡a†a,soH=ℏω(N+12).N \equiv a^\dagger a, \qquad\text{so}\qquad H = \hbar\omega\left(N+\tfrac12\right).N≡a†a,soH=ℏω(N+21​).

    NNN is Hermitian, N†=(a†a)†=a†a=NN^\dagger=(a^\dagger a)^\dagger=a^\dagger a=NN†=(a†a)†=a†a=N, so it is an observable with real eigenvalues, and HHH is just NNN affinely rescaled. Find the eigenvalues of NNN and the entire energy spectrum follows, with no differential equation.

    NNN has one more feature we lean on immediately: it can never be negative. For any state its expectation value is a squared length,

    \langle\psi|N|\psi\rangle = \langle\psi|a^\dagger a|\psi\rangle = \langle a\psi|a\psi\rangle = \big\|\,a|\psi\rangle\,\big\|^2 \ge 0, \tag{1}

    where the middle step moves a†a^\daggera† across the inner product as the adjoint of aaa. Any operator of the form "dagger times itself" is positive semidefinite, exactly as ∣z∣2≥0|z|^2\ge0∣z∣2≥0 for a complex number. Keep (1) in hand; it is the floor the whole ladder rests on.

    Step 1 — a†a^\daggera† and aaa shift NNN by one

    The Leibniz rule from Canonical commutation relations, combined with antisymmetry, gives [A^B^,C^]=A^[B^,C^]+[A^,C^]B^[\hat A\hat B,\hat C]=\hat A[\hat B,\hat C]+[\hat A,\hat C]\hat B[A^B^,C^]=A^[B^,C^]+[A^,C^]B^. Apply it with [a,a†]=1[a,a^\dagger]=1[a,a†]=1:

    [N,a†]=[a†a, a†]=a†[a,a†]+[a†,a†]a=a†,[N,a^\dagger] = [a^\dagger a,\, a^\dagger] = a^\dagger[a,a^\dagger] + [a^\dagger,a^\dagger]a = a^\dagger,[N,a†]=[a†a,a†]=a†[a,a†]+[a†,a†]a=a†, [N,a]=[a†a, a]=a†[a,a]+[a†,a]a=−a.[N,a] = [a^\dagger a,\, a] = a^\dagger[a,a] + [a^\dagger,a]a = -a.[N,a]=[a†a,a]=a†[a,a]+[a†,a]a=−a.

    So [N,a†]=+a†[N,a^\dagger]=+a^\dagger[N,a†]=+a† and [N,a]=−a[N,a]=-a[N,a]=−a: acting with a†a^\daggera† or aaa carries exactly ±1\pm1±1 unit of NNN, which is what makes them ladder rungs. Multiplying by ℏω\hbar\omegaℏω restates them for the energy (the constant 12\tfrac1221​ in HHH drops out of any commutator):

    [H,a†]=+ℏω a†,[H,a]=−ℏω a.[H,a^\dagger]=+\hbar\omega\,a^\dagger, \qquad [H,a]=-\hbar\omega\,a.[H,a†]=+ℏωa†,[H,a]=−ℏωa.

    Step 2 — the ladder

    Let ∣ν⟩|\nu\rangle∣ν⟩ satisfy N∣ν⟩=ν∣ν⟩N|\nu\rangle=\nu|\nu\rangleN∣ν⟩=ν∣ν⟩. Push NNN through a†a^\daggera† using Step 1:

    N a†∣ν⟩=(a†N+[N,a†])∣ν⟩=a†(ν+1)∣ν⟩=(ν+1) a†∣ν⟩.N\,a^\dagger|\nu\rangle = \big(a^\dagger N + [N,a^\dagger]\big)|\nu\rangle = a^\dagger(\nu+1)|\nu\rangle = (\nu+1)\,a^\dagger|\nu\rangle.Na†∣ν⟩=(a†N+[N,a†])∣ν⟩=a†(ν+1)∣ν⟩=(ν+1)a†∣ν⟩.

    So a†∣ν⟩a^\dagger|\nu\ranglea†∣ν⟩ is again an eigenstate, with eigenvalue raised to ν+1\nu+1ν+1 (energy up by ℏω\hbar\omegaℏω). It is genuinely nonzero: the same norm identity used in Step 4 gives ∥a†∣ν⟩∥2=⟨ν∣(N+1)∣ν⟩=ν+1≥1\|a^\dagger|\nu\rangle\|^2=\langle\nu|(N+1)|\nu\rangle=\nu+1\ge1∥a†∣ν⟩∥2=⟨ν∣(N+1)∣ν⟩=ν+1≥1 for any ν≥0\nu\ge0ν≥0. The identical computation with [N,a]=−a[N,a]=-a[N,a]=−a gives

    N a∣ν⟩=(ν−1) a∣ν⟩,N\,a|\nu\rangle = (\nu-1)\,a|\nu\rangle,Na∣ν⟩=(ν−1)a∣ν⟩,

    so aaa lowers ν\nuν by one, unless it kills the state outright — that loophole is about to matter. Hence the names: a†a^\daggera† creates a quantum, aaa annihilates one.

    Step 3 — positivity + ladder ⇒\Rightarrow⇒ spectrum is {0,1,2,… }\{0,1,2,\dots\}{0,1,2,…}

    This is the coin argument made rigorous.

    Start from any eigenvalue ν≥0\nu\ge0ν≥0 (it's ≥0\ge0≥0 by (1)) and apply aaa repeatedly. Each application lowers ν\nuν by one, producing eigenvalues ν,ν−1,ν−2,…\nu,\nu-1,\nu-2,\dotsν,ν−1,ν−2,…. If this chain never stopped it would eventually produce a nonzero eigenstate with eigenvalue below 000, contradicting positivity. The only escape is that at some point aaa annihilates the state: there is a lowest eigenstate ∣ν0⟩|\nu_0\rangle∣ν0​⟩ (take it normalized) with

    a∣ν0⟩=0.a|\nu_0\rangle = 0.a∣ν0​⟩=0.

    Now read ν0\nu_0ν0​ off positivity, which pins it to exactly zero rather than to some small non-negative number:

    ν0=⟨ν0∣N∣ν0⟩=∥a∣ν0⟩∥2=0.\nu_0=\langle\nu_0|N|\nu_0\rangle=\big\|a|\nu_0\rangle\big\|^2=0.ν0​=⟨ν0​∣N∣ν0​⟩=​a∣ν0​⟩​2=0.

    So the bottom rung sits at 000. Name its normalized state ∣0⟩|0\rangle∣0⟩: it satisfies a∣0⟩=0a|0\rangle=0a∣0⟩=0 and N∣0⟩=0N|0\rangle=0N∣0⟩=0 (the vacuum — no quanta).

    Finally, why must the original ν\nuν have been an integer? If it took rrr lowerings to reach the bottom, then ν−r=0\nu-r=0ν−r=0, so ν=r∈Z≥0\nu=r\in\mathbb Z_{\ge0}ν=r∈Z≥0​. Every eigenvalue sits an integer distance above a bottom that is itself 000, which is what forbids a fractional ladder like {12,32,… }\{\tfrac12,\tfrac32,\dots\}{21​,23​,…}. Building back up with a†a^\daggera† fills in 0,1,2,…0,1,2,\dots0,1,2,… and nothing else:

    \boxed{\;N|n\rangle = n|n\rangle,\quad n=0,1,2,\dots,\qquad E_n=\hbar\omega\left(n+\tfrac12\right)\;} \tag{2}

    The spectrum is an evenly spaced ladder with rung spacing ℏω\hbar\omegaℏω — Planck's E=ℏωE=\hbar\omegaE=ℏω, one quantum per rung — sitting on the zero-point floor E0=12ℏωE_0=\tfrac12\hbar\omegaE0​=21​ℏω derived in Ladder operators. The word "quantum" means nothing more than one indivisible step of this ladder.

    Step 4 — normalized rungs, and the sense in which NNN "counts"

    To use the ladder we need the constants in a†∣n⟩=cn∣n+1⟩a^\dagger|n\rangle=c_n|n+1\ranglea†∣n⟩=cn​∣n+1⟩. Get them from a norm, using aa†=a†a+[a,a†]=N+1aa^\dagger=a^\dagger a+[a,a^\dagger]=N+1aa†=a†a+[a,a†]=N+1:

    ∥a†∣n⟩∥2=⟨n∣aa†∣n⟩=⟨n∣(N+1)∣n⟩=n+1,\big\|a^\dagger|n\rangle\big\|^2 = \langle n|aa^\dagger|n\rangle = \langle n|(N+1)|n\rangle = n+1,​a†∣n⟩​2=⟨n∣aa†∣n⟩=⟨n∣(N+1)∣n⟩=n+1, ∥a∣n⟩∥2=⟨n∣a†a∣n⟩=⟨n∣N∣n⟩=n.\big\|a|n\rangle\big\|^2=\langle n|a^\dagger a|n\rangle = \langle n|N|n\rangle = n.​a∣n⟩​2=⟨n∣a†a∣n⟩=⟨n∣N∣n⟩=n.

    Fixing the phase of each ∣n⟩|n\rangle∣n⟩ so the coefficients are positive,

    a†∣n⟩=n+1 ∣n+1⟩,a∣n⟩=n ∣n−1⟩.a^\dagger|n\rangle = \sqrt{n+1}\,|n+1\rangle, \qquad a|n\rangle = \sqrt{n}\,|n-1\rangle.a†∣n⟩=n+1​∣n+1⟩,a∣n⟩=n​∣n−1⟩.

    The n\sqrt nn​ in a∣n⟩a|n\ranglea∣n⟩ is self-policing: at n=0n=0n=0 it gives 0 ∣−1⟩=0\sqrt0\,|{-1}\rangle=00​∣−1⟩=0, so the algebra kills the would-be negative state on its own. Iterating a†a^\daggera† builds the whole tower from the vacuum:

    ∣n⟩=(a†)nn! ∣0⟩.|n\rangle = \frac{(a^\dagger)^n}{\sqrt{n!}}\,|0\rangle.∣n⟩=n!​(a†)n​∣0⟩.

    The n!\sqrt{n!}n!​ is precisely the normalizer. To verify, commute aaa through (a†)n(a^\dagger)^n(a†)n — one gets [a,(a†)n]=n(a†)n−1[a,(a^\dagger)^n]=n(a^\dagger)^{n-1}[a,(a†)n]=n(a†)n−1 by induction from the Leibniz rule — so that, since a∣0⟩=0a|0\rangle=0a∣0⟩=0,

    ∥(a†)n∣0⟩∥2=⟨0∣an(a†)n∣0⟩=n ⟨0∣an−1(a†)n−1∣0⟩=n!.\big\|(a^\dagger)^n|0\rangle\big\|^2 =\langle0|a^n(a^\dagger)^n|0\rangle =n\,\langle0|a^{n-1}(a^\dagger)^{n-1}|0\rangle =n!.​(a†)n∣0⟩​2=⟨0∣an(a†)n∣0⟩=n⟨0∣an−1(a†)n−1∣0⟩=n!.

    Dividing by n!\sqrt{n!}n!​ gives ⟨n∣n⟩=1\langle n|n\rangle=1⟨n∣n⟩=1.

    The verb "count" is exact. Read ∣n⟩|n\rangle∣n⟩ as "the vacuum with nnn identical quanta added": each a†a^\daggera† deposits one quantum worth ℏω\hbar\omegaℏω, N=a†aN=a^\dagger aN=a†a hands back the integer nnn — how many are present — and HHH bills ℏω\hbar\omegaℏω per quantum plus the fixed 12ℏω\tfrac12\hbar\omega21​ℏω floor. The quanta are indistinguishable bosons: there is a single a†a^\daggera†, and (a†)n(a^\dagger)^n(a†)n is automatically symmetric, so the state depends only on how many, never on which. This is the hinge of the whole course — in A string is many oscillators each vibration mode gets its own a†a^\daggera†, "nnn quanta in mode kkk" becomes "the string rings in its kkk-th harmonic nnn quanta deep," and those excitation numbers get reread as particles.

    Step 5 — no states hide off the ladder

    The algebra shows every eigenstate lies on a ladder anchored at 000, but could there be a second normalizable bottom state, starting a parallel ladder? In the concrete Schrödinger representation, no. With p^=−iℏ d/dx\hat p=-i\hbar\,d/dxp^​=−iℏd/dx the vacuum condition aψ0=0a\psi_0=0aψ0​=0 reads

    mω2ℏ(x+ℏmωddx)ψ0(x)=0  ⟹  ψ0′(x)=−mωℏ x ψ0(x).\sqrt{\frac{m\omega}{2\hbar}}\left(x+\frac{\hbar}{m\omega}\frac{d}{dx}\right)\psi_0(x)=0 \;\Longrightarrow\; \psi_0'(x)=-\frac{m\omega}{\hbar}\,x\,\psi_0(x).2ℏmω​​(x+mωℏ​dxd​)ψ0​(x)=0⟹ψ0′​(x)=−ℏmω​xψ0​(x).

    This first-order ODE has a one-dimensional solution space,

    ψ0(x)=Cexp⁡ ⁣(−mωx22ℏ),C=(mωπℏ)1/4,\psi_0(x)=C\exp\!\left(-\frac{m\omega x^2}{2\hbar}\right),\qquad C=\left(\frac{m\omega}{\pi\hbar}\right)^{1/4},ψ0​(x)=Cexp(−2ℏmωx2​),C=(πℏmω​)1/4,

    with CCC fixed by ∫−∞∞e−βx2dx=π/β\int_{-\infty}^\infty e^{-\beta x^2}dx=\sqrt{\pi/\beta}∫−∞∞​e−βx2dx=π/β​, β=mω/ℏ\beta=m\omega/\hbarβ=mω/ℏ. So the bottom is unique. Acting with (a†)n/n!(a^\dagger)^n/\sqrt{n!}(a†)n/n!​ dresses this Gaussian with a degree-nnn polynomial — the Hermite functions — and as eigenfunctions of the confining self-adjoint Hamiltonian −ℏ22m∂x2+12mω2x2-\tfrac{\hbar^2}{2m}\partial_x^2+\tfrac12 m\omega^2x^2−2mℏ2​∂x2​+21​mω2x2 they form a complete orthonormal basis. No normalizable state hides off the single ladder.

    Open questions

    • Completeness in Step 5 leans on the Sturm–Liouville theorem for a confining self-adjoint operator; that is mathematical background, not string-specific physics.
    • With several independent oscillators, different occupation lists can share the same total NNN — a degeneracy that is exactly the state-counting problem of Partition Functions and State Counting.

    Exercise

    The number operator "counts," but does it count linearly in energy? Compute the expectation and spread of energy in the state a†∣0⟩=∣1⟩a^\dagger|0\rangle=|1\ranglea†∣0⟩=∣1⟩ directly, without using (2) — use only [a,a†]=1[a,a^\dagger]=1[a,a†]=1, a∣0⟩=0a|0\rangle=0a∣0⟩=0, and H=ℏω(a†a+12)H=\hbar\omega(a^\dagger a+\tfrac12)H=ℏω(a†a+21​). Then sanity-check against (2). Is ∣1⟩|1\rangle∣1⟩ an energy eigenstate (spread zero) or a superposition (spread nonzero)?

    Solution

    Write ∣1⟩=a†∣0⟩|1\rangle=a^\dagger|0\rangle∣1⟩=a†∣0⟩ (already normalized, since ∥a†∣0⟩∥2=⟨0∣aa†∣0⟩=⟨0∣(a†a+1)∣0⟩=1\|a^\dagger|0\rangle\|^2=\langle0|aa^\dagger|0\rangle=\langle0|(a^\dagger a+1)|0\rangle=1∥a†∣0⟩∥2=⟨0∣aa†∣0⟩=⟨0∣(a†a+1)∣0⟩=1).

    Mean energy. H∣1⟩=ℏω(a†a+12)a†∣0⟩H|1\rangle=\hbar\omega(a^\dagger a+\tfrac12)a^\dagger|0\rangleH∣1⟩=ℏω(a†a+21​)a†∣0⟩. Move a†aa^\dagger aa†a onto a†∣0⟩a^\dagger|0\ranglea†∣0⟩: since a†a a†∣0⟩=a†(aa†)∣0⟩=a†(a†a+1)∣0⟩=a†∣0⟩a^\dagger a\,a^\dagger|0\rangle=a^\dagger(a a^\dagger)|0\rangle=a^\dagger(a^\dagger a+1)|0\rangle=a^\dagger|0\ranglea†aa†∣0⟩=a†(aa†)∣0⟩=a†(a†a+1)∣0⟩=a†∣0⟩ (using a∣0⟩=0a|0\rangle=0a∣0⟩=0), we get H∣1⟩=ℏω(1+12)∣1⟩=32ℏω ∣1⟩.H|1\rangle=\hbar\omega\left(1+\tfrac12\right)|1\rangle=\tfrac32\hbar\omega\,|1\rangle.H∣1⟩=ℏω(1+21​)∣1⟩=23​ℏω∣1⟩. So ⟨H⟩=32ℏω\langle H\rangle=\tfrac32\hbar\omega⟨H⟩=23​ℏω.

    Spread. The line above shows ∣1⟩|1\rangle∣1⟩ is an exact eigenstate of HHH with eigenvalue 32ℏω\tfrac32\hbar\omega23​ℏω, so ⟨H2⟩=(32ℏω)2\langle H^2\rangle=(\tfrac32\hbar\omega)^2⟨H2⟩=(23​ℏω)2 and ΔE=⟨H2⟩−⟨H⟩2=0.\Delta E=\sqrt{\langle H^2\rangle-\langle H\rangle^2}=0.ΔE=⟨H2⟩−⟨H⟩2​=0. ∣1⟩|1\rangle∣1⟩ is a sharp energy eigenstate, not a superposition — the spread vanishes.

    Check. Formula (2) gives E1=ℏω(1+12)=32ℏωE_1=\hbar\omega(1+\tfrac12)=\tfrac32\hbar\omegaE1​=ℏω(1+21​)=23​ℏω: exactly one quantum ℏω\hbar\omegaℏω above the vacuum's 12ℏω\tfrac12\hbar\omega21​ℏω. The direct algebra reproduces the counting result, confirming NNN counts linearly — each rung adds exactly ℏω\hbar\omegaℏω, no more, no less.
