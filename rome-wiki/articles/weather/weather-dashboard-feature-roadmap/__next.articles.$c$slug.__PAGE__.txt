7:T23d3,<h2 id="the-throughline">The throughline</h2>
<p>The moat is the <strong>119-member ensemble</strong>. The best features aren't "add AQI like everyone else" — they're the ones only <em>this</em> app can do: <em>"73% of members say it hits 90°F today," "rain most likely 2–6pm, members split on evening," "Saturday has cooled 6° since yesterday."</em> Prioritize features that make uncertainty the star. Second priority: reuse data already in memory (zero new calls). Third: one cheap free API per feature.</p>
<h2 id="tier-1--near-free-wins-reuse-ensemble-data-already-fetched-s-effort">Tier 1 — near-free wins (reuse ensemble data already fetched, S effort)</h2>
<ul>
<li><strong>Rain-timing ribbon</strong> ⭐ — "rain starts ~4:20pm, lasts ~40 min," with honest <em>likely/possible</em> confidence = fraction of members raining each hour. A dry-window finder ("gap to walk the dog: 5–7pm"). <em>The single highest-value daily feature; pure client-side from members.</em></li>
<li><strong>Threshold probability chips</strong> — per day: "73% chance ≥90°F," "40% chance of freeze tonight," "gusts >30mph." Auto-pick thresholds by season. <em>Counting members, zero new calls.</em></li>
<li><strong>Spaghetti / plume toggle</strong> ⭐ — swap the p10–p90 band for the raw 119 member lines fanning out with lead time. Optionally colored by model (GFS/ECMWF/ICON). <em>Viscerally beautiful, screenshot-bait, trivial.</em></li>
<li><strong>Best / likely / worst day cards</strong> — each 7-day card shows p10 / p50 / p90 for the high &#x26; low, not one number. The spread tightens as the day nears.</li>
<li><strong>Dew-point mugginess meter + warmest/coolest-hour pins</strong> — "sticky/oppressive" comfort bands; "open the windows at 6am — coolest it'll get."</li>
<li><strong>"What to wear" strip</strong> — jacket / umbrella / sunglasses icons + one-line verdict from feels-like + PoP + UV + gusts.</li>
<li><strong>"Nice day" score (0–100)</strong> — one composite pleasantness number per day + the factor dragging it down ("83 — great, but breezy"). Naturally shareable.</li>
<li><strong>Sparklines in the 7-day cards</strong> — a tiny temp-band microchart + precip bar per card (reuses uPlot + data already loaded).</li>
<li><strong>Sun &#x26; moon strip</strong> — sunrise/sunset, golden/blue hour, daylight ±vs yesterday, moon phase + illumination. Pure <strong>SunCalc</strong> math, no API, never fails.</li>
</ul>
<h2 id="tier-2--one-new-free-api-each-sm">Tier 2 — one new free API each (S–M)</h2>
<ul>
<li><strong>Air quality (US AQI + PM2.5) + wildfire-smoke flag</strong> ⭐ — Open-Meteo <strong>Air Quality API</strong> (<code>air-quality-api.open-meteo.com</code>, free/no-key/CORS): <code>us_aqi, pm2_5, pm10, ozone</code>. Smoke = PM2.5/AOD anomaly vs the place's own baseline (client-side). <em>Answers "run? open windows? mask?" — most valuable on NYC's worsening summer smoke days.</em></li>
<li><strong>UV burn window</strong> — <code>uv_index</code> is a free field on the forecast API you already call. "Protect between 11am–3:40pm; UV peaks 8." Burn-time by skin type.</li>
<li><strong>"Today vs normal" + records</strong> — Open-Meteo <strong>ERA5 archive</strong> (<code>archive-api.open-meteo.com</code>, ~80yr, ~5-day latency): per-calendar-day normal + record, computed once and cached (pre-bake a small JSON per place). Shade a "normal band" behind the temp trace; flag "3° short of the record." <em>Deepens the honesty angle: future uncertainty + past context.</em></li>
<li><strong>Forecast-change tracker</strong> ⭐ — Open-Meteo <strong>Previous Runs API</strong> (<code>previous-runs-api.open-meteo.com</code>): "Saturday has warmed 6° since yesterday," trend arrows per day, a sparkline of how each day's predicted high has drifted across runs. <em>Literally impossible without stored past runs — a real daily-return hook.</em></li>
<li><strong>Live radar / nowcast overlay</strong> — <strong>RainViewer</strong> (<code>api.rainviewer.com/public/weather-maps.json</code>, free/no-key/CORS): 13 past frames + short nowcast, plus a satellite layer. Needs a small map lib (Leaflet/MapLibre). <em>Radar is the most-opened mobile weather feature.</em></li>
<li><strong>Marine (waves/SST) + tides</strong> — Open-Meteo <strong>Marine API</strong> + <strong>NOAA CO-OPS Tides</strong> (US, free/no-key/CORS). Show a beach/surf panel <em>only</em> for coastal places (Battery Park, Rockaways, coastal cities).</li>
<li><strong>River/flood outlook</strong> — Open-Meteo <strong>Flood API</strong> (GloFAS): river discharge with p25/p75 bands — a perfect thematic match for the uncertainty angle. Only spikes in wet spells.</li>
<li><strong>Aurora watch</strong> — NOAA <strong>SWPC</strong> Kp + OVATION grid (free/no-key/CORS), fun for higher-latitude places.</li>
</ul>
<h2 id="tier-3--social--multi-place--sharing-m">Tier 3 — social / multi-place / sharing (M)</h2>
<ul>
<li><strong>"Nicest right now / this weekend" ranking</strong> ⭐ — score every place in the sidebar on pleasantness and rank them; toggle Now / Today / Weekend. A #1 flagged "could go either way" is the whole thesis in one glance. <em>Turns a place list into a daily scoreboard.</em></li>
<li><strong>Side-by-side compare (2–4 places)</strong> — overlay their bands on one chart, aligned by local clock ("6pm here vs 6pm there").</li>
<li><strong>"Me vs friend" pair link</strong> — a two-up view for exactly two places in their own local times ("it's 8am there, 7pm here"), whole pairing encoded in the URL to send.</li>
<li><strong>Shareable snapshot PNG</strong> — render the current view (city, time, feels-like + band, sparkline) to a canvas → a self-contained "postcard" that carries the honest band into group chats.</li>
<li><strong>All-my-places overview grid</strong> — one compact tile per place (time, feels-like, hi/lo, rain odds, microchart, volatility dot) — the home screen you land on.</li>
<li><strong>Add-your-own place</strong> — Open-Meteo <strong>Geocoding API</strong> (free/no-key/CORS) → search a city, pin favorites in localStorage, encode the set in the URL. Makes it <em>your</em> page.</li>
<li><strong>Embeddable widget</strong> — a <code>?embed=&#x3C;place></code> chrome-less mode for blogs/Notion.</li>
</ul>
<h2 id="tier-4--delight--platform-ml">Tier 4 — delight &#x26; platform (M–L)</h2>
<ul>
<li><strong>"Story of the week" natural-language summary</strong> ⭐ — deterministic rules over the ensemble write a short honest paragraph ("calm sunny start, then confidence drops after Thursday: members split between a dry ridge and a rainy trough — treat the weekend as a coin-flip"). <em>Makes the uncertainty legible to non-nerds in one sentence. No LLM needed.</em></li>
<li><strong>Conditions- &#x26; time-aware dynamic theming</strong> — palette derived from weather code + sun position (clear-day azure, clear-night indigo, storm violet). The site looks like the sky outside.</li>
<li><strong>Ambient animated background</strong> — rain whose density tracks the honest p(rain), snow, stars at night; fully stops under <code>prefers-reduced-motion</code>.</li>
<li><strong>Apple-style hour-by-hour strip</strong> — the near-term "jacket for the 6pm walk?" view the multi-day chart doesn't serve.</li>
<li><strong>Installable PWA + offline last-known-good</strong> — home-screen icon, opens &#x3C;1s, shows last forecast offline with an "updated Xh ago" banner.</li>
<li><strong>Threshold push notifications</strong> — "notify if p(rain) >60% in next 3h," new NWS alert. Foreground/periodic-sync is client-side; true background push needs a push server (the one non-lazy tier).</li>
<li><strong>Pro mode</strong> — spaghetti + dew point + pressure + wind barbs + model-run timestamp, behind a toggle; default stays clean.</li>
<li><strong>Accessibility, unit toggles (°F/°C, mph/kph, 12/24h), and a "last updated / model run" transparency panel</strong> — the invisible polish that signals a serious, honest product.</li>
</ul>
<h2 id="recommended-next-34-to-build">Recommended next 3–4 to build</h2>
<ol>
<li><strong>Rain-timing ribbon + threshold chips</strong> — the thesis, zero new API, highest daily value.</li>
<li><strong>Air quality + smoke flag</strong> — one S-effort free API, huge real-world relevance (NYC summer).</li>
<li><strong>Spaghetti toggle</strong> — a delightful, trivial, screenshot-worthy flex of the ensemble.</li>
<li><strong>"Nicest right now" ranking</strong> — makes the multi-place list finally sing and is the most shareable.</li>
</ol>
<p>Then pick from Tier 3/4 based on whether the goal is <em>reach</em> (sharing, PWA) or <em>depth</em> (records, forecast-change, radar).</p>
<h2 id="open-questions">Open questions</h2>

<li>Which places are coastal enough to justify the marine/tides panel?</li>
<li>Is a small map library (Leaflet) an acceptable dependency for radar, or keep it strictly dependency-light?</li>
