    Beta functions and conformal invariance

    A string in a curved spacetime is a 2d field theory whose coupling constants are the spacetime fields themselves; quantizing it makes those couplings run unless the spacetime is Ricci-flat, so demanding conformal invariance (killing the running) is Einstein's equation in disguise.

    The string cannot move consistently in a spacetime that fails to solve the gravitational field equations: if it tries, the worldsheet theory breaks down as a quantum theory. This note builds the machinery; Einstein equations from conformal invariance reads off the gravitational consequence.

    Couplings that are spacetime fields

    Set strings aside for a moment. In any quantum field theory the coupling constants — the numbers multiplying interaction terms — are not really constant: quantum corrections make them drift as one changes the energy scale μ\muμ probed at. The beta function β=μ ∂μ(coupling)\beta = \mu\,\partial_\mu(\text{coupling})β=μ∂μ​(coupling) measures that drift. When β=0\beta=0β=0 the theory looks the same at every scale, and it is scale (conformal) invariant.

    Return to the string. A string sweeping through a curved spacetime is governed by a 2d worldsheet theory in which the metric of spacetime plays the role of the coupling constant. So the question "does this 2d theory run?" becomes "does the spacetime metric drift under the renormalization group?" And the string cannot afford any drift: worldsheet conformal invariance is the gauge symmetry that made D=26D=26D=26 and the graviton come out right in the first place. So we set β=0\beta=0β=0. The answer that emerges is β∝Rμν\beta \propto \mathcal R_{\mu\nu}β∝Rμν​, so β=0\beta=0β=0 forces Rμν=0\mathcal R_{\mu\nu}=0Rμν​=0 — the vacuum Einstein equation. A consistent worldsheet forces gravity on the target space.

    The string in a curved background is a sigma model

    The Polyakov action generalizes from flat space to a general target metric Gμν(X)G_{\mu\nu}(X)Gμν​(X). For the loop computation we Wick-rotate to a Euclidean worldsheet (hence g\sqrt{g}g​, not −h\sqrt{-h}−h​) and a Euclidean target (δμν\delta_{\mu\nu}δμν​ in place of the mostly-plus ημν\eta_{\mu\nu}ημν​); the signs below are fixed by that convention: S = \frac{1}{4\pi\alpha'}\int d^2\sigma\,\sqrt{g}\,g^{\alpha\beta}\,\partial_\alpha X^\mu\,\partial_\beta X^\nu\,G_{\mu\nu}(X). \tag{1} The worldsheet metric gαβg_{\alpha\beta}gαβ​ (α,β\alpha,\betaα,β = worldsheet indices) is still the 2d gauge field; the new ingredient is the spacetime metric Gμν(X)G_{\mu\nu}(X)Gμν​(X) (μ,ν\mu,\nuμ,ν = target indices), which depends on the dynamical fields XXX. A theory whose kinetic term has field-dependent coefficients is a nonlinear sigma model, and the DDD-dimensional spacetime is its target space.

    This Gμν(X)G_{\mu\nu}(X)Gμν​(X) is genuinely made of the flat-space string's gravitons: writing Gμν=δμν+hμνG_{\mu\nu}=\delta_{\mu\nu}+h_{\mu\nu}Gμν​=δμν​+hμν​ and inserting the exponential of the graviton vertex operator into the path integral is the same as building a coherent state — a condensate — of gravitons. "String in a background metric" and "string in a cloud of its own gravitons" are the same statement.

    The couplings are the Taylor coefficients of GμνG_{\mu\nu}Gμν​

    To see the metric literally as an infinite set of coupling constants, expand around a point xˉ\bar xxˉ with Xμ=xˉμ+α′ YμX^\mu = \bar x^\mu + \sqrt{\alpha'}\,Y^\muXμ=xˉμ+α′​Yμ. (The α′\sqrt{\alpha'}α′​ makes YYY dimensionless: [X]=−1[X]=-1[X]=−1 in worldsheet units, [α′]=−2[\alpha']=-2[α′]=−2.) G_{\mu\nu}(X) = G_{\mu\nu}(\bar x) + \sqrt{\alpha'}\,\partial_\omega G_{\mu\nu}(\bar x)\,Y^\omega + \tfrac{\alpha'}{2}\,\partial_\omega\partial_\rho G_{\mu\nu}(\bar x)\,Y^\omega Y^\rho + \cdots \tag{2} Each Taylor coefficient multiplies a distinct interaction among the fluctuations YYY: ∂ωGμν\partial_\omega G_{\mu\nu}∂ω​Gμν​ is a cubic vertex, ∂ω∂ρGμν\partial_\omega\partial_\rho G_{\mu\nu}∂ω​∂ρ​Gμν​ a quartic, and so on. Infinitely many couplings, all packaged into the single function Gμν(X)G_{\mu\nu}(X)Gμν​(X).

    When is this weakly coupled? If the target curves on a length scale rcr_crc​ (so ∂G/∂X∼1/rc\partial G/\partial X\sim 1/r_c∂G/∂X∼1/rc​), the dimensionless coupling is \frac{\sqrt{\alpha'}}{r_c}. \tag{3} Perturbation theory in the sigma model is therefore the α′\alpha'α′-expansion: valid when spacetime varies slowly compared to the string length α′\sqrt{\alpha'}α′​. This is a separate expansion from the gsg_sgs​ (string-loop) one — a string amplitude is a double series in α′\alpha'α′ and gsg_sgs​.

    The beta functional and why it must vanish

    Classically (1) is conformally invariant. Quantum-mechanically, regulating UV divergences forces in a scale μ\muμ, and the couplings — i.e. the metric — run. Because there is a coupling for every point of spacetime, the running is measured by a beta functional: \beta_{\mu\nu}(G) \sim \mu\,\frac{\partial G_{\mu\nu}(X;\mu)}{\partial\mu}. \tag{4} In string theory conformal (Weyl) invariance is a gauge symmetry of the Polyakov action and cannot be given up. So we impose \beta_{\mu\nu}(G) = 0. \tag{5} Everything downstream in this module is the computation and consequence of this one condition.

    One-loop computation of βμν(G)\beta_{\mu\nu}(G)βμν​(G)

    Start by choosing the cleverest coordinates. At xˉ\bar xxˉ, pick Riemann normal coordinates, where the metric's Taylor expansion has no linear term and its leading nontrivial piece is the curvature itself: G_{\mu\nu}(X) = \delta_{\mu\nu} - \tfrac{\alpha'}{3}\,\mathcal R_{\mu\lambda\nu\kappa}(\bar x)\,Y^\lambda Y^\kappa + \mathcal O(Y^3). \tag{6} These coordinates discard the coordinate-artifact terms and leave a single physical interaction, controlled by the Riemann tensor. The action (1) becomes S = \frac{1}{4\pi}\int d^2\sigma\,\Big[\,\partial Y^\mu\partial Y^\nu\,\delta_{\mu\nu} - \tfrac{\alpha'}{3}\,\mathcal R_{\mu\lambda\nu\kappa}\,Y^\lambda Y^\kappa\,\partial Y^\mu\partial Y^\nu\,\Big]. \tag{7} The first term is a free 2d scalar; the second is a quartic vertex (two "spectator" legs Yλ,YκY^\lambda,Y^\kappaYλ,Yκ from the metric, two derivative legs ∂Yμ,∂Yν\partial Y^\mu,\partial Y^\nu∂Yμ,∂Yν from the kinetic structure).

    Now find the divergence. The one-loop correction comes from contracting the two spectator legs Yλ,YκY^\lambda,Y^\kappaYλ,Yκ of a single vertex with each other — a self-loop closing on one point (a tadpole). That contraction is the coincident-point limit of the free 2d propagator, \langle Y^\lambda(\sigma)\,Y^\kappa(\sigma')\rangle = -\tfrac12\,\delta^{\lambda\kappa}\,\ln|\sigma-\sigma'|^2, \tag{8} which diverges as σ′→σ\sigma'\to\sigmaσ′→σ. Regulating in d=2+ϵd=2+\epsilond=2+ϵ dimensions turns the log divergence into a 1/ϵ1/\epsilon1/ϵ pole: \langle Y^\lambda(\sigma)\,Y^\kappa(\sigma)\rangle \;\longrightarrow\; \frac{\delta^{\lambda\kappa}}{\epsilon}. \tag{9}

    Read off the counterterm. To subtract the pole, replace YλYκY^\lambda Y^\kappaYλYκ in the vertex by its self-contraction (9). Contracting the Riemann tensor on those two indices collapses it to the Ricci tensor: \mathcal R_{\mu\lambda\nu\kappa}\,\langle Y^\lambda Y^\kappa\rangle \;\propto\; \mathcal R_{\mu\lambda\nu\kappa}\,\frac{\delta^{\lambda\kappa}}{\epsilon} = \frac{1}{\epsilon}\,\mathcal R_{\mu\nu}. \tag{10} So the divergent piece is ∝Rμν ∂Yμ∂Yν\propto \mathcal R_{\mu\nu}\,\partial Y^\mu\partial Y^\nu∝Rμν​∂Yμ∂Yν — the same structure as the kinetic term. The loop cannot manufacture a new kind of term at this order; it can only shift the coefficient of ∂Yμ∂Yν\partial Y^\mu\partial Y^\nu∂Yμ∂Yν, which is nothing but the metric. Absorbing the pole (with a harmless YYY-field redefinition) requires renormalizing the metric coupling: G_{\mu\nu} \;\longrightarrow\; G_{\mu\nu} + \frac{\alpha'}{\epsilon}\,\mathcal R_{\mu\nu}. \tag{11}

    Finally, turn the counterterm into a beta function. The bare metric — the thing written in the Lagrangian — is independent of the arbitrary scale μ\muμ: G_{\mu\nu}^{\text{bare}} = G_{\mu\nu}(\mu) + \frac{\alpha'}{\epsilon}\,\mathcal R_{\mu\nu}\big(G(\mu)\big) + \cdots,\qquad \mu\,\frac{d}{d\mu}\,G_{\mu\nu}^{\text{bare}} = 0. \tag{12} For the bare quantity to stay fixed while the pole is subtracted, the finite (renormalized) metric Gμν(μ)G_{\mu\nu}(\mu)Gμν​(μ) must drift with μ\muμ. Tracking that drift order by order gives the one-loop beta function: \boxed{\,\beta_{\mu\nu}(G) = \alpha'\,\mathcal R_{\mu\nu}\,} \tag{13} Curvature is not just an interaction — it is precisely the obstruction to the worldsheet theory staying scale-invariant after quantization. A curved background sources the running; a Ricci-flat one does not.

    The same result as a Weyl anomaly

    Result (13) came from studying the running on a flat worldsheet. The mirror-image statement lives on a curved worldsheet, and it is the one that makes the word "conformal" literal. Write the worldsheet metric as gαβ=e2ϕδαβg_{\alpha\beta}=e^{2\phi}\delta_{\alpha\beta}gαβ​=e2ϕδαβ​; a Weyl transformation shifts ϕ\phiϕ. In d=2+ϵd=2+\epsilond=2+ϵ the g\sqrt gg​ and gαβg^{\alpha\beta}gαβ factors in (1) fail to cancel by an amount ∝ϵ\propto\epsilon∝ϵ, and after renormalizing the metric with (11) that mismatch leaves a finite ϕ\phiϕ-dependence as ϵ→0\epsilon\to0ϵ→0: the action depends on the Weyl factor, so Weyl invariance is broken.

    The clean diagnostic is the trace of the worldsheet stress tensor. Classically the trace vanishes; the quantum expectation value does not, and computing it gives \langle T^{\alpha}{}_{\alpha}\rangle = -\frac{1}{2\alpha'}\,\beta_{\mu\nu}(G)\,\partial X^\mu\partial X^\nu = -\tfrac12\,\mathcal R_{\mu\nu}\,\partial X^\mu\partial X^\nu. \tag{14} This is the chain that runs the whole module: βμν≠0  ⟺  ⟨Tαα⟩≠0  ⟺  Weyl anomaly  ⟺  no CFT.\beta_{\mu\nu}\ne 0 \;\Longleftrightarrow\; \langle T^\alpha{}_\alpha\rangle\ne 0 \;\Longleftrightarrow\; \text{Weyl anomaly} \;\Longleftrightarrow\; \text{no CFT}.βμν​=0⟺⟨Tαα​⟩=0⟺Weyl anomaly⟺no CFT. Demanding βμν=0\beta_{\mu\nu}=0βμν​=0 is exactly demanding that the worldsheet theory remain a conformal field theory. That is the precise content of "worldsheet conformal invariance constrains the spacetime fields."

    The full set, with BBB and Φ\PhiΦ

    Turning on all three massless closed-string fields — metric GμνG_{\mu\nu}Gμν​, Kalb–Ramond BμνB_{\mu\nu}Bμν​, dilaton Φ\PhiΦ (see Metric, B-field, and dilaton as low-energy fields) — gives three beta functions whose simultaneous vanishing is the full consistency condition:

    where H=dBH=dBH=dB is the 3-form field strength. The metric term is (13); the extra pieces are the dilaton gradient and the BBB-field flux acting as sources. These are written for the critical dimension D=26D=26D=26; off-critical, β(Φ)\beta(\Phi)β(Φ) picks up a constant D−266\tfrac{D-26}{6}6D−26​ whose vanishing is what selects D=26D=26D=26 (that framing is developed in Worldsheet consistency becomes spacetime dynamics). Only the leading βμν(G)=α′Rμν\beta_{\mu\nu}(G)=\alpha'\mathcal R_{\mu\nu}βμν​(G)=α′Rμν​ is derived above; the BBB and Φ\PhiΦ pieces come from the analogous background-field expansion with torsion and dilaton improvement terms, which we quote rather than compute (see Open questions).

    The RG flow is Ricci flow (aside)

    Reading (13) as an actual flow equation, \mu\,\partial_\mu\, G_{\mu\nu} = \alpha'\,\mathcal R_{\mu\nu}, \tag{16} is exactly Ricci flow — the metric evolving in the direction of its own curvature. (The μ\muμ on the left is the RG scale, distinct from the tensor index μ\muμ on GμνG_{\mu\nu}Gμν​; the flow parameter is log-scale, t=ln⁡μt=\ln\mut=lnμ, so ∂tGμν=α′Rμν\partial_t G_{\mu\nu}=\alpha'\mathcal R_{\mu\nu}∂t​Gμν​=α′Rμν​, and the "standard" mathematician's normalization ∂tG=−2Rμν\partial_t G=-2\mathcal R_{\mu\nu}∂t​G=−2Rμν​ differs only by rescaling ttt and orienting toward the IR.) This is the same geometric flow (with a dilaton-like term) that Perelman used to prove the Poincaré conjecture. The renormalization group of a 2d sigma model is literally geometric flow on the target manifold; the fixed points, where the flow stops, are the Ricci-flat metrics — the string's allowed universes.

    Open questions

    • Only βμν(G)=α′Rμν\beta_{\mu\nu}(G)=\alpha'\mathcal R_{\mu\nu}βμν​(G)=α′Rμν​ is derived here. The BBB and Φ\PhiΦ terms in (15) are quoted; deriving them needs the full background-field expansion with torsion and the dilaton's R(2)R^{(2)}R(2) coupling. That is the standard Friedan / Callan–Friedan–Martinec–Perry computation, deferred to a dedicated sigma-model-renormalization note.
    • The one-loop derivation above tracks the covariant structure and the pole coefficient, but not every Feynman-graph symmetry factor from first principles. A fully rigorous coefficient audit belongs in that same dedicated note.

    Exercise

    The boxed result βμν(G)=α′Rμν\beta_{\mu\nu}(G)=\alpha'\mathcal R_{\mu\nu}βμν​(G)=α′Rμν​ can be sanity-checked without redoing the loop, purely from dimensions and symmetry. Suppose you had never seen equation (13). Argue that at one loop βμν(G)\beta_{\mu\nu}(G)βμν​(G) must be proportional to Rμν\mathcal R_{\mu\nu}Rμν​, and determine the power of α′\alpha'α′ that multiplies it. Then use the same dimensional reasoning to predict which structure(s) can appear at the next (α′2\alpha'^2α′2, two-loop) order.

    Solution

    Why Rμν\mathcal R_{\mu\nu}Rμν​ and nothing else at one loop. βμν(G)\beta_{\mu\nu}(G)βμν​(G) renormalizes the metric coupling, so it must be a symmetric two-index tensor built covariantly from GμνG_{\mu\nu}Gμν​ — general covariance forbids anything that isn't a genuine tensor (this is what Riemann normal coordinates enforce automatically). The loop expansion is the α′\alpha'α′-expansion (3), and each power of α′\alpha'α′ carries two derivatives, since [α′]=−2[\alpha']=-2[α′]=−2 and [∂]=+1[\partial]=+1[∂]=+1. At one loop we have exactly one power of α′\alpha'α′, hence two derivatives of the metric. The only symmetric two-index covariant tensor with two derivatives of GμνG_{\mu\nu}Gμν​ is the Ricci tensor Rμν\mathcal R_{\mu\nu}Rμν​ (its trace R Gμν\mathcal R\,G_{\mu\nu}RGμν​ is the only other candidate, and it does not arise from the coincident-propagator contraction, which delivers the un-traced Rμλνκδλκ=Rμν\mathcal R_{\mu\lambda\nu\kappa}\delta^{\lambda\kappa}=\mathcal R_{\mu\nu}Rμλνκ​δλκ=Rμν​ directly). So βμν(G)=c α′ Rμν,\beta_{\mu\nu}(G) = c\,\alpha'\,\mathcal R_{\mu\nu},βμν​(G)=cα′Rμν​, and the explicit loop fixes c=1c=1c=1.

    Next order. Two loops means α′2\alpha'^2α′2, i.e. four derivatives of the metric. The available symmetric two-index tensors are curvature-squared contractions such as RμλρσRνλρσ\mathcal R_{\mu\lambda\rho\sigma}\mathcal R_\nu{}^{\lambda\rho\sigma}Rμλρσ​Rν​λρσ (and, by index gymnastics, terms like RμρRνρ\mathcal R_{\mu\rho}\mathcal R_\nu{}^\rhoRμρ​Rν​ρ or ∇2Rμν\nabla^2\mathcal R_{\mu\nu}∇2Rμν​). So we predict βμν(G)=α′ Rμν+12α′2 RμλρσRνλρσ+⋯ ,\beta_{\mu\nu}(G) = \alpha'\,\mathcal R_{\mu\nu} + \tfrac12\alpha'^2\,\mathcal R_{\mu\lambda\rho\sigma}\mathcal R_\nu{}^{\lambda\rho\sigma} + \cdots,βμν​(G)=α′Rμν​+21​α′2Rμλρσ​Rν​λρσ+⋯, the curvature-squared correction to Einstein's equations that kicks in when rc∼α′r_c\sim\sqrt{\alpha'}rc​∼α′​. Dimensional analysis alone gets the structure; only the honest two-loop graph fixes the coefficient 12\tfrac1221​.
