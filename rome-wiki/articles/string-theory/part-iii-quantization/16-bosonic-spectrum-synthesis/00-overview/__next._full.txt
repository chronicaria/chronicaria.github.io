17:T30b52,<h2 id="the-one-thing-to-take-away">The one thing to take away</h2>
<p>You never <em>put</em> gravity into string theory. You start with the simplest relativistic object — a rubber band whose worldsheet area you extremize — and quantize it like a violin string. The notes of that string are particles. One of the low notes is a <strong>massless spin-2 particle</strong>, and a theorem outside string theory says the only consistent thing a massless spin-2 particle can do is mediate general relativity. So gravity <em>falls out</em>. Run the same machine with open (Neumann) instead of closed (periodic) boundary conditions and it produces a <strong>photon</strong> instead. That is the bosonic string in one line, and this module is where you watch it happen end to end.</p>
<p>The price of admission: the construction is only Lorentz-consistent in <strong><span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>D</mi><mo>=</mo><mn>26</mn></mrow><annotation encoding="application/x-tex">D=26</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord mathnormal" style="margin-right:0.0278em;">D</span><span class="mspace" style="margin-right:0.2778em;"></span><span class="mrel">=</span><span class="mspace" style="margin-right:0.2778em;"></span></span><span class="base"><span class="strut" style="height:0.6444em;"></span><span class="mord">26</span></span></span></span></strong> spacetime dimensions. That is not a choice — it is forced by demanding the quantum theory keep the Lorentz symmetry the classical string had.</p>
<h2 id="why-this-module-exists">Why this module exists</h2>
<p>Modules 7–15 built the bosonic string one tool at a time: the worldsheet action, boundary conditions and D-branes, classical motion, classical light-cone gauge, then the quantum point particle, open string, and closed string. Each module stopped to invent machinery. This module is the <strong>checkpoint</strong>: run the entire chain without stopping, so the logical skeleton stands exposed. If you can narrate "extremize a worldsheet area" all the way to "therefore, a graviton," and say <em>why every step was forced</em>, you have passed.</p>
