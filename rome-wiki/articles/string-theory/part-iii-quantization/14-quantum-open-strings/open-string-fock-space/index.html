    Open-string Fock space

    Build the states of one quantum open string: start from a momentum-labeled ground state, act with creation operators a_n^{I\dagger} , and read the excitation off with the number operator N^\perp=\sum_{n\ge1} n\,a_n^{I\dagger}a_n^I — the same number that will set the mass.

    An infinite bag of oscillators

    A quantized open string is an infinite bag of independent harmonic oscillators — one oscillator for each pair (mode number n≥1n\ge1n≥1, transverse direction III). Everything here is the bookkeeping of that bag:

    • A state is an occupation list. Say how many quanta sit in each oscillator, and you have named the state completely. This is a Fock space — the same construction as photons in a box, just with more oscillators.
    • The center of mass is separate. The string as a whole still flies through spacetime with some momentum; that momentum labels the ground state, so there is a whole continuum of ground states, one per momentum.
    • Each occupation list is a particle species. One string, quantized, is not one particle — it is an entire tower of them.

    Everything below is standard harmonic-oscillator machinery, run once per mode: anI†a_n^{I\dagger}anI†​ raises, anIa_n^IanI​ lowers, the ground state is annihilated by every lowering operator, and "how excited is this state?" is answered by a number operator.

    Ground states: one vacuum per momentum

    The zero modes of the string are the same as those of a free point particle: the center-of-mass position/momentum pairs (x0I,pI)(x_0^I,p^I)(x0I​,pI) and (x0−,p+)(x_0^-,p^+)(x0−​,p+). Nothing oscillates in them, so they carry no excitation — but they do carry the string's overall momentum. We label the ground state by that conserved momentum:

    ∣p+,p⃗T⟩,p⃗T=(p2,…,pD−1).|p^+,\vec p_T\rangle,\qquad \vec p_T=(p^2,\dots,p^{D-1}).∣p+,p​T​⟩,p​T​=(p2,…,pD−1).

    There is not one vacuum but a continuum of them, one for each center-of-mass momentum. This is the vacuum of a single string, not the vacuum of spacetime: a string in its lowest internal state, moving with definite momentum. (An actual localized string is a wavepacket, a superposition ∫dp+ dp⃗T ψ(p+,p⃗T) ∣p+,p⃗T⟩\int dp^+\,d\vec p_T\,\psi(p^+,\vec p_T)\,|p^+,\vec p_T\rangle∫dp+dp​T​ψ(p+,p​T​)∣p+,p​T​⟩ — a wrinkle we can ignore for counting states.)

    Every positive mode annihilates them:

    anI∣p+,p⃗T⟩=0,n≥1, I=2,…,D−1.a_n^I|p^+,\vec p_T\rangle=0,\qquad n\ge1,\ I=2,\dots,D-1.anI​∣p+,p​T​⟩=0,n≥1, I=2,…,D−1.

    This equation is a definition, not a theorem: it selects the representation in which the positive modes anIa_n^IanI​ act as lowering operators and the ground state sits at the bottom of every oscillator tower — the convention set up in Oscillator commutation relations.

    The creation tower and the general state

    The raising operators form a two-dimensional grid: mode number n=1,2,3,…n=1,2,3,\dotsn=1,2,3,… running down the rows, transverse direction I=2,…,D−1I=2,\dots,D-1I=2,…,D−1 running across the columns. (After Critical dimension and the spectrum fixes D=26D=26D=26, the columns become I=2,…,25I=2,\dots,25I=2,…,25, exactly D−2=24D-2=24D−2=24 of them.) A general basis state is built by hitting the ground state with any raising operators, any number of times:

    ∣λ⟩=∏n=1∞∏I=2D−1(anI†)λn,I ∣p+,p⃗T⟩.|\lambda\rangle=\prod_{n=1}^{\infty}\prod_{I=2}^{D-1}\big(a_n^{I\dagger}\big)^{\lambda_{n,I}}\,|p^+,\vec p_T\rangle.∣λ⟩=∏n=1∞​∏I=2D−1​(anI†​)λn,I​∣p+,p​T​⟩.

    The non-negative integer λn,I\lambda_{n,I}λn,I​ is the occupation number: how many quanta sit in the (n,I)(n,I)(n,I) oscillator. Because all raising operators commute (that is [amI†,anJ†]=0[a_m^{I\dagger},a_n^{J\dagger}]=0[amI†​,anJ†​]=0), the order of building doesn't matter — the whole state is fixed by the list {λn,I}\{\lambda_{n,I}\}{λn,I​}, nothing more. Requiring only finitely many λn,I≠0\lambda_{n,I}\neq0λn,I​=0 makes every ∣λ⟩|\lambda\rangle∣λ⟩ a finite excitation; the span of all such lists is the infinite-dimensional string Hilbert space.

    This is where "one string = many particles" becomes concrete. Each distinct occupation list is a genuinely different one-particle state — a different mass, a different spin content — so the single object we quantized describes infinitely many particle species at once.

    The number operator N⊥N^\perpN⊥

    We need one number that measures "how excited" a state is. Define

    N⊥≡∑n=1∞n anI†anI=∑n=1∞α−nIαnIN^\perp\equiv\sum_{n=1}^{\infty} n\,a_n^{I\dagger}a_n^I=\sum_{n=1}^{\infty}\alpha_{-n}^I\alpha_n^IN⊥≡∑n=1∞​nanI†​anI​=∑n=1∞​α−nI​αnI​

    (transverse index III summed; the second form uses α−nI=n anI†\alpha_{-n}^I=\sqrt n\,a_n^{I\dagger}α−nI​=n​anI†​, αnI=n anI\alpha_n^I=\sqrt n\,a_n^IαnI​=n​anI​). The crucial feature is the weight nnn: the (n,I)(n,I)(n,I) oscillator's quanta count nnn each, not 111 each. From the algebra [amI,anJ†]=δmnδIJ[a_m^I,a_n^{J\dagger}]=\delta_{mn}\delta^{IJ}[amI​,anJ†​]=δmn​δIJ one gets

    [N^\perp,a_n^{I\dagger}]=n\,a_n^{I\dagger},\qquad [N^\perp,a_n^{I}]=-n\,a_n^{I}. \tag{1}

    So each raising operator anI†a_n^{I\dagger}anI†​ lifts the N⊥N^\perpN⊥ eigenvalue by its mode number nnn. A single a3I†a_3^{I\dagger}a3I†​ contributes 333 — the same as three separate a1I†a_1^{I\dagger}a1I†​'s. This weighting is what makes N⊥N^\perpN⊥ the right object, and it is the single easiest thing to get wrong (see the exercise).

    Because N⊥N^\perpN⊥ is written with all annihilators on the right, it kills the vacuum, N⊥∣p+,p⃗T⟩=0N^\perp|p^+,\vec p_T\rangle=0N⊥∣p+,p​T​⟩=0. On a general basis state it is diagonal, with eigenvalue equal to the total weighted count:

    N^\perp|\lambda\rangle=N_\lambda^\perp|\lambda\rangle,\qquad N_\lambda^\perp=\sum_{n=1}^\infty\sum_{I=2}^{D-1} n\,\lambda_{n,I}. \tag{2}

    Read (2) as: add up, over every excited oscillator, its mode number times its occupation. For instance N⊥(a3J†a2I†∣p+,p⃗T⟩)=(3+2) a3J†a2I†∣p+,p⃗T⟩N^\perp\big(a_3^{J\dagger}a_2^{I\dagger}|p^+,\vec p_T\rangle\big)=(3+2)\,a_3^{J\dagger}a_2^{I\dagger}|p^+,\vec p_T\rangleN⊥(a3J†​a2I†​∣p+,p​T​⟩)=(3+2)a3J†​a2I†​∣p+,p​T​⟩: the eigenvalue is just the sum of the mode numbers present. This eigenvalue is what other books call the level NNN — same object, and the reason "level matching" has its name. (The open string has only this one tower, so there is no second Nˉ⊥\bar N^\perpNˉ⊥ to match it against; that is a closed-string story.)

    N⊥N^\perpN⊥ earns its keep in the Hamiltonian: it enters through L0⊥=α′pIpI+N⊥L_0^\perp=\alpha'p^Ip^I+N^\perpL0⊥​=α′pIpI+N⊥ (natural units, ℏ=c=1\hbar=c=1ℏ=c=1; see Transverse Virasoro operators), and it is exactly the quantity that sets the mass — the payoff worked out in Mass formula and excitation level, where α′M2=N⊥−1\alpha'M^2=N^\perp-1α′M2=N⊥−1. Every rung of the excitation ladder is a rung of the mass tower.

    No ghosts: every state has positive norm

    Bras are Hermitian conjugates of kets, and the ground states are orthonormal in the continuum sense:

    \langle p'^+,\vec p_T'\,|\,p^+,\vec p_T\rangle=\delta(p'^+-p^+)\,\delta^{D-2}(\vec p_T'-\vec p_T). \tag{3}

    To compute any overlap ⟨λ′∣λ⟩\langle\lambda'|\lambda\rangle⟨λ′∣λ⟩, push the annihilators to the right until they hit the ground state and die, using [amI,anJ†]=δmnδIJ[a_m^I,a_n^{J\dagger}]=\delta_{mn}\delta^{IJ}[amI​,anJ†​]=δmn​δIJ. Every commutator spent puts down a +δIJ+\delta^{IJ}+δIJ, never a minus sign: distinct occupation lists come out orthogonal, and every norm comes out positive — ⟨λ∣λ⟩=∏n,Iλn,I!\langle\lambda|\lambda\rangle=\prod_{n,I}\lambda_{n,I}!⟨λ∣λ⟩=∏n,I​λn,I​! times the momentum deltas. Concretely, for ∣λ′⟩=a1I†∣p′+,p⃗T′⟩|\lambda'\rangle=a_1^{I\dagger}|p'^+,\vec p_T'\rangle∣λ′⟩=a1I†​∣p′+,p​T′​⟩ and ∣λ⟩=a1J†∣p+,p⃗T⟩|\lambda\rangle=a_1^{J\dagger}|p^+,\vec p_T\rangle∣λ⟩=a1J†​∣p+,p​T​⟩,

    \langle\lambda'|\lambda\rangle=\langle p'^+,\vec p_T'|\,a_1^{I}a_1^{J\dagger}\,|p^+,\vec p_T\rangle=\delta^{IJ}\,\delta(p'^+-p^+)\,\delta^{D-2}(\vec p_T'-\vec p_T). \tag{4}

    Positive definiteness is what light-cone gauge bought us. Only transverse (spacelike) oscillators act, so the metric contracting them is the Euclidean δIJ\delta^{IJ}δIJ, and no state can have negative norm. Contrast the manifestly covariant approach, which keeps a timelike oscillator αn0\alpha_n^0αn0​: there the commutator carries η00=−1\eta^{00}=-1η00=−1 (mostly-plus signature), and the state α−10∣0;p⟩\alpha_{-1}^0|0;p\rangleα−10​∣0;p⟩ — with ∣0;p⟩|0;p\rangle∣0;p⟩ the covariant ground state of momentum pμp^\mupμ — has negative norm, ⟨0;p′∣α10α−10∣0;p⟩∼−δD(p′−p)\langle 0;p'|\alpha_1^0\alpha_{-1}^0|0;p\rangle\sim-\delta^D(p'-p)⟨0;p′∣α10​α−10​∣0;p⟩∼−δD(p′−p). Such negative-norm states are called ghosts, and removing them is extra work. Light-cone gauge never lets them in — the trade we made was giving up manifest Lorentz invariance to get a clean Hilbert space.

    Time evolution

    Each basis state evolves by the Schrödinger equation with the light-cone Hamiltonian H=L0⊥−1H=L_0^\perp-1H=L0⊥​−1 (see Mass formula and excitation level):

    e^{-i(L_0^\perp-1)\tau}\,|\lambda\rangle. \tag{5}

    The −1-1−1 is the normal-ordering constant a=−1a=-1a=−1, fixed by Lorentz consistency in Light-cone Lorentz anomaly and applied in Critical dimension and the spectrum. Since L0⊥−1=α′pIpI+(N⊥−1)=α′(pIpI+M2)=2α′p+p−L_0^\perp-1=\alpha'p^Ip^I+(N^\perp-1)=\alpha'(p^Ip^I+M^2)=2\alpha'p^+p^-L0⊥​−1=α′pIpI+(N⊥−1)=α′(pIpI+M2)=2α′p+p− by the mass shell, and light-cone gauge set X+=2α′p+τX^+=2\alpha'p^+\tauX+=2α′p+τ, the phase in (5) is exactly p−X+p^-X^+p−X+ — light-cone energy times light-cone time. Evolution in worldsheet time τ\tauτ knows about the particle's mass precisely through N⊥N^\perpN⊥.

    Open questions

    • The overlaps (3)–(4) carry a δ(0)\delta(0)δ(0) from the momentum delta functions, so ⟨λ∣λ⟩\langle\lambda|\lambda\rangle⟨λ∣λ⟩ is formally infinite. It is harmless for counting states (integrate against wavepackets), but this note does not track how it behaves in genuine amplitude computations.
    • Here the order of building the tower never matters because all a†a^\daggera† commute. In the superstring, fermionic oscillators anticommute and order will carry a sign — a flag for later modules.

    Exercise

    The level, not the count. At excitation level N⊥=3N^\perp=3N⊥=3, write down two basis states built from different numbers of creation operators that nonetheless share the same N⊥N^\perpN⊥ eigenvalue, and verify the eigenvalue directly from the algebra [N⊥,anI†]=n anI†[N^\perp,a_n^{I\dagger}]=n\,a_n^{I\dagger}[N⊥,anI†​]=nanI†​. Then say in one line why N⊥N^\perpN⊥ is not just "count the creation operators."

    Solution

    Take ∣A⟩=a3I†∣p+,p⃗T⟩(one creation operator),∣B⟩=a1I†a1J†a1K†∣p+,p⃗T⟩(three).|A\rangle=a_3^{I\dagger}|p^+,\vec p_T\rangle\quad(\text{one creation operator}),\qquad |B\rangle=a_1^{I\dagger}a_1^{J\dagger}a_1^{K\dagger}|p^+,\vec p_T\rangle\quad(\text{three}).∣A⟩=a3I†​∣p+,p​T​⟩(one creation operator),∣B⟩=a1I†​a1J†​a1K†​∣p+,p​T​⟩(three). Apply N⊥N^\perpN⊥ using (1). For ∣A⟩|A\rangle∣A⟩: since N⊥∣p+,p⃗T⟩=0N^\perp|p^+,\vec p_T\rangle=0N⊥∣p+,p​T​⟩=0, N⊥a3I†∣p+,p⃗T⟩=[N⊥,a3I†]∣p+,p⃗T⟩=3 a3I†∣p+,p⃗T⟩,N^\perp a_3^{I\dagger}|p^+,\vec p_T\rangle=[N^\perp,a_3^{I\dagger}]|p^+,\vec p_T\rangle=3\,a_3^{I\dagger}|p^+,\vec p_T\rangle,N⊥a3I†​∣p+,p​T​⟩=[N⊥,a3I†​]∣p+,p​T​⟩=3a3I†​∣p+,p​T​⟩, so NA⊥=3N^\perp_A=3NA⊥​=3. For ∣B⟩|B\rangle∣B⟩, commute N⊥N^\perpN⊥ through all three operators; each a1†a_1^{\dagger}a1†​ contributes its mode number 111: N⊥a1I†a1J†a1K†∣p+,p⃗T⟩=(1+1+1) a1I†a1J†a1K†∣p+,p⃗T⟩,N^\perp a_1^{I\dagger}a_1^{J\dagger}a_1^{K\dagger}|p^+,\vec p_T\rangle=(1+1+1)\,a_1^{I\dagger}a_1^{J\dagger}a_1^{K\dagger}|p^+,\vec p_T\rangle,N⊥a1I†​a1J†​a1K†​∣p+,p​T​⟩=(1+1+1)a1I†​a1J†​a1K†​∣p+,p​T​⟩, so NB⊥=3N^\perp_B=3NB⊥​=3. Both sit at level 333 despite ∣A⟩|A\rangle∣A⟩ having one quantum and ∣B⟩|B\rangle∣B⟩ having three.

    Why counting fails: N⊥N^\perpN⊥ weights each quantum by its mode number nnn, not by 111 — it sums ∑nn λn,I\sum_n n\,\lambda_{n,I}∑n​nλn,I​, not ∑nλn,I\sum_n \lambda_{n,I}∑n​λn,I​. A single high-mode quantum (n=3n=3n=3) carries as much level as three low-mode quanta (n=1n=1n=1). Equivalently, N⊥N^\perpN⊥ is the total energy of the oscillator bag in units where mode nnn has frequency nnn, not the total particle number. (This degeneracy at fixed N⊥N^\perpN⊥ is exactly the multiplicity that populates each mass level in Critical dimension and the spectrum.)
