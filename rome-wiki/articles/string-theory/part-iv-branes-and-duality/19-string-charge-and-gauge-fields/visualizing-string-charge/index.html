    Visualizing string charge

    String charge is a current running down a wire, not charge smeared along a line: a divergenceless vector that cannot stop in empty space, so strings close, run to infinity, or end only where something else picks up the current.

    You count a point charge by enclosing it in a sphere and measuring the flux out; you count a string by linking it with a loop and measuring the circulation around. Same topological idea, one dimension up. This is the geometric picture behind Fundamental string charge, and it turns the open-string endpoint into a genuine puzzle for Endpoint charge.

    Why "current," not "line charge"

    From Fundamental string charge the charge density j⃗ 0\vec j^{\,0}j​0 is supported only on the string, is a vector pointing along it, and obeys

    \nabla\cdot\vec j^{\,0}=0. \tag{1}

    These are exactly the properties of a steady current in magnetostatics. There, charge conservation ∂tρ+∇⋅j⃗=0\partial_t\rho+\nabla\cdot\vec j=0∂t​ρ+∇⋅j​=0 with a time-independent ρ\rhoρ forces ∇⋅j⃗=0\nabla\cdot\vec j=0∇⋅j​=0: current in equals current out of every little box. Here ∇⋅j⃗ 0=0\nabla\cdot\vec j^{\,0}=0∇⋅j​0=0 holds even for moving strings, so string charge is always magnetostatic in character.

    So the string is a wire carrying current down its length, not a smear of static charge sitting on it. A divergenceless current has nowhere to dump itself; like an incompressible flow, its lines cannot terminate. A real current-carrying wire either closes into a loop or runs off to infinity, and the string inherits the same constraint, before D-branes enter:

    String-charge conservation forces every string to be a closed loop or infinitely long.

    A string that simply ended in empty space would be a current that stops: the flow lines would have a source or sink at the endpoint, violating (1). A string can end on a D-brane, but only because electric flux on the brane picks up the current where the string drops it, the resolution in Endpoint charge.

    The dual "magnetic" field: string charge is Ampère's law

    Work in four spacetime dimensions with static strings, so the purely spatial current jik=0j^{ik}=0jik=0. The Kalb-Ramond field equation ∂ρHμνρ=κ2jμν\partial_\rho H^{\mu\nu\rho}=\kappa^2 j^{\mu\nu}∂ρ​Hμνρ=κ2jμν then splits into a trivial piece and one live equation,

    \partial_l H^{0kl}=\kappa^2\,j^{0k}. \tag{2}

    The object H0klH^{0kl}H0kl is antisymmetric in its two spatial indices k,lk,lk,l, so in three spatial dimensions it has exactly three independent components. Package them as a vector B⃗H\vec B_HBH​:

    H^{0kl}=\epsilon^{kln}B_{H\,n},\qquad \epsilon^{123}=1. \tag{3}

    Substituting (3) into (2) and using ϵkln∂lBH n=(∇×B⃗H)k\epsilon^{kln}\partial_l B_{H\,n}=(\nabla\times\vec B_H)_kϵkln∂l​BHn​=(∇×BH​)k​ gives

    \boxed{\;\nabla\times\vec B_H=\kappa^2\,\vec j^{\,0}\;} \tag{4}

    This is Ampère's law: a "magnetic" field B⃗H\vec B_HBH​ curling around the current κ2j⃗ 0\kappa^2\vec j^{\,0}κ2j​0. The Kalb–Ramond field strength of a static string has been repackaged as the magnetic field of a wire, so magnetostatics intuition transfers wholesale. B⃗H\vec B_HBH​ circulates around the string exactly as a real B⃗\vec BB circulates around a current-carrying wire.

    Integrate (4) over a surface SSS bounded by a curve Γ\GammaΓ and apply Stokes' theorem:

    \frac{1}{\kappa^2}\oint_\Gamma\vec B_H\cdot d\vec\ell=\int_S\vec j^{\,0}\cdot d\vec a. \tag{5}

    This turns "no loose ends" into a theorem. The left side depends only on the curve Γ\GammaΓ, while the right side is a surface integral, so consistency demands that its value not depend on which surface SSS caps Γ\GammaΓ. That independence is precisely ∇⋅j⃗ 0=0\nabla\cdot\vec j^{\,0}=0∇⋅j​0=0: two surfaces sharing the boundary Γ\GammaΓ enclose a volume, and the difference of their fluxes is ∫∇⋅j⃗ 0=0\int\nabla\cdot\vec j^{\,0}=0∫∇⋅j​0=0. If a string ended in empty space, j⃗ 0\vec j^{\,0}j​0 would have a source there, the flux would jump depending on which side of the endpoint the surface passed, and (5) would be contradictory. One can read the same fact off (4) directly: ∇⋅(∇×B⃗H)=0\nabla\cdot(\nabla\times\vec B_H)=0∇⋅(∇×BH​)=0 identically forces κ2∇⋅j⃗ 0=0\kappa^2\nabla\cdot\vec j^{\,0}=0κ2∇⋅j​0=0, so the consistency of the curl equation is the conservation law.

    Counting strings: the string number N\mathcal NN

    The circulation of B⃗H\vec B_HBH​ around a loop counts the strings threading it. Define

    \tfrac12\,\mathcal N\equiv\frac{1}{\kappa^2}\oint_\Gamma\vec B_H\cdot d\vec\ell=\int_S\vec j^{\,0}\cdot d\vec a. \tag{6}

    N\mathcal NN is the signed number of strings that the loop Γ\GammaΓ links, the string analog of the charge QQQ enclosed by a Gaussian surface. Check it on the simplest case, one infinite string along x1x^1x1 with orientation f′>0f'>0f′>0, where j01=12 δ(x2) δ(x3)j^{01}=\tfrac12\,\delta(x^2)\,\delta(x^3)j01=21​δ(x2)δ(x3). Thread it with a loop Γ\GammaΓ in a constant-x1x^1x1 plane, oriented so its surface normal points along +x1+x^1+x1:

    \tfrac12\,\mathcal N=\int_S j^{01}\,dx^2\,dx^3=\tfrac12\int_S\delta(x^2)\,\delta(x^3)\,dx^2\,dx^3=\tfrac12\quad\Longrightarrow\quad\mathcal N=1. \tag{7}

    One string linked, N=1\mathcal N=1N=1, as it must be. The two factors of 12\tfrac1221​ cancel to give a clean integer count: one is built into j01j^{01}j01 (the 12\tfrac1221​ in the string current, tracked in Fundamental string charge), the other is in the definition 12N\tfrac12\mathcal N21​N, and that cancellation is the whole reason the 12\tfrac1221​ was carried along. Orientation is physical here: reverse the string and j01j^{01}j01 flips sign, so a loop linking two oppositely oriented strings gets N=0\mathcal N=0N=0, the contributions canceling just as ±\pm± charges cancel inside a Gaussian surface.

    Linking is not special to three dimensions; only the vector B⃗H\vec B_HBH​ is. In ddd spatial dimensions a string is a line, its transverse space is (d−1)(d-1)(d−1)-dimensional, and the surface surrounding those transverse directions is a sphere Sd−2S^{d-2}Sd−2. For d=3d=3d=3 that is the S1S^1S1 loop above; for d=4d=4d=4, a string along x1x^1x1 is linked by the 2-sphere (x2)2+(x3)2+(x4)2=R2at fixed x1,(x^2)^2+(x^3)^2+(x^4)^2=R^2\quad\text{at fixed }x^1,(x2)2+(x3)2+(x4)2=R2at fixed x1, which you cannot shrink to a point without dragging it through the string. That inability to pull the sphere off is what linking means, in any dimension.

    The dictionary: enclosing vs. linking

    Maxwell point charge Fundamental string
    charge density ρ=j0\rho=j^0ρ=j0 (scalar) charge density j⃗ 0\vec j^{\,0}j​0 (vector, along the string)
    couples to AμA_\muAμ​ (1 index) couples to BμνB_{\mu\nu}Bμν​ (2 indices)
    enclosed by a sphere S2S^2S2 linked by a loop S1S^1S1

    The last two rows carry the whole content: enclosing a point and linking a line are the same topological statement, shifted up one dimension in the charged object. A point charge is trapped inside a codimension-one sphere; a string is trapped inside a loop threaded around it. This is why the string is the honest one-dimensional generalization of a charged particle, and why its natural gauge field carries one extra index. Measure a particle by the flux it pushes out; measure a string by the field that swirls around.

    Open questions

    • The one-string calculation (7) checks that N\mathcal NN counts links. The general statement, that N\mathcal NN is invariant under smooth deformations of Γ\GammaΓ that do not cross a string, is a linking-number and homology fact taken on faith here.
    • B⃗H\vec B_HBH​ as a vector is a four-dimensional luxury: it needs H0klH^{0kl}H0kl to have exactly three components. In general DDD the same content lives in the two-form HHH itself, with the linking sphere an SD−3S^{D-3}SD−3 and the circulation an integral of HHH over it.
    • With D-branes present, "no endpoints" softens to "no uncancelled endpoints": electric flux on the brane worldvolume carries exactly the current the string drops at its end. That handoff is Endpoint charge and Maxwell fields on branes.

    Exercise

    Two parallel infinite strings run along the x1x^1x1 axis (three spatial dimensions). String A has orientation f′>0f'>0f′>0; string B is antiparallel, f′<0f'<0f′<0. A loop Γ\GammaΓ in a constant-x1x^1x1 plane, with normal along +x1+x^1+x1, encircles both.

    (a) Write j⃗ 0\vec j^{\,0}j​0 for the pair and compute N\mathcal NN from (6). (b) Now reverse only Γ\GammaΓ's orientation (normal along −x1-x^1−x1), still encircling both. What is N\mathcal NN? State the general rule your two answers illustrate.

    Solution

    (a) For a single string along x1x^1x1 the current is j01=12 sgn(f′) δ(x2) δ(x3)j^{01}=\tfrac12\,\mathrm{sgn}(f')\,\delta(x^2)\,\delta(x^3)j01=21​sgn(f′)δ(x2)δ(x3), with the sign set by orientation. Place A at the transverse origin and B at transverse position (b2,b3)(b_2,b_3)(b2​,b3​). Superposing: j01=12 δ(x2)δ(x3)  +  (−12) δ(x2−b2)δ(x3−b3).j^{01}=\tfrac12\,\delta(x^2)\delta(x^3)\;+\;\bigl(-\tfrac12\bigr)\,\delta(x^2-b_2)\delta(x^3-b_3).j01=21​δ(x2)δ(x3)+(−21​)δ(x2−b2​)δ(x3−b3​). With the normal along +x1+x^1+x1, equation (6) gives 12 N=∫Sj01 dx2 dx3=12−12=0⟹N=0.\tfrac12\,\mathcal N=\int_S j^{01}\,dx^2\,dx^3=\tfrac12-\tfrac12=0\quad\Longrightarrow\quad\mathcal N=0.21​N=∫S​j01dx2dx3=21​−21​=0⟹N=0. The oppositely oriented strings contribute +1+1+1 and −1-1−1, and they cancel. The two current-wires' B⃗H\vec B_HBH​ fields cancel their net circulation around Γ\GammaΓ, like two antiparallel wires carrying equal and opposite currents.

    (b) Reversing Γ\GammaΓ flips the sign of the surface normal, hence of da⃗d\vec ada and of every term in the integral: each string's contribution changes sign (+1→−1+1\to-1+1→−1 and −1→+1-1\to+1−1→+1). The sum is still 000, so N=0\mathcal N=0N=0 again.

    Rule. N\mathcal NN is the signed count of linked strings: a string counts +1+1+1 or −1-1−1 according to whether its orientation agrees with the loop's, and reversing the loop flips the sign of the whole count. Only the relative orientation of string and loop is physical. Antiparallel strings threaded by one loop are invisible to N\mathcal NN, exactly as ±q\pm q±q inside a Gaussian surface give zero enclosed charge.
