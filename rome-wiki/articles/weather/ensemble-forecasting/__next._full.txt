17:T1a02,<h2 id="why">Why</h2>
<p>A single deterministic run gives you a number with no error bar. But the initial state and the model are both imperfect, and the atmosphere is chaotic (<a href="/rome-wiki/articles/weather/atmospheric-predictability-limit/" class="wiki-link">Atmospheric predictability limit</a>), so nearby starts diverge. An <strong>ensemble</strong> samples that divergence: perturb the inputs, run <span class="katex"><span class="katex-mathml"><math xmlns="http://www.w3.org/1998/Math/MathML"><semantics><mrow><mi>N</mi></mrow><annotation encoding="application/x-tex">N</annotation></semantics></math></span><span class="katex-html" aria-hidden="true"><span class="base"><span class="strut" style="height:0.6833em;"></span><span class="mord mathnormal" style="margin-right:0.109em;">N</span></span></span></span> forecasts, and read the resulting distribution as a probability forecast.</p>

<p>Two sources of error get perturbed:</p>
<ul>
<li><strong>Initial conditions</strong> — ECMWF: singular vectors (fastest-growing perturbations) + an Ensemble of Data Assimilations (EDA); NCEP: an ensemble Kalman filter.</li>
<li><strong>Model error</strong> — <em>stochastic physics</em>. ECMWF now uses <strong>SPP</strong> (Stochastically Perturbed Parametrizations), which <strong>replaced SPPT in Nov 2024</strong>; GEFS uses SPPT + SKEB. (SPPT is still the canonical textbook example.)</li>
</ul>
<h2 id="reading-the-spread-calibration">Reading the spread: calibration</h2>
<p>A <strong>well-calibrated</strong> ensemble is <em>statistically consistent</em>: the RMS ensemble spread should match the <strong>RMSE of the ensemble mean</strong>. In practice ensembles tend to be <strong>under-dispersive</strong> — too confident — which is why raw spread is often statistically post-processed before it becomes a probability.</p>
<p>Standard scoring tools:</p>
<ul>
<li><strong>CRPS</strong> — Continuous Ranked Probability Score; generalizes <a href="/rome-wiki/articles/weather/temperature-forecast-confidence-intervals/" class="wiki-link">MAE</a> to a full predictive distribution.</li>
<li><strong>Brier score</strong> — MSE of probability forecasts for a binary event.</li>
<li><strong>Rank (Talagrand) histogram</strong> — flat = calibrated, U-shaped = under-dispersive.</li>
<li><strong>Reliability diagram</strong> — observed frequency vs forecast probability; on the diagonal = reliable.</li>
</ul>
<p>The guiding principle (Gneiting, Balabdaoui &#x26; Raftery 2007): <strong>maximize sharpness subject to calibration</strong> — be as confident as you can while still being honest.</p>
<h2 id="why-this-matters-downstream">Why this matters downstream</h2>
<p>The ensemble is what turns "80°F" into a <em>flow-dependent</em> band: tight in a stable regime, wide before a front. A fixed rule-of-thumb interval (<a href="/rome-wiki/articles/weather/temperature-forecast-confidence-intervals/" class="wiki-link">Temperature forecast confidence intervals</a>) is really just the ensemble spread <em>averaged over all regimes</em>.</p>

<li>Singular vectors vs EDA vs EnKF: when does each best capture the true initial uncertainty?</li>
