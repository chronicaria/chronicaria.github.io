    Endpoint velocity and endpoint force

    A free open-string endpoint has nowhere to send the string's tension, and the only way to balance the books is for the end to whip sideways through space at the speed of light .

    Twirl a straight open string like a baton, pinned at the center, spinning in a plane. The middle barely moves; the two tips race around a circle. Push the tips to the fastest speed physics allows and you have a free relativistic string endpoint: forever moving at ccc, forever perpendicular to the string, like the crack of a whip that never slows down. This note proves the motion is forced, not merely allowed.

    Why "velocity" is subtle in the interior but clean at the endpoints

    A string has no substructure — no painted dots to track from one instant to the next. The naive velocity ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t points "along constant σ\sigmaσ," but σ\sigmaσ is our own arbitrary ruling of the string (Static gauge fixed τ=t\tau=tτ=t but left σ\sigmaσ free). Slide the labels along the string and ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t tilts, even though the string itself did nothing. Longitudinal reparameterization is pure gauge, so the direction of this velocity is not physical.

    The cure is the transverse velocity v⃗⊥\vec v_\perpv⊥​: the part of ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t perpendicular to the string. It needs no σ\sigmaσ-choice — it is the rate at which the string, seen as a curve in space, sweeps sideways. Sliding labels along the curve cannot fake it.

    Building v⃗⊥\vec v_\perpv⊥​

    Measure position along the string by arc length sss, so ds=∣∂X⃗/∂σ∣ ∣dσ∣ds = |\partial\vec X/\partial\sigma|\,|d\sigma|ds=∣∂X/∂σ∣∣dσ∣, and orient σ\sigmaσ so that sss grows with it. Then ∂X⃗/∂s\partial\vec X/\partial s∂X/∂s is a unit tangent: differentiating position by distance-along-the-curve gives a unit vector pointing along the curve, because

    ∂X⃗∂s⋅∂X⃗∂s=∣∂X⃗∂σ∣2(dσds)2=1.\frac{\partial\vec X}{\partial s}\cdot\frac{\partial\vec X}{\partial s} = \Big|\frac{\partial\vec X}{\partial\sigma}\Big|^2\Big(\frac{d\sigma}{ds}\Big)^2 = 1.∂s∂X​⋅∂s∂X​=​∂σ∂X​​2(dsdσ​)2=1.

    Write n^≡∂X⃗/∂s\hat n \equiv \partial\vec X/\partial sn^≡∂X/∂s for this unit tangent. The transverse velocity is ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t with its component along n^\hat nn^ subtracted off — the standard "kill the parallel part" projection u⃗−(u⃗⋅n^)n^\vec u - (\vec u\cdot\hat n)\hat nu−(u⋅n^)n^:

    \vec v_\perp = \frac{\partial\vec X}{\partial t} - \Big(\frac{\partial\vec X}{\partial t}\cdot\hat n\Big)\hat n. \tag{1}

    Squaring (1), the cross term and the (u⃗⋅n^)2(\vec u\cdot\hat n)^2(u⋅n^)2 term combine, using n^⋅n^=1\hat n\cdot\hat n = 1n^⋅n^=1, to leave

    v_\perp^2 = \Big(\frac{\partial\vec X}{\partial t}\Big)^2 - \Big(\frac{\partial\vec X}{\partial t}\cdot\hat n\Big)^2. \tag{2}

    This is Pythagoras: (full speed)2^22 minus (speed along the string)2^22.

    The action in terms of v⊥v_\perpv⊥​

    Feed the static-gauge tangents into the Nambu–Goto action. With Xμ=(ct,X⃗)X^\mu = (ct,\vec X)Xμ=(ct,X) and η=diag(−,+,…,+)\eta = \mathrm{diag}(-,+,\dots,+)η=diag(−,+,…,+) (mostly-plus signature),

    (X˙)2=−c2+(∂X⃗∂t)2,(X′)2=(∂X⃗∂σ)2,X˙ ⁣⋅X′=∂X⃗∂t⋅∂X⃗∂σ.(\dot X)^2 = -c^2 + \Big(\frac{\partial\vec X}{\partial t}\Big)^2, \qquad (X')^2 = \Big(\frac{\partial\vec X}{\partial\sigma}\Big)^2, \qquad \dot X\!\cdot X' = \frac{\partial\vec X}{\partial t}\cdot\frac{\partial\vec X}{\partial\sigma}.(X˙)2=−c2+(∂t∂X​)2,(X′)2=(∂σ∂X​)2,X˙⋅X′=∂t∂X​⋅∂σ∂X​.

    Substituting these into the Nambu–Goto radicand and using (2) plus ∂X⃗/∂σ=(ds/dσ) n^\partial\vec X/\partial\sigma = (ds/d\sigma)\,\hat n∂X/∂σ=(ds/dσ)n^, the mess collapses into a single relativistic factor:

    \sqrt{(\dot X\!\cdot X')^2 - (\dot X)^2(X')^2} = c\,\frac{ds}{d\sigma}\sqrt{1 - \frac{v_\perp^2}{c^2}}. \tag{3}

    So the action and Lagrangian become

    S = -T_0\int dt\int_0^{\sigma_1}\!d\sigma\,\frac{ds}{d\sigma}\sqrt{1-\frac{v_\perp^2}{c^2}}, \qquad L = -T_0\int ds\,\sqrt{1-\frac{v_\perp^2}{c^2}}. \tag{4}

    The Lagrangian reads off cleanly. Each length dsdsds carries rest energy T0 dsT_0\,dsT0​ds (from String tension and the energy of a stretched string, where μ0c2=T0\mu_0 c^2 = T_0μ0​c2=T0​), and L=− ⁣∫(rest energy)1−v⊥2/c2L = -\!\int(\text{rest energy})\sqrt{1-v_\perp^2/c^2}L=−∫(rest energy)1−v⊥2​/c2​ is the string version of the relativistic point particle L=−mc21−v2/c2L=-mc^2\sqrt{1-v^2/c^2}L=−mc21−v2/c2​. Only the transverse speed appears; longitudinal sliding is gauge and correctly drops out.

    Endpoint motion: the two theorems

    Free (Neumann) endpoints are those with Pμσ=0\mathcal P^\sigma_\mu = 0Pμσ​=0 at σ=0,σ1\sigma=0,\sigma_1σ=0,σ1​ — see Neumann versus Dirichlet conditions, where Pμσ=∂L/∂X′μ\mathcal P^\sigma_\mu = \partial\mathcal L/\partial X'^\muPμσ​=∂L/∂X′μ is computed for the Nambu–Goto action. Substitute the static-gauge tangents into that expression, use (3) as the denominator, and trade every σ\sigmaσ-derivative for an sss-derivative — the factors of ds/dσds/d\sigmads/dσ cancel — to get

    \vec{\mathcal P}^\sigma = -\frac{T_0}{c^2}\,\frac{\Big(\hat n\cdot\dfrac{\partial\vec X}{\partial t}\Big)\dfrac{\partial\vec X}{\partial t} + \bigg(c^2 - \Big(\dfrac{\partial\vec X}{\partial t}\Big)^{\!2}\bigg)\hat n}{\sqrt{1-v_\perp^2/c^2}}, \qquad \mathcal P^{\sigma\,0} = -\frac{T_0}{c}\,\frac{\hat n\cdot(\partial\vec X/\partial t)}{\sqrt{1-v_\perp^2/c^2}}. \tag{5}

    The arbitrary σ\sigmaσ is gone: everything is built from the unit tangent n^\hat nn^ and the velocity ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t. Two facts fall out — one from the time component, one from the space components.

    (1) The velocity is transverse. The time component Pσ 0\mathcal P^{\sigma\,0}Pσ0 must vanish at the end. Its denominator is at most 111, so it cannot rescue a nonzero numerator — the numerator itself vanishes:

    \hat n\cdot\frac{\partial\vec X}{\partial t} = 0 \quad\text{at the endpoints.} \tag{6}

    The unit tangent n^\hat nn^ and the endpoint velocity ∂X⃗/∂t\partial\vec X/\partial t∂X/∂t are orthogonal — the end moves perpendicular to the string. Feeding (6) back into (1), the subtracted term dies and v⃗⊥=∂X⃗/∂t≡v⃗\vec v_\perp = \partial\vec X/\partial t \equiv \vec vv⊥​=∂X/∂t≡v: at a free end the velocity is entirely transverse, and we may write vvv for v⊥v_\perpv⊥​ interchangeably there.

    (2) The speed is ccc. Now the space components. Transversality (6) wipes out the first term in the numerator of P⃗σ\vec{\mathcal P}^\sigmaPσ, and in what survives (∂X⃗/∂t)2=v⊥2=v2(\partial\vec X/\partial t)^2 = v_\perp^2 = v^2(∂X/∂t)2=v⊥2​=v2, so c2−v2c^2 - v^2c2−v2 cancels against the square root:

    \vec{\mathcal P}^\sigma = -\frac{T_0}{c^2}\,\frac{(c^2 - v^2)\,\hat n}{\sqrt{1-v^2/c^2}} = -T_0\sqrt{1-\frac{v^2}{c^2}}\,\hat n = 0 \quad\text{at the endpoints.} \tag{7}

    But n^\hat nn^ is a unit vector — never zero. The product can only vanish if the square root does:

    \boxed{\,v^2 = c^2\,} \tag{8}

    Free open-string endpoints move at the speed of light. And it is forced, not optional. Equation (6) by itself would be satisfied trivially by a motionless end (v⃗=0\vec v = 0v=0), but a motionless end makes 1−v2/c2=1\sqrt{1-v^2/c^2}=11−v2/c2​=1, so P⃗σ=−T0n^≠0\vec{\mathcal P}^\sigma = -T_0\hat n \ne 0Pσ=−T0​n^=0 and the Neumann condition (7) fails. The only escape is v=cv=cv=c. The whip must crack.

    Why this is not a paradox. A massive particle at v=cv=cv=c would cost infinite energy — but the tip is not a massive particle. The Hamiltonian built from (4) assigns each piece of string the energy T0 ds/1−v⊥2/c2T_0\,ds/\sqrt{1-v_\perp^2/c^2}T0​ds/1−v⊥2​/c2​: rest energy times the usual relativistic factor. Approaching the tip, 1−v⊥2/c21-v_\perp^2/c^21−v⊥2​/c2 vanishes linearly in the remaining arc length δ\deltaδ, so the energy density diverges like δ−1/2\delta^{-1/2}δ−1/2 — but integrably: the last δ\deltaδ of string has rest energy only T0 δT_0\,\deltaT0​δ and carries total energy ∼T0δ→0\sim T_0\sqrt{\delta}\to 0∼T0​δ​→0. The tip itself has no rest mass to boost (the string is made of pure tension — see String tension and the energy of a stretched string), and a massless thing is allowed to move at ccc. The exercise runs the same numerator-versus-denominator race for Pσ 0\mathcal P^{\sigma\,0}Pσ0 in (5), which becomes a 0/00/00/0 form at the end.

    "Endpoint force": where the tension goes

    The v=cv=cv=c theorem is momentum bookkeeping at the end. Pμσ\mathcal P^\sigma_\muPμσ​ is the flux of μ\muμ-momentum flowing along the string toward the endpoint — the tension's pull, carried outward. At a free end there is nothing beyond the tip to push against, so this flux must vanish: Pμσ=0\mathcal P^\sigma_\mu = 0Pμσ​=0. The string cannot dump its longitudinal pull into empty space, so it converts it into transverse motion at the maximum allowed speed. That is theorem (8), reread as force balance.

    At a fixed (Dirichlet) end the story flips: Pμσ≠0\mathcal P^\sigma_\mu \ne 0Pμσ​=0 is allowed, and that nonzero flux is the force the string exerts on whatever holds it — a D-brane. Momentum leaks from string into brane. This is the hinge between this note and Neumann versus Dirichlet conditions / D-branes (first appearance): which directions are free (transverse, at ccc) versus pinned (force absorbed) is exactly the data that defines a brane's worldvolume.

    What changes on a Dp-brane

    The v=cv=cv=c theorem assumed the end is free in all spatial directions — a space-filling brane. On a Dppp-brane with p<dp<dp<d, only brane-tangent directions are Neumann; the normal directions are Dirichlet and can absorb force. The blanket "every free end moves at ccc" softens to

    1−v2c2 n^∥=0,\sqrt{1-\frac{v^2}{c^2}}\,\hat n_\parallel = 0,1−c2v2​​n^∥​=0,

    where n^∥\hat n_\paralleln^∥​ is the projection of the tangent n^\hat nn^ onto the brane. An end that meets the brane orthogonally (n^∥=0\hat n_\parallel = 0n^∥​=0) may move slower than light; an end whose tangent has any component along the brane is still forced to v=cv=cv=c. The D0/D1/Dppp split is worked out in Endpoint motion on a Dp-brane.

    Open questions

    • A gauge-independent check computes PμσPσμ\mathcal P^\sigma_\mu\mathcal P^{\sigma\mu}Pμσ​Pσμ directly at the endpoint; the static-gauge proof above suffices for this module.
    • v=cv=cv=c is a classical statement. What the always-luminal endpoint means for the quantum open string is deferred to the open-string spectrum modules.

    Exercise

    At a free endpoint, both the numerator and the denominator of Pσ 0\mathcal P^{\sigma\,0}Pσ0 in (5) vanish: the numerator by transversality (6), the denominator because v⊥→cv_\perp \to cv⊥​→c. So Pσ 0\mathcal P^{\sigma\,0}Pσ0 is a 0/00/00/0 form there. Show that it genuinely vanishes — that the numerator wins the race — by comparing how fast each factor goes to zero as the endpoint is approached along the string (s→sends\to s_{\text{end}}s→send​). Assume the geometric quantities are smooth in sss near the end.

    Solution

    Write Pσ 0=−T0c N/D\mathcal P^{\sigma\,0} = -\tfrac{T_0}{c}\,N/DPσ0=−cT0​​N/D with N(s)=n^⋅∂X⃗∂t,D(s)=1−v⊥2c2.N(s) = \hat n\cdot\frac{\partial\vec X}{\partial t}, \qquad D(s) = \sqrt{1 - \frac{v_\perp^2}{c^2}}.N(s)=n^⋅∂t∂X​,D(s)=1−c2v⊥2​​​. Both vanish at the end: N→0N\to 0N→0 is transversality (6), and D→0D\to 0D→0 because v⊥→cv_\perp\to cv⊥​→c — at the end the velocity is entirely transverse with v=cv=cv=c.

    Denominator rate. Since v⊥2→c2v_\perp^2 \to c^2v⊥2​→c2 smoothly, write v⊥2/c2=1−ϵ(s)v_\perp^2/c^2 = 1 - \epsilon(s)v⊥2​/c2=1−ϵ(s) with ϵ→0\epsilon\to 0ϵ→0 linearly in the distance δ≡send−s\delta \equiv s_{\text{end}}-sδ≡send​−s (generic smooth approach, ϵ∼k δ\epsilon \sim k\,\deltaϵ∼kδ with k>0k>0k>0). Then D=ϵ∼k δD = \sqrt{\epsilon} \sim \sqrt{k\,\delta}D=ϵ​∼kδ​ — a square-root (slow) approach to zero.

    Numerator rate. NNN is a smooth function of sss that hits zero at the end, so Taylor expansion gives N=O(δ)N = O(\delta)N=O(δ): generically a simple zero, N∼m δN \sim m\,\deltaN∼mδ, and any faster vanishing only helps.

    The race. Therefore Pσ 0∼δ1δ1/2=δ1/2→0.\mathcal P^{\sigma\,0} \sim \frac{\delta^{1}}{\delta^{1/2}} = \delta^{1/2} \to 0.Pσ0∼δ1/2δ1​=δ1/2→0. The numerator's linear zero beats the denominator's square-root zero, so the ratio vanishes — the boundary condition Pσ 0=0\mathcal P^{\sigma\,0}=0Pσ0=0 holds honestly, not as an artifact of writing 0/00/00/0. The same rates run the energy budget: each piece of string carries energy T0 ds/DT_0\,ds/DT0​ds/D, so the last δ\deltaδ of string holds ∼T0 ⁣∫0δds/k s∼T0δ→0\sim T_0\!\int_0^\delta ds/\sqrt{k\,s} \sim T_0\sqrt{\delta} \to 0∼T0​∫0δ​ds/ks​∼T0​δ​→0 — the luminal tip is massless and costs nothing.
