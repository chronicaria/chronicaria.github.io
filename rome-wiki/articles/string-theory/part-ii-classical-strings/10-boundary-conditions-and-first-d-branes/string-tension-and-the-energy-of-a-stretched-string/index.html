    String tension and the energy of a stretched string

    Evaluating the Nambu–Goto action for a static stretched string gives an energy V = T_0\,a , proportional to length — which is why T_0 deserves the name "tension" and why the rest mass per unit length must be \mu_0 = T_0/c^2 .

    What stretching costs

    Stretch an open string to length aaa and hold it there. The energy that costs is T0 aT_0\,aT0​a: each additional unit of length costs the same T0T_0T0​, however long the string already is. A constant cost per unit length is exactly what "tension" means — a restoring force that never grows, an idealized rubber band with no stiffening. T0T_0T0​ is the first genuine quantity string theory computes, and this note is the short calculation that produces it.

    The calculation has a payoff. Stored energy is rest mass (E=mc2E=mc^2E=mc2), so the relativistic string has mass only because it has tension. Turn off T0T_0T0​ and the string is massless — there is no separate "stuff" carrying its own weight.

    Setup: a string frozen along one axis

    Pin the two endpoints of an open string at x1=0x^1 = 0x1=0 and x1=a>0x^1 = a>0x1=a>0, with every other spatial coordinate zero — so the endpoints sit at (0,0⃗)(0,\vec 0)(0,0) and (a,0⃗)(a,\vec 0)(a,0) and the string is stretched only along x1x^1x1. Work in Static gauge, X0=cτX^0 = c\tauX0=cτ, so worldsheet time equals lab time.

    Label the material points of the static string by a strictly increasing function fff:

    X1(t,σ)=f(σ),X2=⋯=Xd=0,f(0)=0, f(σ1)=a.X^1(t,\sigma) = f(\sigma),\quad X^2 = \cdots = X^d = 0,\qquad f(0)=0,\ f(\sigma_1)=a.X1(t,σ)=f(σ),X2=⋯=Xd=0,f(0)=0, f(σ1​)=a.

    "Strictly increasing" just means each bead of string gets its own σ\sigmaσ. The configuration is a straight segment from 000 to aaa on the x1x^1x1-axis, and fff is nothing but a choice of ruler laid along it. The final answer will forget fff entirely.

    The two worldsheet tangents

    Nothing moves and nothing happens off the x1x^1x1-axis, so the τ\tauτ-tangent is pure time and the σ\sigmaσ-tangent is pure stretch:

    X˙μ=(c, 0, 0⃗),X′μ=(0, f′, 0⃗),f′=dfdσ>0.\dot X^\mu = (c,\,0,\,\vec 0), \qquad X'^\mu = (0,\,f',\,\vec 0), \qquad f' = \frac{df}{d\sigma}>0.X˙μ=(c,0,0),X′μ=(0,f′,0),f′=dσdf​>0.

    Contract these with the mostly-plus metric ημν=diag(−,+,…,+)\eta_{\mu\nu}=\mathrm{diag}(-,+,\dots,+)ημν​=diag(−,+,…,+):

    (\dot X)^2 = -c^2, \qquad (X')^2 = (f')^2, \qquad \dot X\cdot X' = 0. \tag{1}

    The −c2-c^2−c2 marks the τ\tauτ-tangent as timelike, an "at rest" direction; (f′)2(f')^2(f′)2 is the squared stretch; and X˙⋅X′=0\dot X\cdot X' = 0X˙⋅X′=0 says the time direction is orthogonal in spacetime to the stretch direction, exactly what "sitting still" should look like.

    Evaluate the action

    The Nambu–Goto action carries (X˙⋅X′)2−(X˙)2(X′)2\sqrt{(\dot X\cdot X')^2 - (\dot X)^2(X')^2}(X˙⋅X′)2−(X˙)2(X′)2​ under its integral. Plugging in (1):

    0−(−c2)(f′)2=c f′(since f′>0).\sqrt{0 - (-c^2)(f')^2} = c\,f' \quad (\text{since } f'>0).0−(−c2)(f′)2​=cf′(since f′>0).

    So, with S=−T0c∫dt∫dσ ⋯S = -\tfrac{T_0}{c}\int dt\int d\sigma\,\sqrt{\cdots}S=−cT0​​∫dt∫dσ⋯​,

    S = -\frac{T_0}{c}\int_{t_i}^{t_f}\!dt\int_0^{\sigma_1}\!d\sigma\;c\,f' \;=\; -T_0\int_{t_i}^{t_f}\!dt\int_0^{\sigma_1}\!d\sigma\,\frac{df}{d\sigma}. \tag{2}

    The σ\sigmaσ-integrand is a total derivative, so the inner integral collapses to endpoint values:

    S = -T_0\int_{t_i}^{t_f}\!dt\,\big(f(\sigma_1)-f(0)\big) = \int_{t_i}^{t_f}\!dt\,(-T_0\,a). \tag{3}

    The function fff has vanished: any ruler gives the same T0 aT_0\,aT0​a. That is reparameterization invariance made concrete — the calculation kept the endpoint separation aaa and threw away the coordinate labels, which is exactly what a geometric quantity should do.

    Read off the potential energy

    For a static configuration the kinetic energy is zero, so L=−VL = -VL=−V and S=∫dt (−V)S = \int dt\,(-V)S=∫dt(−V). Matching this against (3):

    \boxed{\,V = T_0\,a\,} \tag{4}

    The energy stored is proportional to length, with constant of proportionality T0T_0T0​. Differentiating, dV/da=T0dV/da = T_0dV/da=T0​ is the force you must apply to hold the endpoint out — the tension. That dV/dadV/dadV/da is constant is the defining signature: the force is the same at every length, unlike a Hooke spring whose pull grows with extension.

    The same T0T_0T0​ from the endpoint force

    The force reading can be checked without differentiating VVV, straight from the boundary term. Varying the open-string action leaves the endpoint term ∫dt [Pμσ δXμ]σ=0σ=σ1\int dt\,\big[\mathcal P^\sigma_\mu\,\delta X^\mu\big]_{\sigma=0}^{\sigma=\sigma_1}∫dt[Pμσ​δXμ]σ=0σ=σ1​​ (see Neumann versus Dirichlet conditions), where Pμσ\mathcal P^\sigma_\muPμσ​ is the flux of μ\muμ-momentum along the string toward its end. For this static string (computed in the next section)

    P1σ=−T0,Pμσ=0 (μ≠1).\mathcal P^\sigma_1 = -T_0, \qquad \mathcal P^\sigma_\mu = 0 \ (\mu\neq 1).P1σ​=−T0​,Pμσ​=0 (μ=1).

    Move the right endpoint by δa=δX1(t,σ1)\delta a = \delta X^1(t,\sigma_1)δa=δX1(t,σ1​); its contribution to the action is

    δSright=∫dt P1σ δa=−∫dt T0 δa.\delta S_{\text{right}} = \int dt\,\mathcal P^\sigma_1\,\delta a = -\int dt\,T_0\,\delta a.δSright​=∫dtP1σ​δa=−∫dtT0​δa.

    A static variation obeys δS=−∫dt δV\delta S = -\int dt\,\delta VδS=−∫dtδV, so δV=T0 δa\delta V = T_0\,\delta aδV=T0​δa — the same law as (4), now read off from the momentum flowing off the end. The two derivations agree because the boundary term is precisely the variational form of the endpoint force:

    T0=dVda=∣endpoint force∣.T_0 = \frac{dV}{da} = |\text{endpoint force}|.T0​=dadV​=∣endpoint force∣.

    One view says how much extra energy a longer string costs; the other says what force the support must hold. Same number.

    The static string really solves the equations of motion

    We assumed the straight string is a solution — worth one line to confirm. Since neither X˙μ\dot X^\muX˙μ nor X′μX'^\muX′μ depends on τ\tauτ, neither momentum density does either, and the equation of motion ∂τPμτ+∂σPμσ=0\partial_\tau\mathcal P^\tau_\mu + \partial_\sigma\mathcal P^\sigma_\mu = 0∂τ​Pμτ​+∂σ​Pμσ​=0 reduces to ∂σPμσ=0\partial_\sigma\mathcal P^\sigma_\mu = 0∂σ​Pμσ​=0. The σ\sigmaσ-momentum density is Pμσ=∂L/∂X′μ\mathcal P^\sigma_\mu = \partial\mathcal L/\partial X'^\muPμσ​=∂L/∂X′μ with L\mathcal LL the Nambu–Goto integrand; carrying out the derivative and then substituting (1),

    Pμσ=−T0c (X˙⋅X′) X˙μ−(X˙)2 Xμ′(X˙⋅X′)2−(X˙)2(X′)2=−T0c c2 Xμ′c2(f′)2=−T0 Xμ′f′.\mathcal P^\sigma_\mu = -\frac{T_0}{c}\,\frac{(\dot X\cdot X')\,\dot X_\mu - (\dot X)^2\,X'_\mu}{\sqrt{(\dot X\cdot X')^2 - (\dot X)^2(X')^2}} = -\frac{T_0}{c}\,\frac{c^2\,X'_\mu}{\sqrt{c^2 (f')^2}} = -T_0\,\frac{X'_\mu}{f'}.Pμσ​=−cT0​​(X˙⋅X′)2−(X˙)2(X′)2​(X˙⋅X′)X˙μ​−(X˙)2Xμ′​​=−cT0​​c2(f′)2​c2Xμ′​​=−T0​f′Xμ′​​.

    This is nonzero only for μ=1\mu=1μ=1, where X1′=f′X'_1 = f'X1′​=f′ (mostly-plus leaves the spatial index unchanged), giving the constant P1σ=−T0\mathcal P^\sigma_1 = -T_0P1σ​=−T0​. That constant is manifestly σ\sigmaσ-independent, so ∂σPμσ=0\partial_\sigma\mathcal P^\sigma_\mu = 0∂σ​Pμσ​=0 holds and the straight string is a genuine solution. The boundary conditions hold too. Every spatial coordinate of an endpoint is pinned, so all spatial directions are Dirichlet — in the language of D-branes (first appearance), each end sits on a D0-brane. Time is always Neumann, P0σ=0\mathcal P^\sigma_0 = 0P0σ​=0, satisfied here because X0′=0X'_0 = 0X0′​=0. This is the boundary bookkeeping developed in Neumann versus Dirichlet conditions.

    The payoff: mass from tension

    Creating the string from nothing deposits rest energy VVV into a length aaa. So the rest mass per unit length μ0\mu_0μ0​ obeys

    μ0c2=Va=T0⟹μ0=T0c2.\mu_0 c^2 = \frac{V}{a} = T_0 \quad\Longrightarrow\quad \mu_0 = \frac{T_0}{c^2}.μ0​c2=aV​=T0​⟹μ0​=c2T0​​.

    This is the deep part. In a Newtonian string, mass density μ0\mu_0μ0​ and tension T0T_0T0​ are two independent inputs — you can imagine a heavy slack rope with density but no tension. The relativistic string has no such freedom: its mass density is its tension, divided by c2c^2c2. Set T0=0T_0=0T0​=0 and the string is genuinely massless, with no leftover "stuff." The string weighs something only because it is taut; every gram of its rest mass is stored tension energy, not intrinsic material. (Contrast The wave equation on an interval, where tension and density are separate nonrelativistic dials.)

    The signs matter here. Had we chosen the opposite sign in front of the action or under the radical, VVV in (4) would have come out negative — a string that releases energy as you stretch it, an instability. Positive VVV justifies both minus signs after the fact (the same check done fast in Static gauge).

    Open questions

    • μ0\mu_0μ0​ is a rest mass density. Once the string moves, transverse motion adds a relativistic γ\gammaγ-factor to the energy — see Endpoint velocity and endpoint force for the moving-string Lagrangian L=−T0 ⁣∫ds 1−v⊥2/c2L = -T_0\!\int ds\,\sqrt{1-v_\perp^2/c^2}L=−T0​∫ds1−v⊥2​/c2​.
    • Units: T0T_0T0​ is a force (energy per length). Later it is traded for the slope parameter α′\alpha'α′ via T0=12πα′T_0 = \dfrac{1}{2\pi\alpha'}T0​=2πα′1​ in ℏ=c=1\hbar=c=1ℏ=c=1 units — with units restored, T0=ℏc2πα′T_0 = \dfrac{\hbar c}{2\pi\alpha'}T0​=2πα′ℏc​, where α′=ℓs2\alpha' = \ell_s^2α′=ℓs2​ carries dimensions of length squared. The 2π2\pi2π is a convention in the definition of α′\alpha'α′ and plays no role in this classical result.

    Exercise

    A common slip is to think that if you use a "denser" reparameterization near one end — say fff that rises slowly then quickly — the string stores more energy there and the total changes. Show explicitly that it does not: take the concrete ruler f(σ)=a (σ/σ1)3f(\sigma) = a\,(\sigma/\sigma_1)^3f(σ)=a(σ/σ1​)3 on σ∈[0,σ1]\sigma\in[0,\sigma_1]σ∈[0,σ1​], carry it through the action, and confirm you still get V=T0aV = T_0 aV=T0​a. Then state in one sentence which line of the general derivation guarantees this had to happen.

    With f(σ)=a (σ/σ1)3f(\sigma) = a\,(\sigma/\sigma_1)^3f(σ)=a(σ/σ1​)3 we have f(0)=0f(0)=0f(0)=0, f(σ1)=af(\sigma_1)=af(σ1​)=a (endpoints correct), and f′(σ)=3aσ13 σ2>0on (0,σ1],f'(\sigma) = \frac{3a}{\sigma_1^3}\,\sigma^2 > 0 \quad\text{on } (0,\sigma_1],f′(σ)=σ13​3a​σ2>0on (0,σ1​], so fff is strictly increasing.
