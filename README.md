# chronicaria.github.io

NBA power rankings and season forecast, served at https://chronicaria.github.io/.

Elo ratings in points against an average team, with preseason Vegas win-total priors and a player-availability
layer, plus 100,000 hot simulations of the rest of the season. Every file here is generated by a nightly build;
edit the source kit, not this repo.

The previous personal site is preserved on the `personal-site-archive` branch.
