    Spending the gauge freedom on a clock

    The worldsheet coordinates (τ,σ)(\tau,\sigma)(τ,σ) are labels drawn on the string, and the string does not care which grid we draw. Light-cone gauge spends that relabeling freedom to make one of the string's own coordinates the time axis. Instead of asking "where is the string at worldsheet time τ\tauτ?", we declare that τ\tauτ means the light-cone time X+=(X0+X1)/2X^+ = (X^0+X^1)/\sqrt2X+=(X0+X1)/2​ has reached a given value. Time on the sheet and light-cone time in spacetime become the same clock; once X+X^+X+ is pinned to τ\tauτ it is no longer a field to solve for, and that single move is what makes the string exactly solvable in the notes that follow.

    Filming a thrown ball, you can label the frames by frame number (τ\tauτ) or by how far downrange the ball has traveled (X+X^+X+). The second labels time by a coordinate of the object itself, so that coordinate stops being separately unknown. Downrange distance works where height would fail: a clock must advance monotonically, and height turns around. For the string, p+>0p^+ > 0p+>0 is what keeps X+X^+X+ ticking forward.

    Why we are allowed to choose

    The Nambu–Goto action is reparameterization invariant: relabeling (τ,σ)→(τ~,σ~)(\tau,\sigma)\to(\tilde\tau,\tilde\sigma)(τ,σ)→(τ~,σ~) leaves the physics unchanged. This is a gauge symmetry — a redundancy in the description, not a symmetry of nature — and it contains two relabelings to fix, one for τ\tauτ and one for σ\sigmaσ.

    A gauge choice picks one coordinate grid on each worldsheet out of the infinitely many equivalent ones. We add no force and change no string; we choose coordinates in which a dependent variable can be promoted to the independent time variable. The point particle already shows this: the covariant description uses DDD functions Xμ(τ)X^\mu(\tau)Xμ(τ), but one function's worth of that is pure parameter choice.

    The class of gauges

    Fix τ\tauτ by demanding it equal a linear combination of the spacetime coordinates. Pick a constant covector nμn_\munμ​ and impose

    n⋅X(τ,σ)=λ τ.n\cdot X(\tau,\sigma) = \lambda\,\tau.n⋅X(τ,σ)=λτ.

    At fixed τ\tauτ the string lies in the hyperplane n⋅x=λτn\cdot x = \lambda\taun⋅x=λτ, normal to nnn. So nnn chooses which slicing of the worldsheet counts as "equal time" — different nnn, different notion of simultaneity along the string.

    • nμ=(1,0,…,0)n_\mu = (1,0,\dots,0)nμ​=(1,0,…,0) makes n⋅X=X0n\cdot X = X^0n⋅X=X0: worldsheet time tracks ordinary time. This is the static gauge; see Static gauge.
    • A null nnn gives the light-cone gauge — the choice this note is about.

    Trade λ\lambdaλ for a cleaner constant built from the conserved component n⋅pn\cdot pn⋅p (for a free open string all of pμp^\mupμ is conserved; in general we only need n⋅pn\cdot pn⋅p). Working in natural units ℏ=c=1\hbar = c = 1ℏ=c=1 with τ,σ\tau,\sigmaτ,σ dimensionless, the full gauge fixes both relabelings at once:

     n⋅X(τ,σ)=β α′ (n⋅p) τ,(n⋅p) σ=2πβ∫0σdσˉ n⋅Pτ(τ,σˉ) (1)\boxed{\, n\cdot X(\tau,\sigma) = \beta\,\alpha'\,(n\cdot p)\,\tau,\qquad (n\cdot p)\,\sigma = \frac{2\pi}{\beta}\int_0^\sigma d\bar\sigma\, n\cdot\mathcal P^\tau(\tau,\bar\sigma) \,} \tag{1}n⋅X(τ,σ)=βα′(n⋅p)τ,(n⋅p)σ=β2π​∫0σ​dσˉn⋅Pτ(τ,σˉ)​(1) β={2open strings1closed strings.\beta = \begin{cases} 2 & \text{open strings} \\ 1 & \text{closed strings.}\end{cases}β={21​open stringsclosed strings.​

    With nnn on both sides, only its direction matters — its overall scale cancels. The first equation fixes the τ\tauτ slicing: the clock. The second lays the ruler: the n⋅pn\cdot pn⋅p-momentum accumulated between 000 and σ\sigmaσ (density Pτμ\mathcal P^{\tau\mu}Pτμ, from Variation of the worldsheet area) must grow linearly in σ\sigmaσ. Differentiating gives n⋅p=2πβ n⋅Pτn\cdot p = \frac{2\pi}{\beta}\,n\cdot\mathcal P^\taun⋅p=β2π​n⋅Pτ, so that density is constant along the string — a uniform ruler. Evaluating the second equation at the far end, where the integral is all of n⋅pn\cdot pn⋅p, sets the ranges σ∈[0,2π/β]\sigma\in[0,2\pi/\beta]σ∈[0,2π/β]: [0,π][0,\pi][0,π] open, [0,2π][0,2\pi][0,2π] closed. The factor α′\alpha'α′ keeps τ\tauτ dimensionless.

    So the gauge does two jobs: the first equation makes a spacetime coordinate into a clock; the second lays a uniform σ\sigmaσ-ruler along each clock slice. Both are needed before the clean constraints of Light-cone constraints appear.

    Here α′\alpha'α′ is the Regge slope, the theory's one dimensionful parameter (tension T0=1/(2πα′)T_0 = 1/(2\pi\alpha')T0​=1/(2πα′), string length ℓs=α′\ell_s = \sqrt{\alpha'}ℓs​=α′​). Everything below is dimensional analysis around it — no QFT needed.

    Light-cone coordinates

    From x0x^0x0 (time) and one chosen spatial direction x1x^1x1, define (see Light-cone coordinates)

    x^\pm = \tfrac{1}{\sqrt 2}\big(x^0 \pm x^1\big). \tag{2}

    The fact that matters is the metric. With mostly-plus signature η=diag(−,+,+,… )\eta = \mathrm{diag}(-,+,+,\dots)η=diag(−,+,+,…), invert (2) to a0=12(a++a−)a^0 = \tfrac{1}{\sqrt2}(a^++a^-)a0=2​1​(a++a−), a1=12(a+−a−)a^1 = \tfrac{1}{\sqrt2}(a^+-a^-)a1=2​1​(a+−a−) and compute:

    a⋅b=−a0b0+a1b1+aIbI=−a+b−−a−b++aIbI.a\cdot b = -a^0 b^0 + a^1 b^1 + a^I b^I = -a^+ b^- - a^- b^+ + a^I b^I.a⋅b=−a0b0+a1b1+aIbI=−a+b−−a−b++aIbI.

    The (+,−)(+,-)(+,−) block is off-diagonal: η+−=η−+=−1\eta_{+-} = \eta_{-+} = -1η+−​=η−+​=−1, with no (a+)2(a^+)^2(a+)2 or (a−)2(a^-)^2(a−)2 term. This single fact drives the whole module — it lets a quadratic constraint be solved for the −-− component linearly, no square root.

    The transverse coordinates are everything left over: XI=(X2,…,XD−1),I=2,…,D−1,X^I = (X^2,\dots,X^{D-1}), \qquad I = 2,\dots,D-1,XI=(X2,…,XD−1),I=2,…,D−1, which is D−2D-2D−2 of them.

    Imposing the gauge: X+∝τX^+ \propto \tauX+∝τ

    Choose nnn to be the light-cone direction, as the covector

    n_\mu = \Big(\tfrac{1}{\sqrt 2},\, \tfrac{1}{\sqrt 2},\, 0,\dots,0\Big). \tag{3}

    This is null: raising with mostly-plus gives nμ=(−12,12,0,… )n^\mu = (-\tfrac1{\sqrt2},\tfrac1{\sqrt2},0,\dots)nμ=(−2​1​,2​1​,0,…), so nμnμ=−12+12=0n_\mu n^\mu = -\tfrac12+\tfrac12 = 0nμ​nμ=−21​+21​=0. Contracting the covector (3) — as displayed, without raising — with XXX and with ppp:

    n\cdot X = \frac{X^0 + X^1}{\sqrt 2} = X^+, \qquad n\cdot p = \frac{p^0 + p^1}{\sqrt 2} = p^+. \tag{4}

    The null slicing still cuts the string along sensible directions: a tangent bμb^\mubμ to an equal-τ\tauτ slice obeys n⋅b=0n\cdot b = 0n⋅b=0, so b1=−b0b^1 = -b^0b1=−b0 and b2=−(b0)2+(b1)2+bIbI=bIbI≥0b^2 = -(b^0)^2+(b^1)^2+b^Ib^I = b^Ib^I \geq 0b2=−(b0)2+(b1)2+bIbI=bIbI≥0 — the slices are spacelike (at worst null), never timelike.

    The gauge condition (1) with β=2\beta = 2β=2 (open) now reads

     X+(τ,σ)=2α′ p+ τ .\boxed{\,X^+(\tau,\sigma) = 2\alpha'\,p^+\,\tau\,}.X+(τ,σ)=2α′p+τ​.

    Worldsheet time τ\tauτ is the light-cone time X+X^+X+, up to the constant 2α′p+2\alpha' p^+2α′p+ (positive, so the clock runs forward). X+X^+X+ is no longer an unknown function — it is fixed to be linear in τ\tauτ, with no center-of-mass position and no oscillators: x0+=0,αn+=α−n+=0(n≥1).x_0^+ = 0, \qquad \alpha_n^+ = \alpha_{-n}^+ = 0 \quad (n\geq1).x0+​=0,αn+​=α−n+​=0(n≥1).

    One of the DDD coordinate fields is thus entirely eaten by the gauge — the redundant parameter direction, now made explicit for the string. This is why the physical count will come out to D−2D-2D−2: this note kills one coordinate (X+X^+X+), and the constraints in Light-cone constraints will kill a second (X−X^-X−).

    The second gauge condition, in light-cone variables, becomes

    p+ σ=2πβ∫0σdσˉ Pτ+(τ,σˉ).p^+\,\sigma = \frac{2\pi}{\beta}\int_0^\sigma d\bar\sigma\, \mathcal P^{\tau +}(\tau,\bar\sigma).p+σ=β2π​∫0σ​dσˉPτ+(τ,σˉ).

    For open strings (β=2\beta = 2β=2) this forces Pτ+=p+/π\mathcal P^{\tau +} = p^+/\piPτ+=p+/π, constant along the string: every equal-τ\tauτ slice carries a uniform density of p+p^+p+. This is the quieter σ\sigmaσ-half of light-cone gauge, and it feeds directly into Light-cone constraints.

    The price: no manifest Lorentz covariance

    A null nnn is exactly what makes n⋅X=X+n\cdot X = X^+n⋅X=X+. The cost: nnn singles out the x1x^1x1 axis, so the gauge condition looks different in different Lorentz frames — light-cone gauge is not Lorentz covariant. Classically this is harmless: the physics stays Lorentz invariant, only our description hides it. It becomes the central issue at quantization, where demanding that the hidden Lorentz generators still close forces D=26D = 26D=26.

    Open questions

    • We assumed the space-filling open-string setup, so all of pμp^\mupμ (hence p+p^+p+) is conserved. For lower-dimensional D-branes, light-cone gauge needs nnn chosen so n⋅pn\cdot pn⋅p stays conserved along the Neumann directions; deferred to the D-brane modules.
    • The gauge uses p+p^+p+ as a scale, and the next note divides by it. Why p+>0p^+ > 0p+>0 holds for every physical state except a massless particle aimed exactly along −x1-x^1−x1 is settled in Light-cone constraints.

    Exercise

    The boxed result X+=2α′p+τX^+ = 2\alpha' p^+\tauX+=2α′p+τ has the factor 222 for the open string. Redo the substitution for a closed string (β=1\beta=1β=1) and state the analogous result. Then verify the null vector by lowering: given the raised null vector nμ=(−12,12,0,… )n^\mu=(-\tfrac1{\sqrt2},\tfrac1{\sqrt2},0,\dots)nμ=(−2​1​,2​1​,0,…), lower it with η=diag(−,+,… )\eta=\mathrm{diag}(-,+,\dots)η=diag(−,+,…) and confirm you recover the covector (3) — so that n⋅X=X+n\cdot X=X^+n⋅X=X+ regardless of which form you were handed.

    Solution

    Closed string. Set β=1\beta=1β=1 in the first equation of (1). With nnn the same null direction, n⋅X=X+n\cdot X=X^+n⋅X=X+ and n⋅p=p+n\cdot p=p^+n⋅p=p+ from (4) are unchanged (they do not depend on β\betaβ). So X+(τ,σ)=α′ p+ τ,X^+(\tau,\sigma) = \alpha'\,p^+\,\tau,X+(τ,σ)=α′p+τ, exactly half the open-string coefficient. The factor 222 vs 111 is the only difference; it tracks the doubled range σ∈[0,2π]\sigma\in[0,2\pi]σ∈[0,2π] chosen for closed strings, so that the p+p^+p+-density comes out uniform on that longer ruler. X+X^+X+ is again pure clock: no x0+x_0^+x0+​, no oscillators.

    Lowering the null vector. With nμ=(−12,12,0,… )n^\mu=(-\tfrac1{\sqrt2},\tfrac1{\sqrt2},0,\dots)nμ=(−2​1​,2​1​,0,…), apply nμ=ημνnνn_\mu=\eta_{\mu\nu}n^\nunμ​=ημν​nν: n0=η00 n0=(−1)(−12)=12,n1=η11 n1=(+1)(12)=12,n_0 = \eta_{00}\,n^0 = (-1)\big(-\tfrac1{\sqrt2}\big)=\tfrac1{\sqrt2},\qquad n_1=\eta_{11}\,n^1=(+1)\big(\tfrac1{\sqrt2}\big)=\tfrac1{\sqrt2},n0​=η00​n0=(−1)(−2​1​)=2​1​,n1​=η11​n1=(+1)(2​1​)=2​1​, and nI=0n_I=0nI​=0. That is the covector (3). Check nullity either way: nμnμ=12 ⁣⋅ ⁣(−12)+12 ⁣⋅ ⁣12=−12+12=0n_\mu n^\mu = \tfrac1{\sqrt2}\!\cdot\!(-\tfrac1{\sqrt2})+\tfrac1{\sqrt2}\!\cdot\!\tfrac1{\sqrt2}=-\tfrac12+\tfrac12=0nμ​nμ=2​1​⋅(−2​1​)+2​1​⋅2​1​=−21​+21​=0. Because n⋅X=nμXμ=12(X0+X1)=X+n\cdot X=n_\mu X^\mu=\tfrac1{\sqrt2}(X^0+X^1)=X^+n⋅X=nμ​Xμ=2​1​(X0+X1)=X+ uses the covector, both presentations give the same contraction — the sign only bites if you mistake the displayed downstairs components for upstairs ones.
