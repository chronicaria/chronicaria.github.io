    One rule: the action is the size of the swept shape

    A point particle is a dot; a string is a tiny loop or segment. Pushed through time, each sweeps out a shape: the dot a curve (its worldline), the string a surface (its worldsheet). A single rule then fixes the entire theory of each object — the action is the geometric size of the swept shape: proper length for the curve, proper area for the surface.

    0-dim particle → sweeps  1-dim worldline,S=−mc∫ds\text{0-dim particle}\ \xrightarrow{\ \text{sweeps}\ }\ \text{1-dim worldline}, \qquad S=-mc\int ds0-dim particle  sweeps ​ 1-dim worldline,S=−mc∫ds 1-dim string → sweeps  2-dim worldsheet,S=−T0c∫dA\text{1-dim string}\ \xrightarrow{\ \text{sweeps}\ }\ \text{2-dim worldsheet}, \qquad S=-\frac{T_0}{c}\int dA1-dim string  sweeps ​ 2-dim worldsheet,S=−cT0​​∫dA

    The reason the free particle extremizes proper length is, word for word, the reason the free string extremizes proper area — the same sentence with "length" swapped for "area." This note works out that one swap, and it is why the course spends a module on a particle: the string action is too unfamiliar to guess cold, yet it is a near-mechanical lift of the particle action once the dimensional pattern is visible. The recipe is identical both times — take the reparameterization-invariant geometric measure of the swept object and multiply by the constant with the right units. See Worldsheet and induced metric for the surface and its geometry.

    The five parallels that matter

    The table asserts; five of its rows deserve proof rather than assertion.

    1. Geometric action. The particle action is (rest energy) ×\times× (proper time): since dsdsds is proper length and ds/cds/cds/c is proper time, S=−mc2 ⁣∫(ds/c)=−mc∫dsS = -mc^2\!\int (ds/c) = -mc\int dsS=−mc2∫(ds/c)=−mc∫ds. The simplest Lorentz-invariant number a curve carries is its length, so length is the inevitable first guess for the action — and it is correct. A surface's analogous invariant is its area, so the string action is S=−T0c∫dAS = -\frac{T_0}{c}\int dAS=−cT0​​∫dA, the Nambu-Goto action. The prefactor mcmcmc has units of momentum, and momentum ×\times× length === action; T0/cT_0/cT0​/c has units of action per area. Same idea, one dimension up.

    2. Reparameterization invariance. A parameter is a ruler laid along the shape; sliding the ruler cannot change the shape's size. Concretely, the particle integrand

    S=−mc∫τiτf−ημν dxμdτdxνdτ  dτS = -mc\int_{\tau_i}^{\tau_f}\sqrt{-\eta_{\mu\nu}\,\tfrac{dx^\mu}{d\tau}\tfrac{dx^\nu}{d\tau}}\;d\tauS=−mc∫τi​τf​​−ημν​dτdxμ​dτdxν​​dτ

    (mostly-plus signature, so the argument of the root is positive for timelike motion) is homogeneous of degree one in the velocities dxμ/dτdx^\mu/d\taudxμ/dτ: under τ→τ′\tau\to\tau'τ→τ′, one factor of the Jacobian dτ′/dτd\tau'/d\taudτ′/dτ pulls out of the square root and one is eaten converting dτ→dτ′d\tau\to d\tau'dτ→dτ′. They cancel, so SSS is unchanged — see Reparameterization invariance. Nambu–Goto is built with the same homogeneity, so the identical cancellation kills the 2-dim Jacobian ∂(τ′,σ′)/∂(τ,σ)\partial(\tau',\sigma')/\partial(\tau,\sigma)∂(τ′,σ′)/∂(τ,σ). Relabeling a curve becomes relabeling a surface; the redundancy grows from one arbitrary function to two.

    3. Gauge fixing. Redundancy is freedom you get to spend. The particle's one function lets you pick τ=s\tau=sτ=s (proper-time gauge, giving the clean d2xμ/ds2=0d^2x^\mu/ds^2=0d2xμ/ds2=0), or τ=t\tau=tτ=t (static gauge, recovering Newtonian p⃗\vec pp​ and EEE), or τ∝x+\tau\propto x^+τ∝x+ (light-cone) — see Gauge choices for the worldline parameter. The string's two functions fix two conditions at once: X+∝τX^+\propto\tauX+∝τ plus a condition spreading p+p^+p+ uniformly along σ\sigmaσ. For the particle a gauge choice is a convenience; for the string it is a necessity — the particle's light-cone choice is the rehearsal for the string's Light-cone gauge, the move that makes quantization tractable.

    4. Equation of motion. Varying −mc∫ds-mc\int ds−mc∫ds gives dpμ/dτ=0dp_\mu/d\tau=0dpμ​/dτ=0: a total τ\tauτ-derivative set to zero, i.e. momentum is constant along the worldline. Varying Nambu–Goto gives ∂α(worldsheet momentum density)=0\partial_\alpha(\text{worldsheet momentum density})=0∂α​(worldsheet momentum density)=0: a 2-dim divergence set to zero, i.e. a wave equation. The boundary term that the particle's fixed endpoints kill becomes, for the open string, genuine physical boundary conditions — and those conditions are the first hint of D-branes.

    5. Constraint from redundancy. Reparameterization invariance is not free: it forces a constraint. For the particle, the momenta pμp_\mupμ​ conjugate to xμx^\muxμ cannot all be independent — the square-root structure of the action locks them onto the single mass shell pμpμ=−m2c2p^\mu p_\mu = -m^2c^2pμpμ​=−m2c2 (see Mass-shell relation). For the string, the same invariance forces the worldsheet stress tensor to vanish — and that is one local condition per point along the string, an infinite tower: the Virasoro constraints. One mass becomes a whole spectrum: the particle's mass mmm is an input, while the string's mass is an output built from its vibration modes.

    Index counting: why strings need BμνB_{\mu\nu}Bμν​

    This is the deepest and least obvious parallel. A charged particle couples to the electromagnetic potential through

    qc∫PAμ dxμ,\frac{q}{c}\int_\mathcal{P} A_\mu\,dx^\mu ,cq​∫P​Aμ​dxμ,

    the integral of a one-index field along the one-dimensional worldline. Why one index? Because dxμdx^\mudxμ carries exactly one spacetime index, and a Lorentz scalar needs it contracted against a field with one index. The dimension of the swept object dictates the rank of the field it can naturally couple to.

    Lift this one dimension up. A worldsheet has two independent tangent directions, so its natural area element dXμ∧dXνdX^\mu\wedge dX^\nudXμ∧dXν carries two antisymmetric indices. A scalar therefore needs a two-index antisymmetric field,

    ∫ΣBμν dXμ∧dXν,(1)\int_\Sigma B_{\mu\nu}\,dX^\mu\wedge dX^\nu , \tag{1}∫Σ​Bμν​dXμ∧dXν,(1)

    and this is precisely how the antisymmetric [[Kalb-Ramond field|Kalb–Ramond field BμνB_{\mu\nu}Bμν​]] enters string theory. A particle sources a 1-form potential; a string sources a 2-form. The existence of BμνB_{\mu\nu}Bμν​ follows from nothing but the dimension of a string.

    What does not carry over cleanly

    The analogy is a lift, not an isomorphism. Three places it genuinely breaks:

    • No proper-time gauge for the string. A surface has no single clock; its induced metric γαβ\gamma_{\alpha\beta}γαβ​ is a 2×22\times22×2 matrix, not a single normalization you can set to 111. The string's workable gauges are conformal and light-cone, not proper time.
    • The jump in constraint complexity is real, not cosmetic. One mass-shell condition →\to→ an infinite Virasoro tower is a genuine escalation. Quantizing the tower forces a normal-ordering constant and a critical dimension (D=26D=26D=26 for the bosonic string), neither of which has any point-particle counterpart. Beyond this module.
    • The massless case. −mc∫ds-mc\int ds−mc∫ds collapses to zero when m=0m=0m=0, so the geometric particle action fails for a photon (though the mass-shell constraint survives — see Mass-shell relation). The string action does not degenerate: the constant multiplying its measure is the tension, and T0≠0T_0\neq0T0​=0. The clean fix for the particle is the auxiliary-metric formulation, the Polyakov action — deferred.

    Open questions

    • The normalization and wedge-factor convention of the BμνB_{\mu\nu}Bμν​ coupling (1) are set in the string-charge module; here index counting only predicted its rank. → Kalb-Ramond field.
    • The Polyakov action gives a cleaner bridge between the particle constraint and the string constraints (both come from an auxiliary metric's equation of motion), and it repairs the massless case — but it belongs to the graduate-bridge module.

    Exercise

    The dictionary claims the constant multiplying the geometric measure changes from mcmcmc (particle) to T0/cT_0/cT0​/c (string). Verify this is forced by units alone, then use the same logic to predict the constant for a hypothetical 2-brane — a membrane whose world-volume is 3-dimensional and whose "size" is a proper 3-volume. Take its defining constant to be a tension T2T_2T2​ with units of energy per unit area (energy/length²).

    An action has the dimensions of ℏ\hbarℏ: energy ×\times× time. Give the multiplying constant in all three cases and state the pattern.

    Solution

    Write [S][S][S] for the dimensions of an action: energy ×\times× time =E T= \mathsf{E}\,\mathsf{T}=ET. The measure in each case has these dimensions:

    • worldline: ∫ds\int ds∫ds is a length L\mathsf{L}L;
    • worldsheet: ∫dA\int dA∫dA is an area L2\mathsf{L}^2L2;
    • membrane world-volume: ∫dV\int dV∫dV is a 3-volume L3\mathsf{L}^3L3.

    The constant must supply whatever is left over so the product lands on E T\mathsf{E}\,\mathsf{T}ET. Using L=VT\mathsf{L}=\mathsf{V}\mathsf{T}L=VT (velocity ×\times× time) via factors of ccc:

    Particle. Need [k0]⋅L=E T[k_0]\cdot\mathsf{L} = \mathsf{E}\,\mathsf{T}[k0​]⋅L=ET, so [k0]=E T/L=E/V[k_0]=\mathsf{E}\,\mathsf{T}/\mathsf{L} = \mathsf{E}/\mathsf{V}[k0​]=ET/L=E/V. With rest energy mc2mc^2mc2 and speed ccc: k0=mc2/c=mc  ✓k_0 = mc^2/c = mc\;\checkmarkk0​=mc2/c=mc✓ — matching S=−mc∫dsS=-mc\int dsS=−mc∫ds.

    String. Tension T0T_0T0​ has units energy/length =E/L=\mathsf{E}/\mathsf{L}=E/L. Need [k1]⋅L2=E T[k_1]\cdot\mathsf{L}^2=\mathsf{E}\,\mathsf{T}[k1​]⋅L2=ET, so [k1]=E T/L2=(E/L)⋅(T/L)=(E/L)/V[k_1]=\mathsf{E}\,\mathsf{T}/\mathsf{L}^2 = (\mathsf{E}/\mathsf{L})\cdot(\mathsf{T}/\mathsf{L}) = (\mathsf{E}/\mathsf{L})/\mathsf{V}[k1​]=ET/L2=(E/L)⋅(T/L)=(E/L)/V. So k1=T0/c  ✓k_1 = T_0/c\;\checkmarkk1​=T0​/c✓ — matching S=−T0c∫dAS=-\frac{T_0}{c}\int dAS=−cT0​​∫dA.

    Membrane. Tension T2T_2T2​ has units energy/area =E/L2=\mathsf{E}/\mathsf{L}^2=E/L2. Need [k2]⋅L3=E T[k_2]\cdot\mathsf{L}^3=\mathsf{E}\,\mathsf{T}[k2​]⋅L3=ET, so [k2]=E T/L3=(E/L2)⋅(T/L)=(E/L2)/V[k_2]=\mathsf{E}\,\mathsf{T}/\mathsf{L}^3=(\mathsf{E}/\mathsf{L}^2)\cdot(\mathsf{T}/\mathsf{L})=(\mathsf{E}/\mathsf{L}^2)/\mathsf{V}[k2​]=ET/L3=(E/L2)⋅(T/L)=(E/L2)/V. So k2=T2/ck_2=T_2/ck2​=T2​/c, and Smembrane=−T2c∫dV.S_{\text{membrane}} = -\frac{T_2}{c}\int dV.Smembrane​=−cT2​​∫dV.

    The pattern. For a ppp-brane sweeping a (p+1)(p{+}1)(p+1)-dimensional world-volume, the constant is always (tension)/c/c/c, where the tension has units of energy per unit ppp-volume. Units alone fix the 1/c1/c1/c; the minus sign and any dimensionless factor need the full derivation. This is exactly the dimensional lift the note describes: bump the swept dimension by one, bump the tension's spatial-density rank by one, and divide by ccc.
